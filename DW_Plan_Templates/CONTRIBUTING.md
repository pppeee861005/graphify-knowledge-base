# 🤝 貢獻指南 - Contributing Guidelines

感謝你想為 DW Plan Templates 做出貢獻！

Thank you for wanting to contribute to DW Plan Templates!

## 中文 - 簡體中文版本

### 我們歡迎的貢獻類型

✅ **新語言翻譯** - 將DW文檔翻譯成其他語言（英文、日本語、韓文、西班牙文等）

✅ **新應用場景** - 分享你發現的DW新應用領域（例如：教育、醫療、製造業等）

✅ **框架改進** - 基於你的實踐提出對DW框架的改進建議

✅ **案例分享** - 分享你成功應用DW的實際故事和經驗

✅ **文檔完善** - 修正錯誤、補充缺漏、改進表述

✅ **工具開發** - 開發围绕DW的輔助工具或工作流程

✅ **最佳實踐** - 分享你的使用經驗和最佳實踐

### 如何提交貢獻

#### Step 1: Fork 本倉庫
```bash
gh repo fork pppeee861005/dw-plan-templates --clone
cd dw-plan-templates
```

#### Step 2: 創建你的特性分支
```bash
git checkout -b feature/your-contribution-name
# 例如：
# git checkout -b feature/translate-english
# git checkout -b feature/new-scenario-education
# git checkout -b feature/improvement-framework
```

#### Step 3: 進行你的更改

請確保：
- ✅ 遵循現有的文檔格式和風格
- ✅ 在中文文檔中保持繁體中文
- ✅ 添加適當的說明和例子
- ✅ 註明你的名字和貢獻日期

#### Step 4: 提交你的更改
```bash
git add .
git commit -m "簡要說明你的貢獻

詳細說明：
- 你貢獻了什麼
- 為什麼這很重要
- 如何幫助全人類升級決策思維"
```

#### Step 5: 推送到你的 fork
```bash
git push origin feature/your-contribution-name
```

#### Step 6: 創建 Pull Request
在 GitHub 上創建 PR，說明：
- 這個貢獻的具體內容
- 為什麼它對 DW 社群很重要
- 如何驗證你的貢獻（如果適用）

### 貢獻審核標準

我們會根據以下標準審核貢獻：

| 標準 | 要求 |
|------|------|
| **清晰性** | 說明清楚，易於理解 |
| **品質** | 符合 DW 的哲學和標準 |
| **完整性** | 包含必要的例子和說明 |
| **原創性** | 基於實踐和真實經驗 |
| **價值** | 對 DW 社群有意義 |

## English - Contribution Guidelines

### Types of Contributions We Welcome

✅ **Language Translations** - Translate DW documents into other languages (English, Japanese, Korean, Spanish, etc.)

✅ **New Application Scenarios** - Share new use cases for DW frameworks (e.g., Education, Healthcare, Manufacturing)

✅ **Framework Improvements** - Suggest improvements to the DW framework based on your experience

✅ **Case Studies** - Share your success stories and experiences applying DW

✅ **Documentation Improvements** - Fix errors, fill gaps, improve clarity

✅ **Tool Development** - Develop supporting tools or workflows around DW

✅ **Best Practices** - Share your experiences and best practices

### How to Contribute

#### Step 1: Fork the repository
```bash
gh repo fork pppeee861005/dw-plan-templates --clone
cd dw-plan-templates
```

#### Step 2: Create your feature branch
```bash
git checkout -b feature/your-contribution-name
```

#### Step 3: Make your changes

Please ensure:
- ✅ Follow existing document format and style
- ✅ Clear and well-explained changes
- ✅ Include appropriate examples
- ✅ Add your name and contribution date

#### Step 4: Commit your changes
```bash
git commit -m "Brief description of your contribution

Detailed explanation:
- What you contributed
- Why this matters
- How it helps the global community upgrade decision-making"
```

#### Step 5: Push to your fork
```bash
git push origin feature/your-contribution-name
```

#### Step 6: Create a Pull Request
On GitHub, create a PR explaining:
- What your contribution specifically includes
- Why it's important for the DW community
- How to verify your contribution (if applicable)

### Review Standards

We review contributions based on:

| Criteria | Requirement |
|----------|------------|
| **Clarity** | Clear and easy to understand |
| **Quality** | Aligns with DW philosophy |
| **Completeness** | Includes necessary examples |
| **Originality** | Based on real experience |
| **Value** | Meaningful for DW community |

## ❓ 常見問題

**Q: 我從未貢獻過，可以開始嗎？**
A: ✅ 絕對可以！我們歡迎任何級別的貢獻者。

**Q: 我的英文不好，可以只用中文提交嗎？**
A: ✅ 可以。我們可以幫助翻譯或協助你。

**Q: 提交需要多長時間才能被審核？**
A: 通常 3-7 天，具體取決於複雜性。

**Q: 如果我的貢獻被拒絕了怎麼辦？**
A: 我們會提供反饋和改進建議。這是學習的機會。

**Q: 我可以修改別人的貢獻嗎？**
A: 如果有改進，可以創建新的 PR。我們會協調不同的想法。
