# Antigravity 2.0：深層 Agent-First 協作編程環境

> **核心定義**：Antigravity 2.0 是由 Google DeepMind 開發的「Agent-First（智能體優先）」軟體開發協作平台。它徹底顛覆了傳統 AI 僅作為編輯器側邊欄聊天室（Chatbot）或代碼補全（Autocomplete）的被動角色，轉而將 AI 智能體（Agents）定位為主動的程式協同開發者。

---

## 🎯 核心設計哲學：Agent-First 範式

在傳統的軟體開發中，AI 只是「輔助工具」，開發者必須主動下達指令、複製貼上代碼，並手動在終端機與瀏覽器中進行驗證。

**Antigravity 2.0** 則實現了 **Software 3.0** 的核心願景——**開發者定義意圖，智能體自主執行與驗證**：
* **意圖驅動**：開發者只需描述巨觀目標（Goal），Antigravity 即可將其轉化為具體的實作計畫。
* **閉環執行**：擁有讀寫檔案、操作沙盒終端機、運行測試指令，以及控制瀏覽器進行前端驗證的完整權限。
* **透明度與可控性**：透過可視化的「工件（Artifacts）」追蹤進度，開發者無需埋首於繁雜的終端日誌。

---

## 🛠️ 四大核心架構

Antigravity 2.0 的高效協作建立在以下四個維度之上：

### 1. 雙階段計畫範式（Planning Mode）
為避免盲目修改代碼導致系統崩潰，Antigravity 2.0 嚴格區分了「調研計畫」與「執行驗證」：
* **研討與計畫期（Research & Plan）**：智能體先深入探索代碼庫，產出 `implementation_plan.md`，列出修改範圍與潛在風險，獲得開發者核准後才動手。
* **執行與驗證期（Execute & Verify）**：透過 `task.md` 即時同步 TODO 進度，並在完成後生成 `walkthrough.md` 進行變更導覽。

### 2. 多智能體協同調度（Multi-Agent Orchestration）
系統支援動態定義與喚醒專用子智能體（Subagents）：
* **研究專家（Research Subagent）**：負責廣泛檢索代碼庫與搜尋 Web 資源，不影響主線寫作。
* **代碼執行者（Self Subagent）**：複製主配置以進行沙盒環境中的並行重構或並行任務。

### 3. 可視化工件系統（Artifacts）
將複雜的執行日誌提煉為直觀的 Markdown 文件：
* 自動排版代碼 Diff 區塊。
* 整合 Mermaid 圖表以視覺化系統架構。
* 支持多狀態切換的卡片輪播（Carousels），方便審查 UI 的前後對比。

### 4. 瀏覽器端自動化驗證（Browser Automation）
內置網頁自動化工具，智能體能自主啟動本地開發伺服器，模擬用戶在瀏覽器中的點擊、填表與導覽，截圖或錄製影片以自我驗證前端渲染效果是否正確。

## 📊 Antigravity 2.0 與傳統 AI 輔助開發的對比

| 維度 | 傳統 AI 助手 (如 Copilot/Chat) | Antigravity 2.0 (Agent-First) |
| :--- | :--- | :--- |
| **交互模式** | 被動式（問答、代碼補全） | 主動式（研讀、提案、計畫與執行） |
| **上下文邊界** | 單一檔案或有限的 Token 視窗 | 全局代碼庫理解 + Web 即時檢索 |
| **執行權限** | 僅能生成代碼，由人類手動貼上 | 自主讀寫、運行指令、修改多個關聯檔案 |
| **驗證機制** | 無（由開發者手動編譯與測試） | 閉環驗證（自動執行 Unit Test 與模擬瀏覽器驗證） |
| **協作管理** | 單一對話線路 | 支持多 Agent 並行協作，且狀態可視化 |

## 🚀 未來展望與 Software 3.0

在 Antigravity 2.0 的框架下，未來的程式開發工作將會產生轉變：
* **開發者的角色**：從「寫代碼的打字員（Coder）」晉升為「架構決策者與審查者（Reviewer）」。
* **引力源的轉移**：個人與組織擁有的數位資產（即個人知識庫、專案代碼、工作流）將產生強大的「引力」，而 Antigravity 則是引導這些引力自動化生成價值的作業系統（Agent OS）。
