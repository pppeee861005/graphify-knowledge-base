## 🧠 第一步：選一個任務

### 什麼是好的首次任務？

✅ **適合的任務**：
- 你熟悉的領域
- 比較簡單，不要太複雜
- 有清楚的成功標準
- 有多個角度要檢查

❌ **不適合的任務**：
- 你完全不懂的領域
- 非常複雜的系統
- 沒有明確目標
- 只需要一個人做

### 5 個練習選項

#### 選項 1️⃣：檢查一份文章
```
任務：評估一篇文章的質量

為什麼好？
- 你能理解
- 有多個評估維度
- 有清楚的標準

多少個 Agent？（不用你決定）
- Agent 1：檢查語法和拼寫
- Agent 2：檢查邏輯和結構
- Agent 3：檢查內容是否有用
- 決策 Agent：匯總結果
```

#### 選項 2️⃣：評估一個電影或動漫
```
任務：評估一部作品是否值得看

為什麼好？
- 你看過
- 有多個評估方面（故事、角色、動畫等）
- 你有自己的標準

多少個 Agent？
- Agent 1：故事評估
- Agent 2：角色評估
- Agent 3：視覺效果評估
- 決策 Agent：給總評分
```

#### 選項 3️⃣：檢查一個工作計劃
```
任務：檢查一個團隊的工作計劃是否可行

為什麼好？
- 有現實意義
- 多個維度（時間、資源、人力）
- 有清楚的標準

多少個 Agent？
- Agent 1：時間可行性
- Agent 2：資源可行性
- Agent 3：風險評估
- 決策 Agent：最終決定
```

#### 選項 4️⃣：評估一個商業想法
```
任務：評估一個創業想法是否可行

為什麼好？
- 有趣
- 多維度評估
- 有具體標準

多少個 Agent？
- Agent 1：市場評估
- Agent 2：技術可行性
- Agent 3：財務評估
- 決策 Agent：投資決定
```

#### 選項 5️⃣：檢查你自己的想法
```
你有什麼想檢查的嗎？
- 一個計劃
- 一個決定
- 一件事情

都可以！用 DW 的方法來評估它。
```

## ✍️ 第二步：寫你的 DW 定義

### 模板（簡化版）

```markdown
# [任務名稱] 的 Dynamic Workflows 定義

## 一、問題定義

**要解決什麼問題？**
[一句話描述]

**輸入是什麼？**
[什麼東西進來]

**輸出是什麼？**
[什麼結果出去]

## 二、驗證標準

**成功標準**：
- 標準 1：[具體要求]
- 標準 2：[具體要求]
- 標準 3：[具體要求]

## 三、決策規則

**規則**：
- 若 [情況 1] → [怎麼做]
- 若 [情況 2] → [怎麼做]
- 若 [無法決定] → 升級給人工

## 四、預算

**總預算**：[X] 單位
**預期成本**：[Y] 單位
**預留**：[Z] 單位（[百分比]%）
```

## 📝 完整例子 1️⃣：檢查文章

### 你的答案應該是這樣的

```markdown
# 文章質量評估 - Dynamic Workflows 定義

## 一、問題定義

**要解決什麼問題？**
評估一篇文章的總體質量，判斷是否值得發佈

**輸入是什麼？**
一篇完成的文章（1000-5000 字）

**輸出是什麼？**
評分（1-10 分）+ 改進建議 + 發佈 YES/NO 的決定

## 二、驗證標準

**成功標準**：
- 語法和拼寫檢查無誤（100% 正確）
- 邏輯清晰（至少 8/10）
- 內容有用（至少 7/10）
- 結論明確

## 三、決策規則

**規則**：
- 若 語法 + 邏輯 + 內容都 ≥ 7/10 → 發佈
- 若 任何維度 < 7/10 → 改進後再評估
- 若 無法判斷質量 → 升級給人工編輯

## 四、預算

**總預算**：0.5 單位
**預期成本**：0.2 單位
**預留**：0.3 單位（60%）
```

## 📝 完整例子 2️⃣：評估電影

### 你的答案應該是這樣的

```markdown
# 《咒術回戰》值得看嗎？- Dynamic Workflows 定義

## 一、問題定義

**要解決什麼問題？**
判斷一部動漫是否值得推薦給朋友看

**輸入是什麼？**
一部完成的動漫作品

**輸出是什麼？**
推薦指數（1-10）+ 適合人群 + 改進意見

## 二、驗證標準

**成功標準**：
- 故事評分 ≥ 7/10
- 角色塑造 ≥ 7/10
- 動畫質量 ≥ 6/10
- 音樂和音效 ≥ 6/10

## 三、決策規則

**規則**：
- 若 所有評分 ≥ 7/10 → 強烈推薦（9-10）
- 若 三項 ≥ 7/10，一項 ≥ 5/10 → 推薦（7-8）
- 若 有項 < 5/10 → 不推薦（4-6）
- 若 無法判斷某些方面 → 升級給多個粉絲評估

## 四、預算

**總預算**：1.0 單位
**預期成本**：0.4 單位
**預留**：0.6 單位（60%）
```

## 🎬 範例：你可能犯的錯誤

### ❌ 錯誤 1️⃣：問題太模糊

```
❌ 「評估文章」
✅ 「評估這篇文章是否值得發佈」

❌ 「檢查質量」
✅ 「檢查代碼的語法、邏輯和安全性」
```

### ❌ 錯誤 2️⃣：標準不具體

```
❌ 「文章要寫得好」
✅ 「語法無誤，邏輯清晰 ≥ 8/10，內容有用 ≥ 7/10」

❌ 「質量要高」
✅ 「Bug 發現率 ≥ 80%」
```

### ❌ 錯誤 3️⃣：提前決定 Agent

```
❌ 「用 3 個 Agent：語法檢查、邏輯檢查、安全檢查」
✅ 「檢查多個方面，AI 決定怎麼分工」

❌ 「先做語法，再做邏輯」
✅ 「檢查語法和邏輯，順序由 AI 決定」
```

### ❌ 錯誤 4️⃣：預留太少

```
❌ 總預算 0.5，預期 0.45，預留 0.05（10%）
✅ 總預算 1.0，預期 0.4，預留 0.6（60%）
```
