# ⚡ Dynamic Workflows 核心速查表
## 遇到不懂的詞彙時查這裡

---

## 🎯 核心概念（5 個）

### 1️⃣ Dynamic Workflows（動態工作流）
**簡單說**：一個 AI 團隊根據不同情況自動改變工作方式

**比喻**：
- 🏴‍☠️ **航海王**：草帽海賊團根據敵人不同而改變戰術
- 就算敵人強，就算情況複雜，他們也能應對

**你需要做**：告訴 AI「要達成什麼目標」，AI 會自動決定「怎麼分工」

---

### 2️⃣ Agent（代理人）
**簡單說**：一個有特定技能的 AI 助手

**比喻**：
- 🥷 **火影忍者**：一個忍者的「影分身」
- 🏴‍☠️ **航海王**：路飛（戰鬥）、索隆（劍術）、娜美（航海）
- 每個 Agent 有自己擅長的事

**記住**：你不需要決定要多少個 Agent，AI 會自動決定

---

### 3️⃣ 決策規則（Decision Rules）
**簡單說**：「在什麼情況下應該怎麼做」

**比喻**：
- ⚔️ **咒術回戰**：虎杖在戰鬥中的應對
  - 「如果敵人快速移動 → 用直拳」
  - 「如果敵人防禦強 → 用特殊技能」

**格式**：
```
若 [條件] → [怎麼做]

例如：
若 Bug 很嚴重 → 優先修複
若 有兩個意見不同 → 升級給人工決定
```

---

### 4️⃣ 預算（Budget）
**簡單說**：最多花多少「成本」來完成任務

**比喻**：
- 🚁 **極限返航**：直升機的「燃料」
- 💰 **星際救援**：太空人的「食物和水」
- 如果沒有預算限制，就可能超支

**重要**：預留 50% 作為「應急用」，就不會出問題

---

### 5️⃣ 升級（Escalation）
**簡單說**：AI 無法決定時，把問題交給人類

**比喻**：
- 🚀 **THE MANDALORIAN**：尋求領導的建議
- ⚔️ **咒術回戰**：有些敵人太強，要請更厲害的人幫忙

**什麼時候升級？**
- 有無法解決的衝突
- 成本即將超支
- 無法做出自動決策

## 🔤 常見詞彙

| 詞彙 | 簡單說 | 比喻 |
|------|--------|------|
| **Stage** | 工作流的一個步驟 | 火影一集的一個對話 |
| **Pipeline** | 一個接一個做 | 排隊做任務 |
| **Parallel** | 同時做多個 | 多個影分身同時執行 |
| **Aggregation** | 把結果合在一起 | 把多個報告合成一份 |
| **Verification** | 檢查是否成功 | 檢查敵人是否被打敗 |
| **Token** | AI 理解語言的計量單位 | 一句話用掉多少「理解力」 |
| **Cost** | 花掉多少資源 | 用掉多少燃料 |
| **APPROVED** | 通過/同意 | ✅ OK |
| **REJECTED** | 不通過/拒絕 | ❌ 不行 |
| **ESCALATED** | 升級給人工 | 🆘 救命！ |

## 📊 三個重要數字

### 1️⃣ 30-40 分鐘
**這份學童版的時長**
- 讀完你就懂了
- 不需要任何基礎

### 2️⃣ 50%
**預算預留率**
- 預留一半的預算作為應急
- 這樣就不會出問題

### 3️⃣ 87%
**時間節省**
- 傳統方式：10 小時
- Dynamic Workflows：1.5 小時
- 省掉 87% 的時間！

## 💡 5 個「要做」

✅ **要做這些**：

1. **清楚地說出目標**
   - 「我要檢查代碼的 Bug」
   - 「我要審批員工請假」

2. **定義成功標準**
   - 「找到 80% 的 Bug」
   - 「99% 的申請 1 小時內處理」

3. **寫出決策規則**
   - 「若 Bug 很嚴重 → 優先修複」
   - 「若 政策和法律衝突 → 升級給 VP」

4. **給足預算**
   - 預留至少 50%
   - 預期成本 0.5 → 預算 1.0

5. **信任 AI**
   - 不要說「用 3 個 Agent」
   - AI 會自動決定幾個最好

---

## ❌ 5 個「不要做」

❌ **不要這樣**：

1. **不要預先設計流程**
   - ❌ 「Stage 1 做 X，Stage 2 做 Y」
   - ✅ 「需要檢查多個方面」

2. **不要指定 Agent 數量**
   - ❌ 「用 3 個 Agent」
   - ✅ 「需要並行檢查」

3. **不要預估具體成本**
   - ❌ 「0.1 + 0.2 + 0.15 = 0.45」
   - ✅ 「預期成本 0.3-0.5」

4. **不要預留預算太少**
   - ❌ 預留 10%
   - ✅ 預留 50% 或以上

5. **不要寫得太複雜**
   - ❌ 定義書 10 頁
   - ✅ 定義書 1-2 頁

## 🎯 最常問的 3 個問題

### Q1：我需要懂代碼嗎？
**A**：不需要。這版本零代碼。

### Q2：要學多久？
**A**：30-40 分鐘掌握核心。然後可以選擇更深入或應用。

### Q3：學完後能做什麼？
**A**：
- 理解 AI 協作的邏輯
- 認識生活中的類似場景
- 決定是否需要進階學習

## 💾 一頁紙總結

```
Dynamic Workflows = 多個 AI 根據情況自動改變工作方式

三個核心：
  1. Agent = 有技能的 AI 助手（像火影的影分身）
  2. 決策規則 = 「若...則...」的邏輯
  3. 預算 = 資源限制（預留 50%）

你的工作：
  ✅ 定義目標和標準
  ✅ 寫決策規則
  ✅ 給預算

AI 的工作：
  ✅ 決定用多少 Agent
  ✅ 決定工作流程
  ✅ 自動執行和監控

記住：預留預算很重要，這樣就不會失敗！
```
