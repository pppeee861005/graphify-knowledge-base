## 💡 核心概念速查

### DW計劃的本質

```
FROM：給你完整代碼
      → 複製 → 運行 → 只有開發者受益

TO:   教你定義問題
      → 修改定義 → 自動生成 → 所有人受益
```

### 四份核心文檔的角色

```
定義書（5,000-8,000字）
  └─ 業務邏輯核心，任何人都能修改

預算書（3,000-4,000字）
  └─ 透明化成本和ROI，助力決策

教學指南（4,000-7,000字）
  └─ 能力轉移，教用戶自動生成

參考實現（代碼）
  └─ 參考示例，不是必須複製的內容
```

### 三層學習路徑

```
Layer 1：理解（15分鐘）→ 讀定義書
Layer 2：學習（30分鐘）→ 修改定義書
Layer 3：執行（1小時）→ 自動生成 + 驗證 + 分享
```
