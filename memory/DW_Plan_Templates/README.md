## 💡 三個核心原則

### 原則1️⃣：DW應用優先
```
定義書 > 代碼
業務邏輯 > 實現細節
任何人都能修改 > 只有開發者能改
```

### 原則2️⃣：社群共好
```
預留社群參與空間（other_creators_workflows/）
定義書是永恆資產（社群可持續改進）
代碼是短期資產（容易被替代）
```

### 原則3️⃣：快速迭代
```
5-7天完成第一版
持續根據反饋改進
不追求完美，追求完成
```

## ❓ 常見問題

### Q: 這些模版怎麼用？
**A**: 根據你的時間選擇：著急？複製快速模版。慎重？讀詳細指南。

### Q: 5-7天能完成嗎？
**A**: ✅ 是的。有經驗的人3-5天，新手5-7天。關鍵是定義書的清晰度。

### Q: 可以修改模版結構嗎？
**A**: ✅ 可以。核心原則是「DW應用優先」，細節可調整。

### Q: 社群貢獻目錄是什麼？
**A**: 預留給社群改進定義書、用其他語言實現、發現新場景。
