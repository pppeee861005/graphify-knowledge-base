## 💡 使用本模版時的三個核心原則

### 原則1️⃣：DW應用優先
```
定義書 > 代碼
業務邏輯 > 實現細節
任何人都能修改 > 只有開發者能改
```

### 原則2️⃣：社群共好
```
預留社群參與空間（other_creators_workflows/）
定義書是永恆資產（社群可持續改進）
代碼是短期資產（容易被替代）
```

### 原則3️⃣：快速迭代
```
5-7天完成第一版
持續根據反饋改進
不追求完美，追求完成
```

## 📞 常見問題

### Q: 這些模版適用於所有DW應用場景嗎？
**A**: ✅ 是的。基於Plan 1和工具模板的通用原則。場景越多越好，能証明DW的通用性。

### Q: 可以修改模版結構嗎？
**A**: ✅ 可以。核心原則是「DW應用優先」，細節結構可根據場景調整，但建議保持標準化便於對比。

### Q: 如果不清楚某個部分怎麼辦？
**A**:
1. 查看DW_Plan_Development_Index.md的常見問題
2. 參考計劃1或計劃7的具體示範
3. 閱讀工具和模板的DW通用指南

### Q: 社群貢獻目錄是什麼意思？
**A**: 預留other_creators_workflows/給社群改進定義書、用其他語言實現、發現新場景。鼓勵參與。
