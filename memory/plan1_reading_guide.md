## 📝 「決策」和「確認」有什麼區別？

### 決策（Decision）

```
你做出選擇：GO / MODIFY / HOLD / CANCEL

例：
  「我選 GO，明天開始執行」
  或
  「我選 MODIFY，Step 3 需要調整，因為...」
```

### 確認（Confirmation）

```
你確認計劃中的具體細節

例：
  「我確認 3 個 HR 場景的選擇」
  「我確認成功指標的定義」
  「我確認時間表為 2-3 天」
```
