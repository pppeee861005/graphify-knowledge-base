## 🐝 蜂群 Agent

**用戶慣用術語**：「蜂群 agent」

**完整定義**：
> **Dynamic Workflows** - Claude Code v2.1+ 引入的多代理協作系統，允許一個 Lead Agent 在執行任務時動態生成、調度和協調多個 Sub-agents。

**詩意版定義（核心思維框架）**：
> **AI Agent 如蜂群，遇山開路、遇水搭橋，動態協作直到目標達成。**

**技術版總結**：
> 把蜂群 AI 用動態戰術編排，讓代理自動化並互相協調，即時適應任務變化。

## 🧠 核心思維模式

**我們已進入「蜂群 Agent 時代」**

### 思考問題的新視角

當分析問題、設計解決方案、規劃任務時，應用以下思維框架：

**不再問**：「這個任務要怎麼一步步做？」
**而是問**：「需要召喚哪些 AI Agent？如何讓它們協作？」

**不再想**：「如果 A 失敗了怎麼辦？」
**而是想**：「A 失敗了，派 B 用不同方法重試。」

**不再設計**：「寫死的流程 A → B → C」
**而是設計**：「Lead Agent 根據現實動態調整戰術。」

### 核心原則

✅ **遇山開路** - 遇到障礙，動態生成新的解決路徑
✅ **遇水搭橋** - 面對困難，召喚合適的 Agent 協作
✅ **動態協作** - 數量、方法、結構都可即時調整
✅ **目標導向** - 任務開始時只有目標，其餘執行中決定

### 應用場景

- 📝 規劃文章系列 → 召喚研究 Agent、寫作 Agent、編輯 Agent
- 🔧 解決技術問題 → Lead Agent 分析，召喚專家 Agent 協作
- 🎯 完成複雜任務 → 蜂群式並行工作，動態適應變化

## 使用說明

當用戶說「蜂群 agent」時，理解為：
- ✅ Dynamic Workflows 系統
- ✅ 多 Agent 動態協作
- ✅ Lead Agent + Sub-agents 架構
- ✅ 動態戰術編排

**不要理解為**：
- ❌ 單一 Agent
- ❌ 靜態工作流
- ❌ 傳統程式流程
