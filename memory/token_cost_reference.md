## 🎯 成本單位轉換

### 核心公式

```
1 單位（Unit） = 100 萬 Token = 1,000,000 Token

成本 = Token 消耗 / 1,000,000
```

| 成本單位 | Token 數量 | 成本含義 |
|---------|-----------|---------|
| 0.01 | 10 萬 | 簡單檢查一次 |

| 0.10 | 100 萬 | 標準檢查 |

| 0.50 | 500 萬 | 大規模分析 |
| 1.00 | 1000 萬 | 超大規模任務 |

## 🔍 讀者應該理解的

### 成本的實際含義

**0.18 單位 = 180 萬 Token 意味著什麼？**

```
在 Claude Haiku 的成本計算中：
- 輸入 Token：約 $0.80 / 100 萬 Token
- 輸出 Token：約 $4.00 / 100 萬 Token

所以 180 萬 Token ≈ $1.44 - $7.20（美金成本）

或用時間計：
- 普通人手寫相同內容：40-50 小時
- AI 生成相同內容：0.5 小時
- 時間成本節省：98%
```

### 為什麼要強調這個

**讀者需要明白**：
1. ✅ **成本很透明** — 不是黑盒，1 單位 = 100 萬 Token
2. ✅ **成本很低廉** — 180 萬 Token ≈ 幾美元
3. ✅ **成本很可控** — 定義書的預算控制機制完全有效

## 🎓 讀者的核心認知

### ✅ 應該理解的

1. **成本是透明的**
   - 每 100 萬 Token = 1 單位
   - 可以精確跟蹤成本消耗

2. **成本是可控的**
   - 預算上限是硬限制
   - 降級機制確保不超支

3. **成本是極其低廉的**
   - 0.18 單位（180 萬 Token）完成複雜分析
   - 換算成美金：2-8 美金
   - 換算成時間成本節省：98%

### ❌ 不應該陷入的誤區

1. **「Token 不重要」**
   - 錯誤！Token = 實際成本
   - 需要監控以避免浪費

2. **「1 單位很便宜，可以無限用」**
   - 錯誤！需要預算控制意識
   - 便宜是相對的，監控仍然必要

3. **「成本就是 Token，無法理解」**
   - 錯誤！有明確的轉換關係
   - 可以轉換成美金、時間、其他衡量標準

## 💰 成本在決策中的角色

### 成本不是障礙，而是**設計的約束**

**好的定義書應該包含**：
```
1. 明確的預算上限（例如 0.3 單位）
2. 預期成本估算（例如 0.12 單位）
3. 成本監控策略（四個階段）
4. 降級機制（成本達到 80% 時的行動）
5. 升級條件（成本即將超支時的升級）
```

### 成本帶來的好處

**通過監控成本，我們可以**：
- ✅ 評估「問題定義的質量」（好的定義會節省成本）
- ✅ 優化「決策規則的有效性」（減少誤報 = 成本下降）
- ✅ 改進「降級策略的智慧」（巧妙的降級保證完成）

## 🎯 對讀者的建議

### 使用定義書時

1. **第一次**：用默認的預算（如 0.3 單位）
2. **執行時**：看著成本計數器，學習成本的實際含義
3. **第二次**：根據實際成本調整預算估算
4. **優化**：不斷改進，使成本估算更準確

### 理解成本的意義

```
成本監控 ≠ 省錢思維

成本監控 = 設計智慧的體現

一個好的定義書會：
✅ 成本低（效率高）
✅ 成本穩定（可預測）
✅ 成本對標明確（100 萬 Token = 多少工作量）
```
