### 「利益衝突」轉折的價值
- 用逻輯質疑而非感性否定，更有說服力
- 讓讀者在「同意哈拉瑞」和「看到新視角」中不衝突
- 這是「AI 工程派詩人」的特色：理性、感性兼具

### 長文章的節奏控制
- 1,450 字不是太長不是太短
- 分 7 個段落，每個 150-350 字，節奏清晰
- 表格和比喻穿插，視覺不疲勞

### L1 Subagents 模式的實踐驗證 ⭐⭐⭐⭐⭐
- **核心發現**：用 L1 並行模式來完成圖表設計本身
  - 一次派出 3 個 subagent（每層一個）
  - 3 個 subagent 同時執行（不是串行）
  - 主廚整合 3 份回報 → 完整 SVG
  - **成本：極低 token，速度：極快，品質：完整**

- **並行 vs 串行的實際體驗**：
  - 串行方式：Sub1 完成 → Sub2 完成 → Sub3 完成（3 倍時間）
  - 並行方式：Sub1/2/3 同時完成（1 倍時間 + 整合）
  - **這次實作證明了並行的優勢**

- **四層架構的對比洞察**：
  - L1 = 「我決策，你執行」（廚房，最靈活）
  - L1.5 = 「我監控多個廚房」（可視化 + 人類決策）
  - L2 = 「我們一起討論」（peer-to-peer，實驗性）
  - L3 = 「代碼自動執行」（工廠，最昂貴）
  - **選擇權很重要：不是「哪個最好」，而是「適合場景」**

- **下一步機會**：
  - L2 Agent Teams 的圖解（需要展示 peer-to-peer 通訊）
  - 製作「選擇決策樹」：什麼時候用哪一層？
