# 豪力風神總編輯工作台：方法論

## 最終決定方案

> **決定狀態：最終定案**

| 項目 | 最終方案 |
|---|---|
| 技術名稱 | `editorial-collaboration-workbench` |
| 中文名稱 | **豪力風神總編輯工作台** |
| 類型定位 | **圖文連載總編輯協作 Skill** |
| 核心角色 | 人類是總編輯與最終決策者；AI 是編輯助理群 |
| 工作模式 | 依清楚 SOP 進行多輪閱讀、判斷、修訂、驗收與定稿 |
| 生產隱喻 | 手工藝工坊與總編輯桌，不是自動化內容工廠 |
| 最終權力 | 思想、品味、事實責任、採用與發布權均保留給人類 |

### 最終一句話定位

> **一套以人類總編輯為核心、AI 編輯助理為輔，依照清楚 SOP 支援多輪閱讀、判斷、修改與定稿的圖文創作工作台。**

### 最終核心承諾

> **不替作者自動生產作品，而是依照清楚的編輯 SOP，協助作者在每個階段閱讀、判斷、疊代與定稿；將繁瑣工作交給 AI，把作品的思想、品味與最終決定權留給人類。**

### 最終核心原則

> **AI 負責降低創作的摩擦，人類負責決定作品的靈魂。**

### 明確不採用的定位

- 不定位為「一鍵生成完整系列」的自動化生產線。
- 不定位為取代作者的 AI 寫作工廠。
- 不以文章篇數、字數或圖片數量作為主要產能指標。
- 不允許 AI 未經確認，自行定案作品方向、價值立場與發布決策。
- 不把 SOP 變成僵硬流水線，也不把每個創作專案強迫套入相同形式。

本文件標記為**最終定位方案**；後續可以改進執行細節，但若要改變上述核心定位，必須另立版本並說明改變理由。

## 一、為什麼重新定位

最初可以把這套模式理解為「端到端圖文連載製作人」：從手稿開始，一路完成系列規劃、文章、配圖與發布版。

但實際創作《AI 即一切》後，出現一個更重要的理解：

> 文學與思想創作需要高度的人類介入。作品的細節、節奏、情感、比喻與價值判斷，都必須在多次閱讀與修訂中逐漸成形。

「端到端」容易被誤解成從輸入到輸出的全自動流水線，而真正有效的模式更接近總編輯帶領一組助理工作的編輯部：

- 總編輯掌握思想與方向。
- 助理整理素材、提出方案、檢查細節與執行繁瑣工作。
- 每一階段都經過閱讀、討論、修訂與確認。
- 成品不是被一次生成，而是被反覆編輯出來。

因此，最終定位從「製作人自動完成」轉為「總編輯協作工作台」。

## 二、創作不是工廠，而是手工藝工坊

### 工廠邏輯

```text
固定輸入
→ 固定流程
→ 大量複製
→ 標準化輸出
```

工廠適合結果明確、流程穩定、重複性高且錯誤可以被規格直接判斷的工作。

### 創作邏輯

```text
模糊意圖
→ AI 提出理解
→ 作者判斷
→ 形成暫定方向
→ AI 展開或修訂
→ 作者重新閱讀
→ 發現新問題
→ 返回前一階段
→ 多次疊代
→ 暫時定稿
```

創作的輸入經常不完整，完成標準也會在過程中改變。作者可能原本只想寫一篇，整理後才發現真正需要的是一個系列；也可能看到圖片後，反過來更清楚文章真正想說什麼。

這些「返回、重讀、改變方向」不是流程失敗，而是創作本身。

### SOP 的真正功能

SOP 不是為了消滅人類介入，而是為了確保：

- 人類在正確的位置介入。
- 每次決定都有可追蹤的依據。
- 已確認的成果不會被後續修改意外抹除。
- 不滿意時知道應該返回哪一階段。
- AI 能處理繁瑣工作，而不越過作者的決策邊界。

所以，SOP 是創作工坊的工作桌與工具牆，不是輸送帶。

## 三、總編輯模式的角色架構

### 1. 人類：總編輯、作者與責任主體

人類負責：

- 定義作品真正想談的問題。
- 提供個人經驗、觀察、情感與價值立場。
- 判斷一句話是否有靈魂。
- 決定作品是一篇、上下篇或系列。
- 選擇敘事角度、比喻、節奏與情緒。
- 確認事實、證據、公開範圍與責任邊界。
- 判斷圖片是否真正符合心中的意象。
- 決定哪些版本採用、哪些捨棄。
- 擁有最終定稿與發布權。

總編輯不必親自處理所有細節，但必須掌握所有會改變作品意義的決定。

### 2. AI：編輯助理群

AI 可以同時承擔多種輔助角色：

| AI 角色 | 主要工作 |
|---|---|
| 副總編輯 | 整理整體命題、結構與優先級，提出替代方案 |
| 文字編輯 | 展開草稿、調整段落、比較版本、檢查重複與語病 |
| 研究助理 | 整理資料、標記待查證主張、區分事實與推論 |
| 系列企劃 | 判斷篇章關係、設計敘事弧線與系列導航 |
| 美術企劃 | 將文意轉譯成配圖意境、象徵與視覺 DNA |
| Prompt 編輯 | 將已確認的視覺計畫轉成可執行生圖規格 |
| 製作助理 | 管理檔案、圖片、命名、版本、連結與格式檢查 |
| 品質檢查員 | 檢查一致性、遺漏、亂碼、證據缺口與發布風險 |

AI 的多角色能力用來降低協作成本，不代表 AI 成為作品主角。

### 3. 作品：真正的中心

作者與 AI 都不應為了展示能力而犧牲作品。

每一次編輯都應回到三個問題：

1. 這個修改是否更接近作者真正想說的事情？
2. 它是否讓讀者更容易理解、感受與記住？
3. 它是否保住作品的真實、責任與個人性？

## 四、工作台的核心單位：編輯循環

這套方法最小的工作單位不是「生成」，而是一次完整的編輯循環：

```text
閱讀
→ 理解
→ 提案
→ 人類判斷
→ 修訂
→ 再閱讀
→ 確認或返回
```

### 1. 閱讀

先理解現有作品與上下文，不急著輸出新內容。確認目前處於手稿、系列 Plan、單篇草稿、正文、配圖 Plan、Prompt、圖片或圖文組裝的哪一個階段。

### 2. 理解

說明 AI 對作者意圖的判讀，包括核心命題、矛盾、潛在結構、情緒與尚未確定之處。

### 3. 提案

提供一個主要方案與必要的替代方案，清楚說明各自的代價，不用大量選項淹沒作者。

### 4. 人類判斷

作者確認、否決、混合或提出新的方向。AI 不把沉默視為定案，也不把自己的第一個答案當成唯一答案。

### 5. 修訂

依照作者的判斷執行具體修改，保留原稿或前一版本，避免不可逆覆寫。

### 6. 再閱讀

修改後重新放回整體作品檢查，而不是只確認局部文字是否變動。

### 7. 確認或返回

通過品質門檻後鎖定這一階段；若未通過，明確返回上一個正確節點，而不是從頭重做。

## 五、七階段總編輯工作台

詳細流程研討見：[豪力風神圖文連載工作流 V0.1.md](豪力風神圖文連載工作流%20V0.1.md)

| 階段 | AI 助理主要工作 | 人類總編輯主要決定 | 通過條件 |
|---|---|---|---|
| 1. 接住手稿 | 保存、整理、辨認重複命題與待查證處 | 什麼是最想保留的原始直覺 | 作者認為 AI 沒有誤解核心意圖 |
| 2. 判斷規模 | 分析單篇、上下篇與系列方案 | 作品需要多大的敘事空間 | 規模與拆分理由被作者接受 |
| 3. 建立 Plan | 安排篇章、問題、證據與敘事弧線 | 每篇真正要完成什麼 | 整體順序與單篇任務清楚 |
| 4. 草稿到正文 | 展開、比較、修訂、檢查結構與事實 | 語氣、比喻、節奏與定稿 | 作者讀後仍認得自己的聲音 |
| 5. 配圖 Plan | 找出封面衝突、轉場與結尾餘韻 | 哪個意象真正打中作品 | 視覺有敘事功能，不只是裝飾 |
| 6. Prompt 與圖片 | 撰寫 Prompt、生成、保存與技術檢查 | 圖片採用、重生或調整 | 縮圖、文意、一致性與細節通過 |
| 7. 圖文組裝 | 插圖、Alt Text、導航、格式與連結 | 最終閱讀節奏與發布版本 | 圖文互相增強，作者明確定稿 |

每個階段都運行「閱讀—理解—提案—判斷—修訂—再閱讀」循環，次數由作品需要決定。

## 六、三種介入層級

不是所有工作都需要同樣程度的人類介入。工作台應依影響程度分層。

### A. AI 可直接完成，再回報結果

適合機械、可驗證、低風險工作：

- 檔案搜尋與內容盤點。
- 命名、排序與目錄整理。
- Markdown 結構、圖片尺寸與連結檢查。
- 已確認格式的套用。
- 錯字與明顯重複檢查。
- 根據已確認 Plan 產生工作底稿。

### B. AI 提案，人類確認後執行

適合結構性、會改變作品但仍可比較的工作：

- 單篇或系列判斷。
- 篇章拆分與排序。
- 標題、副題與開場方案。
- 大幅刪改或移動段落。
- 配圖意境與視覺風格。
- 圖片採用與重生方向。

### C. 人類主導，AI 只提供輔助

適合涉及靈魂、責任與不可替代個人性的工作：

- 作品最終想說什麼。
- 個人經驗與情感是否真實。
- 價值立場與倫理界線。
- 哪一句話屬於作者。
- 哪一張圖具有真正的感動。
- 事實公開、法律與專業責任。
- 最終定稿與對外發布。

判斷原則：影響越不可逆、越涉及作者身份與作品意義，人類介入程度越高。

## 七、SOP 應如何設計

一個適合文學創作的 SOP，不只列出步驟。每個階段至少應包含：

| 欄位 | 作用 |
|---|---|
| 目的 | 說明這一階段為什麼存在 |
| 輸入 | 說明以哪一份已確認產物為準 |
| AI 工作 | 定義可以交給助理的繁瑣任務 |
| 人類決定 | 標出不可委派的判斷 |
| 輸出 | 產生可獨立保存與接續的檔案 |
| 品質門檻 | 定義什麼情況才算完成 |
| 返回路徑 | 不滿意時回到哪一步，而非全部重來 |
| 版本規則 | 保留原稿、定稿與修改歷史 |

### SOP 的彈性原則

- 可以由任何現有階段開始。
- 可以跳過不需要的階段。
- 可以返回前一階段。
- 可以只完成單篇，不必完成整季。
- 可以只有一張圖，也可以完全不使用概念圖。
- 結構保持穩定，創作內容保持自由。

清楚不等於僵硬；SOP 管理的是協作秩序，不是作品答案。

## 八、版本與疊代方法

文學創作需要多輪疊代，因此工作台必須保護版本。

### 四種狀態

- **原始**：作者最初輸入，不覆寫。
- **工作中**：允許 AI 與作者反覆修改。
- **已確認**：作者同意作為下一階段依據。
- **已定稿**：只能在明確要求下修改，修改時建立新版本。

### 疊代紀錄至少保存

- 這一輪改了什麼。
- 為什麼改。
- 哪些內容被保留。
- 哪些問題仍未解決。
- 作者做了哪些關鍵決定。
- 下一輪應從哪裡開始。

### 禁止行為

- 用新稿覆蓋原始手稿。
- 未經作者確認，把暫定方向標記成最終定案。
- 修改局部後不重新閱讀全文。
- 因為 AI 可以快速重生，就忽略修改理由與版本差異。

## 九、AI 最適合承接的繁瑣工作

總編輯模式不是降低 AI 的重要性，而是讓 AI 在最適合的位置發揮最大力量。

### 資料理解

- 讀取大量手稿與相關文件。
- 整理命題、案例、比喻、證據與疑問。
- 尋找前後矛盾與重複內容。
- 建立原稿到系列篇章的對照。

### 編輯支援

- 產生結構方案與版本差異。
- 依作者決定展開草稿。
- 檢查每篇是否只回答一個核心問題。
- 確認系列伏線、回收與導航。

### 視覺支援

- 從正文找出真正需要畫面的語意節點。
- 建立系列視覺 DNA。
- 將意象轉成 Prompt、負面 Prompt 與驗收條件。
- 生成、保存並檢查圖片。

### 製作支援

- 管理檔名、目錄、版本與圖片位置。
- 組裝圖文稿與 Alt Text。
- 檢查缺圖、斷鏈、亂碼、標題層級與發布格式。
- 建立下一次工作接續點。

AI 承接越多細部摩擦，作者越能把注意力保留給真正需要人類的判斷。

## 十、不可委派的創作主權

以下權力永遠屬於人類總編輯：

1. **意圖主權**：作品為什麼存在。
2. **敘事主權**：從哪個角度說、對誰說。
3. **品味主權**：什麼是好、什麼不夠準確。
4. **情感主權**：哪些感受真實，哪些只是效果。
5. **事實主權**：哪些經驗真的發生，哪些主張可以公開。
6. **倫理主權**：哪些界線不能越過。
7. **採用主權**：AI 的方案是否進入作品。
8. **發布主權**：作品何時、以何種版本面向讀者。

AI 可以提醒、挑戰與提出反方意見，但不能在沒有授權的情況下取代這些決定。

## 十一、品質不以產量衡量

工作台的成功不等於生成更多文章與圖片。

### 五個評估維度

| 維度 | 評估問題 |
|---|---|
| 意圖忠實度 | 成品是否仍然是作者真正想說的作品？ |
| 編輯品質 | 每次疊代是否讓結構、語言與情緒更準確？ |
| 認知減負 | AI 是否承接了搜尋、整理、比較與製作負擔？ |
| 安全完整性 | 原稿、版本、事實、授權與發布邊界是否被保護？ |
| 個人辨識度 | 作品是否保留作者獨有的語氣、經驗與審美？ |

### 最終品質問題

> 這套協作是否用更少的操作摩擦，讓作者做出更像自己、也更能抵達讀者的作品？

## 十二、工作台的反模式

- 未確認意圖就大量生成內容。
- 把作者的模糊視為錯誤，急著補成確定答案。
- 用一套固定爆款結構取代所有作品的自然形狀。
- 每次修改都從頭重寫，導致作者聲音逐輪流失。
- 只展示 AI 的能力，讓作品退成技術示範。
- 把三張配圖、八篇連載或某種色彩寫成固定規則。
- 用華麗概念圖掩蓋證據不足。
- 把 AI 建議當成總編輯命令。
- 將快速生成誤認為高品質疊代。
- 未經明確授權，自動發布或覆寫定稿。

```text
    ├── visual-plan-template.md

    └── illustrated-article-template.md
```

### `SKILL.md` 只保存

- 最終定位與核心承諾。
- 目前階段的辨認方式。
- 編輯循環。
- 人類決策關卡。
- 必須遵守的原稿、事實、版本與發布邊界。
- 何時讀取哪份參考資料或模板。

### 詳細方法放入 `references/`

避免把所有寫作、系列設計、視覺與事實查核知識塞進主 Skill。使用者只進行局部任務時，只讀取必要的參考文件。

### 第一版不追求自動化腳本

第一版的核心是協作判斷，不是工程自動化。等多次實驗證明檔案檢查、導航產生或圖片驗證等工作高度重複，再加入腳本。

## 十五、方法論宣言

豪力風神總編輯工作台不是一座自動生產內容的工廠。

它是一張總編輯桌。

作者把仍然模糊的手稿放上來。AI 協助整理、拆解、比較、查驗、展開與製作；作者則一次又一次閱讀，判斷什麼是真正想說的，什麼只是漂亮但不屬於自己的句子。

作品在這張桌上經過多輪疊代。它可能從一篇長成一季，也可能在討論後重新縮回一篇；可能因為一張圖片找到新的靈魂，也可能因為一項事實無法驗證而重寫整段論述。

這些不是低效率。

這是創作。

AI 的價值，不是把文學變成工業，而是替創作者移開大量繁瑣工作，讓人類有更多注意力，用在只有人類能做的事情上：感受、判斷、承擔、選擇與賦予作品靈魂。

> **AI 負責降低創作的摩擦，人類負責決定作品的靈魂。**
