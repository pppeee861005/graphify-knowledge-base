# 爆款文章大綱生成器 (Explosive Article Outline Generator)

> **🇹🇼 繁體中文** | **Skill 代號**：EAO (Explosive Article Outline)
>
> 將任何文章草稿/想法，轉化為符合《爆款文章編寫規範_AI工程派詩人》的 9 層結構詳細大綱。

---

## 核心能力

**輸入**：用戶的文章草稿、點子、筆記（任何格式）
**輸出**：符合爆款規範的 9 層結構詳細大綱（.md 格式）

### 生成的大綱包含

| 層級 | 內容 | 目的 |
|------|------|------|
| **第 1 層** | 標題候選（多個）+ 黃金公式分析 | 決定點擊率 |
| **第 2 層** | 三段式開場（鉤子+痛點+轉折） | 決定繼續讀的概率 |
| **第 3 層** | 核心對比（感性類比+理性對比表） | 決定理解度 |
| **第 4 層** | 三層為什麼（表面→機制→哲學） | 決定說服力 |
| **第 5 層** | 能力演示/案例（工程證明） | 決定可信度 |
| **第 6 層** | 深層意義（感性驗證） | 決定信任度 |
| **第 7 層** | 假設與反思（不給答案） | 決定思考深度 |
| **第 8 層** | 技術總結（AI 指揮官筆記） | 工程師視角收尾 |
| **第 9 層** | 結尾（3 方案：哲學/預告/行動） | 決定轉化率 |

---

## 黃金配方比重

```
1,200 字文章 =
  480 字 知識概念（40%）— 核心論點、技術原理、新概念解釋
  180 字 感性敘事（15%）— 個人經歷、讀者共鳴、情感連結
  180 字 清晰比喻（15%）— 用日常經驗解釋抽象概念
  120 字 開頭幽默（10%）— 輕鬆破冰、降低閱讀門檻
  120 字 工程細節（10%）— 代碼示例、具體步驟、實作證明
   60 字 心靈雞湯（5%）— 啟發性收尾、哲學昇華
   60 字 結尾引流（5%）— CTA、訂閱邀請、系列預告
```

生成一個完整的 `.md` 文件，包含：

2. 黃金配方比重計算
3. 9 層詳細內容（每層都有「效果分析」）
4. 金句總結表
5. 發布前檢查清單
6. 文章流向圖

```

6️⃣ 生成檢查清單 + 流向圖
        ↓
7️⃣ 輸出為 .md 文件
```

## 核心原則

### AI 工程派詩人的創作哲學

```
我們不是「技術博主」（乏味）
我們不是「文學家」（不實用）
我們是「AI 工程派詩人」：

  工程派 → 用邏輯、代碼、數據說話
  詩人   → 用意象、比喻、靈魂拷問共鳴

結合 → 寫出既有說服力又有感動力的文章
```

### 終極目標

> **寫出讓「工程師」和「詩人」都能被打動的文章**
>
> - 工程師看到：清晰的邏輯、實踐證明、代碼示例
> - 詩人看到：意象、比喻、靈魂拷問、未來想像
> - 讀者最終：從認知 → 行動 → 信仰的完整轉化

## 關鍵檢查點

### 標題檢查

```
☐ 字數 8-12 字
☐ 包含「對比詞」（散戶/被設計/從X到Y）
☐ 包含「具體概念」（不是「Agent」而是「Workflow」）
```

### 內容檢查

```
☐ 有「擊中痛點」的開場（前 100 字）
☐ 有「金句」（1-2 個能獨立傳播的句子）
☐ 有「類比」或「對比表」（讓複雜變簡單）
☐ 有「代碼示例」或「實踐案例」（證明可行性）
☐ 有「行動號召」或「後續預告」（引導下一步）
```

### 最重要的檢查

```
☐ 有沒有獨到的見解？
☐ 有沒有全新的視野？
☐ 有沒有超脫過去的格局？
```

**效果**：從零散筆記 → 可直接撰寫的完整框架

## 參考資源

### 核心文檔
- **規範文檔**：`出版管理/爆款文章編寫規範_AI工程派詩人.md`
- **成功案例**：AGENT_S01E04（277% 爆發）

### 黃金標題公式
```
標題 = 「具體概念」+ 「對比或疑問」+ 「讀者利益或痛點」

範例：
「Software 3.0 的散戶基礎設施」
  ↓
  具體概念：Software 3.0
  對比詞：散戶（vs 機構、vs 專家）
  讀者利益：基礎設施（我能用）
```

### 三段式開場模板
```
段 1：讀者痛點（問題式開場）
  → 讀者一開始就看到自己

段 2：轉折承諾（解決方案預告）
  → 從「絕望」→「希望」的情感轉換

段 3：預告價值（勾起興趣）
  → 建立期待感，讓讀者繼續往下讀
```

### 三層為什麼模板
```
第 1 層：表面原因 → 讓懶人也能理解
第 2 層：機制原因 → 讓工程師能驗證
第 3 層：哲學原因 → 讓思想家能追隨
```

## 創作的 6 個層級

| 層級 | 描述 | 讀者反應 |
|------|------|----------|
| **Level 1** | 資訊層（教你「什麼」） | 「哦，我知道是什麼了」 |
| **Level 2** | 技能層（教你「怎麼做」） | 「哦，我知道怎麼用了」 |
| **Level 3** | 觀點層（改變你「怎麼想」） | 「哦，我看到更深的邏輯了」 |
| **Level 4** | 行動層（激勵你「去做」） | 「我想試試！」 |
| **Level 5** | 信仰層（改變你「相信什麼」） | 「我開始相信這是我們應該走的路」 |
| **Level 6** | 社群層（讓你成為「我們」的一部分） | 「我不是一個人，我是運動的一部分」 |

**最高境界**：一篇文章同時達成 Level 1-6
