#### 戰略重要性
```
赫爾姆滋海峽（Strait of Hormuz）
  ├─ 全球 20-30% 石油運輸通道
  ├─ 寬度僅 21 海里（最窄處）
  ├─ 伊朗可單方面封鎖
  └─ 無替代路線（成本翻倍）
```

#### 三方利益矩陣

| 角色 | 核心訴求 | 談判籌碼 | 底線 |
|------|---------|---------|------|
| **美國** | 開放海峽，避免石油危機 | 軍事力量、經濟制裁 | 油價 < $100 |
| **以色列** | 伊朗去核化 | 情報能力、區域盟友 | 核設施摧毀 |
| **伊朗** | 解除制裁、加入 SWIFT | 封鎖海峽威脅、代理人 | 經濟生存 |

> **零和博弈**：三方訴求互不相容，妥協空間極小

## 第二部分：短期市場波動分析

### 1. 6/24 亞洲股市大跌：真實原因

#### 台股暴跌 -2.24%（-1,057 點）

**內部因素（貢獻度 90%）**：

| 因素 | 數據 | 影響 |
|------|------|------|
| 融資槓桿極高 | 年增 126.6% | 泡沫破裂主因 |
| 外資期貨做空 | 60 萬口空單 | 做空力量 |
| 外資現貨賣超 | 1,774 億 | 資金流出 |
| 估值過高 | 本益比 > 20x | 技術面脆弱 |

**外部因素（貢獻度 10%）**：
- 美股科技股回調（Nvidia -3%）
- 中東局勢心理影響
- Kevin Warsh 鷹派言論預期

> 🎯 **結論**：這是**內部泡沫破裂**，不是地緣政治驅動
