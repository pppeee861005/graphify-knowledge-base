## 📌 系統核心定義

```
實時狀態持久化儀表板 =
   實時性（Real-time）
   + 狀態持久化（State Persistence）
   + 異常驅動警報（Anomaly-Driven）
   + 決策支持引擎（Decision Support）
   + 儀表板可視化（Dashboard Interface）
```

### 核心特性

```
🟢 實時狀態持久化
   • 系統記住所有數據，永不遺漏
   • 完整的24/7歷史記錄
   • 時間旅行查詢能力

🚨 異常驅動警報
   • 自動檢測關鍵閾值觸發
   • 實時推送多級別警報
   • 無需人工干預

📊 多信號監測
   • 追蹤無限數量的相關信號
   • 信號相關性分析
   • 綜合趨勢判斷

🎯 決策支持引擎
   • 場景推演（"如果...會怎樣？"）
   • 實時概率計算
   • 歷史對比分析

🔄 雙向交互
   • 系統主動推送警報
   • 用戶隨時查詢狀態
   • 實時決策支持
```

| 維度 | L1（傳統） | L1.5（革命） |
|-----|----------|------------|

| **警報機制** | 無 | 自動推送 |
| **決策支持** | 被動回答 | 主動提供 |
| **數據丟失** | 風險高 | 零丟失 |
| **用戶角色** | 被動接收者 | 主動決策者 |

## 🚀 快速開始

### 本地部署（5分鐘）

```bash
# 克隆倉庫
git clone https://github.com/pppeee861005/L1.5-Real-Time-State-Dashboard.git
cd L1.5-Real-Time-State-Dashboard

# 創建虛擬環境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安裝依賴
pip install -r requirements.txt

# 運行系統
python -m l1_5.server

# 訪問
# http://localhost:8000
```

### Docker部署（10分鐘）

```bash
# 構建鏡像
docker build -t l1-5-dashboard:latest .

# 運行容器
docker run -p 8000:8000 l1-5-dashboard:latest

# 訪問
# http://localhost:8000
```
