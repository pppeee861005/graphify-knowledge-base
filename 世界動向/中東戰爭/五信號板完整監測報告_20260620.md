## ⏰ 後續監測與風險預警（班組5設計）

### 60天三大風險監測機制

#### 風險① 協議執行真空 →「草案化」倒退
- **監測指標**：制裁豁免行政令/OFAC許可證、國會程序動作、伊朗官方「定性」措辭、銀行回流意願
- **黃線**：行政令後>15天無配套許可證 / 國會擱置 / 伊朗再稱「草案」
- **紅線**：行政令逾30天未出台 / 國會通過反對決議 / ≥2家主要清算行公開拒絕
- **為何重要**：市場端🟢與地緣端🟡分裂的核心斷層，執行失敗則油價、VIX反向補漲

#### 風險② 黎巴嫩停火二次破裂 → 地緣傳染談判桌
- **監測指標**：貝魯特/黎南空襲數、真主黨報復級別、以軍傷亡、美伊談判排期
- **黃線**：24h內單方違反停火1起 / 談判技術性延後≤72h
- **紅線**：雙向成規模交火 / 以軍傷亡 / 美伊談判再延>72h或取消
- **為何重要**：當前唯一活躍黃色警示，已驗證具「外溢拖累協議」傳導力，最可能把🟡推向🔴

#### 風險③ 霍爾木茲重開逆轉 → 油價/VIX雙線反彈
- **監測指標**：海峽日過境量、商船改道比例、伊朗扣船/封鎖聲明、油輪遇襲
- **黃線**：過境量降20-40% / ≥3艘商船改道 / 伊朗「條件性通行」聲明
- **紅線**：過境量驟降>40%或集體停航 / 伊朗扣船封鎖 / 油輪遇襲 / WTI單日≥+8%且VIX跳升≥5
