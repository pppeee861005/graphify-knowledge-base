2️⃣ LangGraph（图状态编排）

适用场景：需要循环、分支、重试或人工批准步骤的工作流 Contabo
vs CrewAI：LangGraph = 状态机，CrewAI = 角色扮演团队

3️⃣ CrewAI（角色化 multi-agent）
将 multi-agent 工作定义为角色化的工作流，每个 Agent 有角色、目标、背景故事，0.105 版本（2026 年 3 月）增加企业可观测性和调度 Contabo
优势：最快原型化速度，直观的角色模型

4️⃣ Microsoft AutoGen / AG2（对话 Agent 团队）

5️⃣ LangChain + LangSmith（生态组合）
LangSmith 是框架无关的可观测性平台，提供追踪、评估和调试，无论基础应用使用 LangChain、LangGraph、OpenAI Agents SDK 还是自定义代码 Kunal Ganglani

最好的应用级 Agent 层，当用户需要共享状态、批准、前端工具和可见 Agent 体验在产品内时闪闪发光，最常与 Mastra 或 LangGraph 配对作为后端 Fungies

7️⃣ Mastra（TypeScript 专属框架）
