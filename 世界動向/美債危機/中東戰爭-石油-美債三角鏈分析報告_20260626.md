## 石油-通膨-美債的傳導機制

### **完整的4階段傳導過程**

#### **階段一：石油危機激活（2月28日-3月中）**

**事件驅動**：
- 2月28日：伊朗宣布全面封鎖霍木茲海峽
- 3月3日：海峽實質中斷，日運油量從2000萬桶→40萬桶（下降98%）

**市場反應**：
```
時間軸：
2月26日（戰爭前）：布倫特原油 70.79美元/桶
    ↓ (2天)
2月28日（宣布關閉）：原油開始飆升
    ↓ (3天)
3月3日（確認關閉）：布倫特原油突破 85美元/桶
    ↓
漲幅：+20%（從70.79→85）

市場恐慌指標：
• VIX（波動率指數）跳升
• 原油期貨波動率上升
• 海運成本急劇上升
• 石油公司股票飆漲
```

**全球供應鏈衝擊**：
```
石油短缺 → 化工產品短缺 → 所有商品成本上升
    ↓
航運、物流、生產成本上升
    ↓
全球供應鏈出現「斷點」
    ↓
企業邊際利潤下降
    ↓
經濟成長壓力上升
```

#### **階段二：通膨預期爆炸（3月-6月）**

**Fed的政策轉折**（2026年6月FOMC會議）：

```
通膨預測修正：
背景：3月份Fed預期通膨為2.7%（溫和水平）
現狀：6月份Fed預期通膨為3.6%（警報水平）
修正幅度：+0.9%（90個基點）

利率路徑修正：
背景：3月份計劃2026年底利率為3.4%
現狀：6月份計劃2026年底利率為3.8%
修正幅度：+0.4%（40個基點）

根本驅動：
1. 油價高企 → 輸入型通膨直接影響
2. 低油價但高通膨 → 說明經濟過熱
   （正常邏輯：油價↓ → 通膨↓；當前邏輯：油價↓ 但通膨↑）
3. 經濟學家發現：低油價反而增加「過熱經濟」的需求
   → 帶來更高而非更低的通膨

關鍵發現：
「油價與通膨脫鉤」現象意味著：
  • 通膨問題不只是供應側（油價），還有需求側（經濟過熱）
  • 單靠油價回落無法解決通膨
  • Fed必須大幅加息來冷卻經濟
```

**企業與消費者反應**：
```
企業端：
• 生產成本上升（原材料、物流）
• 銷售價格必須上升（轉嫁成本）
• 邊際利潤受壓（無法完全轉嫁）
• 招聘放緩（對未來不確定）

消費者端：
• 生活成本上升（食品、能源、交通）
• 購買力下降
• 消費決策延後
• 對經濟前景悲觀

結果：「滯脹」端倪（低增長+高通膨）
```

#### **階段三：美債實際收益率飆升（5月-6月）**

**名義利率 vs. 實際利率的區別**：

```
名義利率（Nominal Rate）：市場直接觀測的利率
  例如：10年期美債收益率 4.4%

實際利率（Real Rate）= 名義利率 - 通膨預期
  例如：名義利率 4.4% - 通膨預期 3.6% = 實際利率 0.8%

通膨飆升的威力：
  背景（3月）：名義利率 3.5% - 通膨 2.7% = 實際利率 0.8%
  現狀（6月）：名義利率 4.4% - 通膨 3.6% = 實際利率 0.8%

  看似一樣，但實際上：
  名義利率上升（3.5% → 4.4%）> 通膨上升（2.7% → 3.6%）

  這意味著：
  • 實際利率上升（0.8% → ?）的「正確計算」
  • 實際利率應該上升了（因為名義利率上升幅度更大）

  簡化理解：
  通膨預期從2.7%飆升至3.6%，意味著：
  • 每個通膨百分點對應的「實際收益」都在下降
  • 投資者的「實際購買力收益」在下降
  • 美債對投資者的真實吸引力在暴跌
```

**市場反應的深層邏輯**：

```
通膨預期↑ → 長期美債持有人「虧損」的預期↑
    ↓
長期美債需求↓
    ↓
要吸引新買家，必須提高收益率
    ↓
長期美債收益率↑
    ↓
這正是我們在6月看到的：
「名義利率上升超過通膨上升」
= 「實際利率上升」
= 「美債吸引力下降」
```

**2026年6月的具體數據**：

```
10年期美債收益率：4.4%（較前一交易日下降10個基點）
  └─ 但這只是短期回落，長期趨勢仍向上

PCE通膨預期：3.6%（遠高於3月的2.7%）
  └─ 每周、每月都有新數據推升預期

實際利率（估算）：已接近或突破1.0%
  └─ 這意味著美債的真實吸引力遠低於名義利率
```

典型表現：

2. 拍賣認購倍數跌破2.0x

  • 如果沒有政策干預，美債危機可能全面爆發
  • 或者政策干預（Fed停止縮表、負利率、政府干預等）

## 伊朗的終極籌碼分析

### **籌碼層次解析**

#### **第一層：地理籌碼（無法改變）**

```
不可替代性：
├─ 霍木茲海峽是中東石油的唯一出海口
├─ 全球20-30%石油供應依賴這一通道
├─ 替代方案極其有限
│  ├─ 沙特東西管道：日運500萬桶（只能替代25%）
│  ├─ 伊拉克管道：日運50萬桶（經過敘利亞，風險高）
│  └─ 總替代運力：最多700萬桶（遠不足以彌補缺口）
└─ 結論：無法在短期內完全繞過伊朗

時間維度：
├─ 短期（0-3個月）：無法繞過
├─ 中期（3-12個月）：部分替代（30-50%）
├─ 長期（1-3年）：可能建設新管道（成本極高）
└─ 現實：伊朗掌控未來12個月的全球能源命運

    ↓ (物價穩定)

```

    ↓ (增加運輸、化工、農業成本)

    ↓ (企業邊際利潤被壓)

    ↓ (物價上升，消費者購買力下降)

    ↓ (認購倍數從2.6倍 → 2.0倍以下)

    ↓ (持倉增加，風險上升)
回購市場流動性緊張
    ↓ (短期融資成本上升)

    ↓ (被迫拋售)
【美債危機爆發】
