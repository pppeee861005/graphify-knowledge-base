## 🎯 核心觀察指標

### **指標1：伊朗官方聲明強度**

#### A. 弱信號（協議可能生效）
```
聲明內容特徵：
✓ 措辭溫和（「譴責」「抗議」）
✓ 無軍事威脅詞彙
✓ 有條件接受協議
✓ 保留權利但無時間表

示例：「我們對美國失信感到失望，但將繼續觀察
      協議執行情況，保留後續權利。」

判斷：伊朗在等待協議執行，暫不升級
時間判斷：聲明發布後 >48小時才可能報復
```

#### B. 中等信號（升級報復啟動）
```
聲明內容特徵：
⚠️ 詞彙升級（「報復」「堅決回應」）
⚠️ 提及軍事準備（「軍事選項已就位」）
⚠️ 設定條件（「如果...將...」）
⚠️ 提及盟國配合（黎巴嫩、敘利亞）

示例：「美國協議已死，伊朗保留一切應對權利，
      軍事選項已準備就緒。」

判斷：伊朗準備升級，但尚未決定時間
時間判斷：聲明發布後 12-48小時內可能報復
```

#### C. 強信號（升級報復確認）
```
聲明內容特徵：
🔴 明確宣布報復（「我們已決定進行報復」）
🔴 具體時間點（「今晚」「24小時內」）
🔴 具體目標名稱（「特定以色列軍事設施」）
🔴 軍方發表聲明（IRGC、德黑蘭指揮部）

示例：「伊朗伊斯蘭革命衛隊命令部隊，
      在24小時內對以色列進行全面報復。」

判斷：升級報復已確認，進入倒計時
時間判斷：聲明發布後 4-24小時內必然發動
```

### **指標2：報復規模升級**

#### 規模評估表

| 升級等級 | 導彈數 | 無人機 | 打擊範圍 | 目標類型 | 對標事件 |
|---------|-------|-------|--------|---------|---------|
| **無升級** | 0 | 0 | — | — | 協議遵守中 |
| **低升級** | 0-5 | 0-10 | 邊界 | 邊防/軍營 | 零星還擊 |
| **中升級** | 5-20 | 10-30 | 邊界+內陸 | 軍事設施 | 6月10日水準 |
| **高升級** | 20-50 | 30-100 | 全以色列 | 軍事+民用 | 2倍於6月10日 |
| **極端升級** | 50+ | 100+ | 多國 | 戰略目標 | 全面戰爭 |

#### 具體判斷方法

**第1小時內確認報復規模**：

```
情報來源優先級：
1️⃣ 軍事觀察者實時報告（推特/新聞）
2️⃣ 以色列防空系統啟動報告
3️⃣ 中東媒體直播（Al Jazeera、BBC）
4️⃣ 官方軍事聲明

看什麼：
✓ 防空警報拉響的位置數量
✓ 報道「空襲波次」的次數（第1波、第2波...）
✓ 伊朗官方聲稱的打擊目標數量
✓ 報復持續時間（持續1小時 vs 5小時 vs 24小時）
```

**規模判斷快速決策樹**：

```
1. 防空警報持續 <30分鐘
   └─ 低升級（零星報復）

2. 防空警報持續 30分鐘-2小時，多地同時警報
   └─ 中升級（有組織報復）

3. 防空警報持續 2小時+，多波次報復
   └─ 高升級（重創打擊）

4. 防空警報持續 >4小時，戰爭直播進行中
   └─ 極端升級（全面戰爭）
```

### **看這5個要素，快速判斷升級程度**

```
1. 伊朗官方聲明
   ├─ 溫和辭令 → 低升級 🟢
   ├─ 軍事威脅 → 中升級 🟡
   └─ 明確宣布 → 高升級 🔴

   ├─ 1-2個地點 → 低升級 🟢
   ├─ 3-5個地點 → 中升級 🟡
   └─ 5個+ → 高升級 🔴

3. 報復波次
   ├─ 單波次(<1小時) → 低升級 🟢
   ├─ 多波次(1-2小時) → 中升級 🟡
   └─ 長期多波(>2小時) → 高升級 🔴

4. 美債反應時間
   ├─ >6小時觸發 → 低升級 🟢
   ├─ 1-6小時觸發 → 中升級 🟡
   └─ <1小時觸發 → 高升級 🔴

5. 打擊目標
   ├─ 邊界軍營 → 低升級 🟢
   ├─ 以色列軍事設施 → 中升級 🟡
   └─ 以色列城市+美軍基地 → 高升級 🔴

─────────────────────────────
結論判斷：
5個綠🟢 = 無升級
3-4個綠 = 低升級
2-3個黃 = 中升級
2-3個紅 = 高升級
全紅🔴🔴🔴 = 極端升級
```
