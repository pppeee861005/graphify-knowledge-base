## 💻 快速部署指南

### 1. 本地開發部署（5分鐘）

```bash
# 克隆倉庫
git clone https://github.com/pppeee861005/L1.5-Real-Time-State-Dashboard.git
cd L1.5-Real-Time-State-Dashboard

# 創建虛擬環境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安裝依賴
pip install -r requirements.txt

# 運行系統
python -m l1_5.server

# 訪問
http://localhost:8000
```

### 2. Docker部署（10分鐘）

```bash
# 構建鏡像
docker build -t l1-5-dashboard:latest .

# 運行容器
docker run -p 8000:8000 l1-5-dashboard:latest

# 或用docker-compose
docker-compose up -d
```

### 3. 雲端部署（AWS）

```bash
# 使用CloudFormation模板
aws cloudformation create-stack \
  --stack-name l1-5-dashboard \
  --template-body file://templates/aws-cfn.yaml

# 或用AWS CDK
cdk deploy
```

### 4. Kubernetes部署

```bash
# 應用Helm chart
helm repo add l1-5 https://charts.l1-5.io
helm install l1-5-dashboard l1-5/dashboard

# 或用kubectl
kubectl apply -f k8s/deployment.yaml
```

## 📊 核心應用場景

### 1. 地緣政治監測

```python
from l1_5.dashboard import RealtimeDashboard

# 創建配置
config = DashboardConfig()
config.add_signals([
    "us_debt_yield",      # 美債殖利率
    "oil_price",          # 石油期貨
    "vix_index",          # VIX恐慌指數
    "iran_rial",          # 伊朗里亞爾
    "military_activity"   # 軍事活動
])

# 啟動監測
dashboard = RealtimeDashboard(config)
dashboard.start_monitoring()

# 獲得實時狀態
state = dashboard.get_current_state()
```

### 2. 金融風險監測

```python
config = DashboardConfig()
config.add_signals([
    "stock_index",        # 股票指數
    "bond_yield",         # 債券收益率
    "currency_rate",      # 匯率
    "credit_spread",      # 信用利差
    "market_volatility"   # 市場波動
])

# 異常警報
config.add_alert_rule({
    "all_of": [
        {"stock_index": "<", -5},      # 下跌5%
        {"bond_yield": ">", 3.5},      # 收益率升高
        {"volatility": ">", 30}        # 波動升高
    ],
    "action": "critical_alert"
})
```

### 3. 供應鏈監測

```python
config = DashboardConfig()
config.add_signals([
    "supplier_status",    # 供應商狀態
    "logistics_delay",    # 物流延遲
    "inventory_level",    # 庫存水平
    "price_fluctuation",  # 價格波動
    "demand_forecast"     # 需求預測
])
```

### 4. 公共衛生監測

```python
config = DashboardConfig()
config.add_signals([
    "case_count",         # 病例數
    "death_rate",         # 死亡率
    "vaccination_rate",   # 接種率
    "hospital_occupancy", # 醫院佔用率
    "genetic_variant"     # 遺傳變異
])
```

### 集成示例

```python
# REST API
dashboard.add_data_source("rest", {
    "url": "https://api.example.com/data",
    "headers": {"Authorization": "Bearer token"},
    "interval": 3600
})

# Kafka
dashboard.add_data_source("kafka", {
    "broker": "localhost:9092",
    "topic": "market_data",
    "group_id": "l1-5-consumer"
})

# 數據庫
dashboard.add_data_source("database", {
    "type": "postgresql",
    "host": "localhost",
    "query": "SELECT * FROM signals WHERE timestamp > NOW() - INTERVAL '1 day'"
})
```
