## 📊 FB 社團 PM 6:00 引流的科學性

### 時間窗口分析

**讀者行為黃金時段**：
```
時間      行為特徵          活躍度    內容消費力
────────────────────────────────────────────
14:00   午餐後檢查        ⭐⭐      低（工作中）
17:00   下班前檢查        ⭐⭐⭐    中（準備離開）
18:00   下班回家          ⭐⭐⭐⭐⭐ 最高（放鬆狀態）
20:00   晚餐後閒瀏覽      ⭐⭐⭐⭐  次高（娛樂時段）
22:00   睡前檢查          ⭐⭐⭐    中（打卡模式）
```

**PM 6:00 的三大優勢**：

1. **時間心態最佳**
   - 用戶剛從工作中解脫，心理狀態放鬆
   - 願意花 5-10 分鐘深度閱讀（而非快速瀏覽）
   - 容易被新的「有趣內容」吸引

2. **社群活躍度最高**
   - Facebook 演算法顯示 PM 6:00-8:00 是每日最高峰
   - 社團成員上線人數最多（相比上班時段 ↑ 200-300%）
   - 貼文回覆率、分享率最高

3. **轉化路徑最短**
   - 用戶看到貼文 → 點擊 Substack → 訂閱
   - 中間沒有「等待」的時間差（即時轉化）
   - 相比上班時間「看到但不點」的行為差異大
