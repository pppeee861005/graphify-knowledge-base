# AI顧問團產品線計劃

**願景**：構建一個開源的、規則庫比對型的AI顧問團，覆蓋普通人一生中的8個高傷害決策場景，讓「顧問民主化」成為公共設施。

**版本**：v1.0
**制定日期**：2026-06-11
**計劃周期**：18個月（2026-06 ~ 2027-12）

---

## 一、產品線願景

### 1.1 核心問題

富人身邊有顧問圈：法律顧問、財務顧問、健康顧問……

普通人在每次重大決策時都是裸奔：簽租約沒人陪、看金融商品DM自己猜、被詐騙話術騙走養老金、教育資源被焦慮稅洗劫……

**現象**：資訊差 + 經驗差 = 可避免的貧困加劇

**機制**：一次決策錯誤（押金被坑、落入高利貸、誤信偽保健品）= 倒退數月到數年

### 1.2 AI顧問團的定義

**不是什麼**：
- ❌ 不是「AI取代人類顧問」
- ❌ 不是「24小時無限陪聊」
- ❌ 不是「預測市場 / 診斷疾病 / 做出最終決定」
- ❌ 不是營利產品（開源公共設施）

**是什麼**：
- ✅ 「高風險決策前的第一意見」
- ✅ 「資訊差拉平器」
- ✅ 「分流站而非終審法官」
- ✅ 「讓普通人帶著對的問題去找對的人」

### 1.3 8個席位的邏輯

**選擇標準**：普通人一生中會遇到、做錯一次會倒退幾年的決策場景

**排序原則**：傷害程度 × 發生頻率

| 席位 | 場景 | 傷害型 | 頻率 | 優先級 |
|------|------|--------|------|--------|
| 1️⃣ **合約顧問** | 租約、勞動契約、買賣合約、保單、貸款、定型化契約 | 即時 | 高頻 | 🔴 P0（已啟動：計劃13租約哨兵） |
| 2️⃣ **行政官僚顧問** | 補助申請、稅務申報、勞保健保、育兒津貼、失業給付 | 隱形損失 | 關鍵節點 | 🔴 P0（規劃中） |
| 3️⃣ **財務顧問** | 貸款利率、保單複雜度、金融商品話術、複利陷阱 | 資產流失 | 中頻 | 🟡 P1 |
| 4️⃣ **大宗購買顧問** | 買房、買車、裝修、婚喪儀式 | 資產流失 | 低頻但高額 | 🟡 P1 |
| 5️⃣ **健康顧問** | 症狀整理、醫囑翻譯、疫苗時程、用藥查核 | 健康與生命 | 全人生 | 🟡 P1 |
| 6️⃣ **職涯顧問** | 履歷面試、市場行情、offer分析、產業預警 | 經濟與心理 | 中頻 | 🟢 P2 |
| 7️⃣ **教育顧問** | 升學制度、補習判斷、資源鑑別、代際傳遞打破 | 代際傳遞 | 集中期 | 🟢 P2 |
| 8️⃣ **資訊心理顧問** | 訊息查證、詐騙識別、情緒決策干預、慢三秒 | 元層面 | 日常 | 🟢 P2（守門人） |

## 二、設計統一標準

### 2.1 所有席位共用的三大鐵律

| 鐵律 | 含義 | 代碼層落地 |
|------|------|-----------|
| **寧可漏報轉介，不可錯報安心** | 若無法判斷就轉介人類，絕不自信地給錯誤結論 | 每條判斷都強制要求「引用官方規範」或「引用常見陷阱」 |
| **信心不足 → 轉介人類** | 信心評分 <70% 自動升級給專業人士 | 轉介話術內置、聯絡方式真實存在、可驗證 |
| **分流站，不是終審法官** | 永遠不替用戶做決定，永遠是「簽之前確認這三點」 | 輸出禁止結論性語句（「可以簽」「不要簽」），只說「有這些差距」 |

### 2.2 統一的工作流程框架

所有8個席位都採用「規則庫比對型Dynamic Workflow」：

```
[用戶輸入] 合約 / 補助資訊 / 金融商品 / 病歷摘要…
   ↓
[Stage 1] 信息提取與結構化
   ↓
[Stage 2] 場景識別與分類
   ↓
[Stage 3] 規則庫比對（規則引擎優先，LLM補充）
   ↓
[Stage 4] 風險解釋與雙引用生成
   ↓
[Stage 5] 信心評分與轉介決策
   ↓
[輸出] 三段式報告（⚠️ 有風險 / ✅ 正常 / 📍 轉介）
```

### 2.3 統一的規則庫來源原則

**核心要求**：
- 必須來自「政府公開發布」或「法律明確規定」的文件
- 必須標注「版本」和「抓取日期」
- 必須定期（每季）與官方來源比對更新

**各席的規則庫來源**：

| 席位 | 規則庫來源 | 權威性 | 更新頻率 |
|------|-----------|--------|---------|
| 1. 合約顧問 | 內政部、勞委會、金管會發布的定型化契約應記載項 | ⭐⭐⭐⭐⭐ 法律 | 每年 |
| 2. 行政官僚 | 政府補助資料庫、國稅局、勞保局公開資訊 | ⭐⭐⭐⭐⭐ 法律 | 每年（補助額度每期） |
| 3. 財務顧問 | 金管局消費者保護資訊、央行最新利率、保險法規 | ⭐⭐⭐⭐ 法律 | 即時 |
| 4. 大宗購買 | 消費者保護法、房屋交易慣例、市場參考價 | ⭐⭐⭐ 法律+數據 | 月度 |
| 5. 健康顧問 | 衛福部、世界衛生組織、台灣藥物給付標準 | ⭐⭐⭐⭐ 專業 | 周度 |
| 6. 職涯顧問 | 勞動統計、產業報告、offer陷阱實例庫 | ⭐⭐⭐ 數據+經驗 | 月度 |
| 7. 教育顧問 | 教育制度法規、升學考試標準、補習實踐資料庫 | ⭐⭐⭐ 法律+經驗 | 學期度 |
| 8. 資訊心理 | 詐騙話術資料庫、事實查核平台、心理學基礎 | ⭐⭐ 經驗+研究 | 周度 |

### 2.4 統一的轉介資源標準

每個席位都必須內置「何時升級給人類」的明確機制和真實聯絡方式：

| 席位 | 轉介觸發 | 轉介對象 | 聯絡方式 |
|------|---------|---------|---------|
| 1. 合約顧問 | 進入糾紛/調解/訴訟 | 律師 / 法律扶助基金會 | 真實電話+網址 |
| 2. 行政官僚 | 被駁回申請 / 複雜稅務情況 | 各地勞工局 / 國稅局 / 里長 | 真實電話+網址 |
| 3. 財務顧問 | 大額資產配置 / 稅務規劃 | 持照財務顧問（時計費）| 搜尋工具+篩選建議 |
| 4. 大宗購買 | 產權爭議 / 隱瞞缺陷 | 房屋檢驗師 / 律師 | 真實電話+網址 |
| 5. 健康顧問 | 有任何疑慮 | 掛號醫生 | 導航邏輯（掛科選擇） |
| 6. 職涯顧問 | 產業判斷不確定 / 離職決定 | 產業顧問 / 人力銀行 | 真實資源列表 |
| 7. 教育顧問 | 升學焦慮 / 非典型需求 | 教育諮詢師 / 輔導老師 | 學校資源+外部機構 |
| 8. 資訊心理 | 真正的心理困擾 / 重症詐騙跡象 | 心理醫生 / 警察 / 心理諮商 | 真實聯絡+緊急熱線 |

## 五、風險登記簿與應對

| 風險 | 等級 | 觸發條件 | 應對方案 |
|------|------|---------|---------|
| **規則庫更新滯後** | 🔴 致命 | 政府改法規但系統未更新 | 建立「規則庫版本控制」+ 季度對標 + 用戶舉報機制 |
| **被誤解為「法律意見」** | 🔴 致命 | 用戶訴訟時引用系統輸出 | 三大鐵律 + 每次輸出都有免責聲明 + 定期法律審查 |
| **轉介資源無法接納** | 🟠 高 | 某地律師協會拒絕接手 | 與轉介機構簽合作協議 + 分層轉介（多個備選） |
| **規則比對邏輯過度簡化** | 🟠 高 | 合約出現超出規則庫的變體 | 規則庫留「灰色地帶」+ 低信心自動轉介 |
| **用戶過度依賴AI** | 🟠 高 | 用戶不再自己思考 | 每個輸出都以「問題」結尾 + 教育內容引導 |
| **資料隱私洩露** | 🟠 高 | 用戶合約/隱私被外洩 | 閱後即焚 + 本地運算 + 隱私政策透明 |
| **某席位規則庫難以構建** | 🟡 中 | 健康/教育顧問的灰色地帶太多 | 提高信心閾值→更多轉介 + 與專家協作 |
| **開源貢獻者不足** | 🟡 中 | Phase 2時Fork沒有增長 | 撰寫詳細教科書 + 與社群合作 + 獎勵機制 |
| **某國家本地化失敗** | 🟡 中 | 規則庫無法對應當地法規 | 選擇簡單國家優先（法規差異小） + 找當地合作者 |
| **資金與人力不足** | 🟡 中 | 開發延期 | 優先級：哨兵 > 補助 > 其他 / 砍非核心功能 |

## 八、與新人類聯盟的戰略連接

### 8.1 「新人類」定位

此AI顧問團項目是「新人類聯盟」的核心産品線體現：

- **「人類共好」**：不是AI替代人，而是「人+AI」拉平資訊差
- **「決策權不讓渡」**：用戶永遠是決策者，AI是提供判斷材料的工具
