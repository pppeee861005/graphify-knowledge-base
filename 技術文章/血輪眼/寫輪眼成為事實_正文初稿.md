# 寫輪眼成為事實

**副標題**：AI 已經能「看一次就會」，你準備好了嗎？

---

## 開場

如果你看過《火影忍者》，你一定知道寫輪眼。

看一次，就會。別人練了十年的忍術，宇智波家的人只要開眼看一遍，轉身就能完美復制。

這是作弊嗎？是。這公平嗎？不公平。但這是事實。

而今天，AI 已經有了這個能力。

---

## 痛點共鳴

過去，你想複製高手的工作流程，怎麼辦？

看影片、讀文章、記筆記、反復練習。花三個月，可能還學不到精髓。

因為「看到」和「做到」之間，隔著一道深淵。

---

## 轉折承諾

但現在，AI 正在填平這道深淵。

Codex 的錄制功能 + Computer Use 能力，讓 AI 不只能「看見」你的操作，還能「理解」為什麼，然後「復制執行」。

這不是兩個獨立的技術，而是一個完整的「寫輪眼」系統。

---

## 核心對比：寫輪眼的映射

讓我們先看看這個對比。

火影忍者的寫輪眼有什麼能力？
- **看見**：能夠洞察對手的動作、技術、邏輪邏輯
- **理解**：自動推理出「為什麼這樣做」
- **復制**：看過一次就能完美復制對方的忍術

AI 的「寫輪眼」呢？

**能力 1：錄制功能（Codex 的新插件）**
- Codex 新增的錄制功能可以記錄用戶的滑鼠、鍵盤操作序列
- AI 自動推理：「這個人為什麼這樣操作？邏輯是什麼？」
- 理解後，將結果固化為可復用的 Skill

這就是寫輪眼的「看見」。

**能力 2：Computer Use（AI 的執行力）**
- 這是 AI 另一個獨立的強大能力：直接操作電腦的任何應用
- 可以進行複雜的多步驟操作，無需人類干預
- 比人類更穩定、更精準、永遠不會疲倦

這就是寫輪眼的「復制術」。

當這兩個能力組合在一起，我們就得到了完整的「寫輪眼」。

---

## 為什麼這很重要？

**第一層原因**：它讓學習變得即時。不用三個月，不用反復練習。看一次，理解一次，執行一次。

**第二層原因**：具體怎麼做到的？錄制功能捕捉你的每一個操作——滑鼠點了哪裡、鍵盤輸入了什麼、操作的順序和邏輯。然後 AI 推理：「這個人為什麼這樣做？」理解後，用 Computer Use 執行：打開應用、輸入指令、完成任務。關鍵是，AI 不是死記硬背，而是理解邏輯後靈活執行。

**第三層原因**：這意味著什麼？這意味著「能力」不再是不可傳遞的私有財產。

過去，天才的工作流只存在於他的大腦裡。你可以模仿，但很難複製精髓。

現在，AI 可以：
- 看見天才的操作
- 理解背後的邏輯
- 固化為可分享的 Skill
- 讓任何人都能使用

這是「能力民主化」的開始。

---

## 現實中的例子

讓我舉兩個具體的例子。

**例子 1：AI 自動創建並發布影片**

想像這個場景：
1. Codex 打開 Gemini 介面
2. 輸入影片生成指令
3. 等待生成完成並下載
4. 打開社交媒體平台
5. 上傳影片、撰寫文案
6. 設定發布時間並發布

這整個流程原本需要人類做「決策與銜接」。現在 AI 可以完整接管。一個強大的 AI Agent，可以協同另一個強大的 AI，完成多步驟的複雜工作流。

**例子 2：AI 自動進行深度研究**

更複雜的例子：
1. Codex 啟動 Claude Code
2. 輸入研究主題
3. 執行 Deep Search
4. 獲取研究結果
5. 分析搜索結果
6. 提煉核心洞察
7. 生成報告

在這個例子中，Codex 不只是執行，而是「調度」其他 AI Agent。一個 AI 可以協同另一個 AI，完成原本需要人類大量判斷的工作流。

這暗示了一種新的能力層級結構：人類在頂端做指揮，Codex 在中間調度，其他 AI 在底層執行。

## 深層意義

現在我們到了更有趣的部分。

**意義 1：一個人可以變成千千萬萬個我**

火影忍者中有一個術叫「影分身之術」。每個分身都有完整的你的能力，分身可以並行工作，經驗可以回傳本體。

AI 讓這個隱喻變成現實。

你的工作流被 AI 錄制，固化為 Skill，然後無限復制執行。你睡覺時，你的「分身」在工作。24/7 的持續運行不再是科幻，而是現實。

當你可以有無限個「自己」在工作，什麼是真正的「你」？

**意義 2：天才的工作流可以被標準化**

過去，天賦是不可傳遞的。頂級設計師的審美只存在於他的大腦裡。你只能模仿，無法複製。

現在，AI 可以錄制天才的操作，理解背後的邏輯，固化為 Skill，讓團隊所有成員都能使用。

結果是什麼？不再靠個人英雄，靠系統複製。團隊的短板可以通過 Skill 補足。

**意義 3：能力正在走向可交易化**

| 時間軸 | 狀態 | 描述 |
|--------|------|------|
| **今天** | Skill 內部復用 | 工作流被固化，可在團隊內復用 |
| **明天** | Skill 可交易 | Skill 可以被交易、授權、購買 |
| **後天** | 能力市場化 | 凡人通過「購買天才 Skill」達成自我提升 |
| **終局** | 能力民主化 | 能力鴻溝開始縮小 |

未來，天才的能力是可以被複製、交易的。凡人的能力得到前所未有的提升。

## 假設與反思

如果 Agent 能無限複製，如果 Agent 能協同執行，如果 Agent 能自我優化，會發生什麼？

可能的場景：計算速度與決策速度的指數增長。人類需要數小時的決策，AI 可能只需數秒。跨領域知識的實時整合——一個 Agent 可以同時調用醫學、法律、工程的知識。24/7 無間斷的執行——人類需要休息，AI 不需要。

關鍵問題是：當 AI 的能力超越人類極限，人類的角色是什麼？

我不會給你答案。但值得思考：
- 你現在的工作流是什麼？
- 哪些步驟可以被 Agent 化、Skill 化、複製化？
- 哪些步驟是你的核心競爭力？
- 你是「執行者」還是「設計者」？
- 你的價值在「做事」還是「定義要做什麼事」？

可能的方向：精進自己的核心工作流，學習頂級高手的工作方式，成為「工作流系統設計師」。

## 技術層面的理解

用技術語言，寫輪眼的能力可以這樣描述：

```
1️⃣ 錄制層（Input）
   「看見」用戶操作（滑鼠、鍵盤）
        ↓
2️⃣ 理解層（Processing）
   AI 推理操作的邏輯、目的、規則
        ↓
3️⃣ Computer Use 層（Execution）
   AI 直接操作電腦，復制或優化流程
        ↓
4️⃣ 固化層（Encoding）
   將學習結果固化為可復用的 Skill
```

一個 Skill 的完整生命週期是：創建 → 固化 → 復用 → 分享 → 商業化。

當我們有了這個能力棧，未來是什麼樣的？

想像 Claude Code 的蜂群網絡：協同數百個 Agents，每個 Agent 配備不同能力的 Skill，通過 API 與通信協議連接，統一的指揮調度系統。

這不是單個 AI 的增強，而是一個能支撑組織級別的智能系統。
