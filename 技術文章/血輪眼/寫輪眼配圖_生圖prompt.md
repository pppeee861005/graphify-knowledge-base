## 💡 如何使用

### 使用 Kling AI
```
1. 進入 Kling Video/Image 生成
2. 選擇「文字描述生成」
3. 複製上面的「中文版 Prompt」
4. 設定參數：
   - 風格：Cyberpunk / 科幻
   - 質量：超高清 (8K)
   - 比例：9:16 （直出發文用） 或 16:9 （文章配圖用）
5. 生成！
```

### 使用 Midjourney
```
1. Discord 輸入：/imagine
2. 複製英文版 Prompt
3. 調整比例：--ar 9:16 (直出) 或 --ar 16:9
4. 加入質量參數：--quality 2 (最高質量)
5. 等待生成
```

### 使用 DALL-E 3
```
1. ChatGPT 或 DALL-E 網站
2. 複製英文版 Prompt
3. 設定尺寸：1024x1024 或 1024x1792
4. 生成
```

## 🎬 Prompt 微調建議

如果生圖效果不滿意，試試這些調整：

### 如果眼睛不夠亮：
```
加入：+ extremely bright glowing red eyes with intense luminance
+ 極其明亮發光的紅眼，強烈的亮度
```

### 如果想要更多賽博龐克細節：
```
加入：+ circuit patterns on face / 臉上的電路圖案
+ glowing wire beneath skin / 皮膚下的發光電線
+ holographic HUD overlay / 全息 HUD 疊加
```

### 如果想要更接近忍者：
```
加入：+ wearing traditional ninja mask / 戴著傳統忍者面罩
+ carrying futuristic katana / 持著未來武士刀
+ dynamic action pose / 動態動作姿態
```

### 如果想要單純的頭像（用於文章頂部）：
```
改為：+ portrait / headshot / close-up of face
+ 肖像 / 頭像 / 臉部特寫
移除：background elements / 背景元素
```
