## 💡 反思與收穫

### 工作流程的演進
```
嘗試 1：SVG → cairosvg → PNG ❌（依賴問題）
嘗試 2：SVG → ImageMagick → GIF ❌（編碼問題）
嘗試 3：SVG → Puppeteer → PNG ❌（下載超時）
最終：SVG → Kling AI API → PNG ✅
    + SVG → Selenium → GIF ✅
```

### 技術決策的關鍵點
1. **穩定性優先**：選擇成熟方案而非新興工具
2. **跨平台考量**：Windows特定問題需要更高級別的抽象
3. **成本收益**：API調用成本換取開發時間節省是值得的
4. **可複用性**：編寫通用腳本為未來工作降低成本
