## 🎯 核心決策

### 決策 1：融入 Agent 系列而非開新系列

**E04 內容**：
- 融入 Agent 系列（而非 HumanInTheLoop）
- 邏輯：E01-E03 蜂群理論 → E04 Workflow 實踐

**理由**：
- ✅ 受眾重疊（開發者 + 架構師）
- ✅ 自然延續（理論 → 實踐）
- ✅ 避免系列過多

### 決策 2：計劃 5 獨立於計劃 1

**原因**：
- 計劃 1 v1.0：MVP / 技術驗證（已完成）
- 計劃 5：企業級 / 生產系統（3 個月開發）
- 兩者是升級關係，但資源投入、目標受眾完全不同

**結構**：
```
計劃 1 v1.0（已完成）
└─ GitHub: gws-hr-automation v1.0

計劃 5（開發中）
└─ GitHub: gws-hr-automation v2.0
```

### 決策 3：v2.0 代碼在計劃 1 目錄下

**原因**：
- 保持 Git 倉庫的連貫性
- v1 和 v2 是同一個項目的版本迭代
- 計劃 5 是「規劃」，`newworld-hr-system-v2/` 是「實現」

### 1. Workflow 是 Agent 工程成熟的標誌
```

Workflow 工程（定義流程）← 企業級應用的門檻

```

```
未來：企業 HR = Workflow 範本庫

```
