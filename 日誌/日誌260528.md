### 工作流程 1：《三維獵殺》詳細劇情大綱

**檔案**：`SWARM_S01E02_三維獵殺_詳細大綱.md`

**核心概念**：
```
三維獵殺 = 三個分析師同時出手，只有全票通過才能扣下扳機

維度 1：基本面分析師 — 這家公司值不值錢？
維度 2：技術面分析師 — 現在是不是好時機？
維度 3：籌碼面分析師 — 誰在買？誰在賣？
```

**劇情結構**：

| 元素 | 內容 |
|------|------|
| **開場** | 群組瘋傳「技術面完美」的股票 |
| **痛點** | 三次被單維度騙局收割的經歷 |
| **暗示** | 「市場裡有一種獵人，專門狩獵單維度投資者」 |
| **轉折** | 召喚三維獵殺系統 |
| **高潮** | 47 分評分 →「回避」；84 分評分 → 三週漲 38% |
| **結尾** | 「從今天起，沒有三維印證，我不出手。」 |

**技術架構**：
- Sonnet×3 並行：基本面、技術面、籌碼面分析師
- Opus Lead 統一評分：0-100 分
- 決策門檻：≥80 買入 / 60-79 觀望 / <60 回避

### 關鍵發現 1：任務流程標準化

**今日工作模式**：
```
任務確認 → 建立清單 → 逐項執行 → 完成標記
```

**效果**：
- 5 個任務在 1 小時內全部完成
- 無遺漏、無返工
- 用戶確認後才執行，避免誤解

### 關鍵發現 2：依規範行事

**原則**：
- 不猜測命名規則，先找到 `文章命名規範_標準化系統.md`
- 使用 `git mv` 保留歷史記錄
- 新增系列簡碼（SWARM、CCWF）遵循現有格式

**效果**：
- 檔案結構清晰一致
- 未來可擴展性強

### 關鍵發現 3：多元產出能力

**今日輸出類型**：
- 劇情大綱（文字創作）
- 檔案重命名（系統整理）
- Kling 配圖（AI 圖像生成）
- SVG 設計（程式化繪圖）

**意義**：
- 單次會話可完成完整的「內容 + 視覺」產出
- Kling + SVG 互補：賽博朋克風格 vs Claude 簡潔風格

### 關鍵發現 4：戰地筆記風格轉換（深夜會話）

**原始需求**：「幫我以指揮官口吻書寫。有實戰感覺。像在戰地臨時記錄。」

**轉換技巧**：
- 開頭急迫：「剛完成首次蜂群部署。記下來，免得忘。」
- 短句直擊：「這是軍團級能力。」
- 口語化：「別跳過」「不然燒光」
- 未完成感：「結果：成功。細節待補。」
- 待辦清單：真實戰地筆記會有的未完事項

**效果**：
- 讀者能感受到緊迫感和真實性
- 適合作為教學內容的「實戰指南」風格

### 關鍵發現 5：Kling AI 批量生成效率

**本次實測**：
- 1 條指令生成 3 張寫實風格圖片
- 總耗時約 30 秒
- 風格一致性高

**最佳實踐**：
- 使用 `--n 3` 參數批量生成
- 提示詞包含具體細節（彈孔、燒焦、手寫筆跡）
- 加入風格關鍵詞（photorealistic, cinematic lighting）
