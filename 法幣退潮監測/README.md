# 法幣退潮監測 — 情報管理系統

**項目簡述**：基於「法幣退潮、金銀回歸貨幣本位」的世界觀，建立可證偽的情報監測系統。

**核心架構**：
- **L3 每日監測**（Workflow 自動化）：每日自動收集五層信號數據，時效性檢查，異常預警
- **L2 月度報告**（Agent Teams）：月末由 5 個班組並行交叉驗證，主控統一彙整，生成深度分析報告
- **Graphify 集成**：知識圖譜語義查詢，長期趨勢分析

---

## 🎯 核心理念

此項目的目標不是「預測未來」，而是建立**可證偽的觀測框架**：

1. **信號強度分層**：將「法幣退潮」分解為五個層級的觀測指標
2. **明確證偽條件**：為每層信號設定具體的「反證條件」
3. **時間窗口紀律**：設定清晰的驗證周期（24個月）
4. **誠實記錄**：當前證據集中在第一到三層，第四五層基本為零

> 若你的假說為真，這些跡象必須按時間順序逐層浮現。
> 若逾期未出現，那就只是又一輪貴金屬牛市，不是貨幣體系的轉變。

---

## 📊 五層信號監測框架

### 第一層：價格層面的脫鉤（最弱信號）

觀測金銀價格與美元指數(DXY)的相關性是否斷裂。

**觀測指標**：黃金/白銀 vs 美元指數相關性變化
**數據來源**：Alpha Vantage、Metals-API
**證偽條件**：相關性未斷裂（維持負相關）
**當前狀態**：⏳ 待觀測（建立中）

---

### 第二層：金銀比的結構性收斂（中等強度）

白銀相對黃金系統性升值，反映市場重新賦予白銀貨幣溢價。

**觀測指標**：Gold-Silver Ratio 趨勢
**目標驗證**：24個月內跌破並穩定在 **40 以下**
**證偽條件**：反彈回 **80 以上**
**當前狀態**：⏳ 待觀測（建立基線中）

---

### 第三層：實物與紙面的撕裂（強信號）

直接暴露「信用凭证 vs 實物本體」的矛盾——正是貨幣轉變的核心。

**觀測指標**：
- COMEX/LBMA 庫存持續下降
- 實物白銀溢價擴大（vs 期貨/ETF）
- 交割違約或提貨困難事件

**證偽條件**：庫存回升、溢價消失、無違約事件
**當前狀態**：⏳ 待觀測（重點追蹤）

---

### 第四層：官方計價單位的轉變（最硬信號，目前接近零）

白銀重新成為計價尺度（東西用白銀標價，而不是白銀用法幣標價）。

**觀測指標**：
- 某國發行白銀計價的主權債券
- BRICS 結算單位納入白銀錨定
- 貿易合同以白銀重量計價

**證偽條件**：24個月內此層信號始終為零
**當前狀態**：❌ 基本為零（誠實記錄）

---

### 第五層：制度與法律層面（終極確認）

法律地位變化：取消金銀交易的資本利得稅、恢復法定貨幣地位、允許以金銀繳稅。

**觀測指標**：聯邦/主權層面的法律制度變化
**證偽條件**：長期未出現制度變化
**當前狀態**：❌ 聯邦/主權層面不存在

## 🚀 工作流與層級架構

### L1：快速驗證（手動查詢）

當用戶問「當前金銀比是多少？」時，快速響應。

**使用情景**：快速查詢、實時反應

---

### L3：每日監測（自動化 Workflow）

每日早上 8:00 自動觸發，執行：
1. 查詢五層信號的實時數據（API 調用）
2. 驗證數據時效性（24小時內）
3. 檢測異常（價格突變、庫存驟降、政策變化）
4. 生成 `每日數據_YYYYMMDD.md`（記錄）

**成本**：~5,000 tokens/天（使用 Haiku 模型查詢層）

---

### L2：月度報告（Agent Teams 協作）

月末由 5 個班組並行工作，主控統一交叉驗證、彙整：

**班組1（數據源審查）**：檢驗 API 數據可信度 → 回報主控

**班組2（現實核實）**：執行實時查詢，收集當前數據 → 回報主控

**班組3（時效性檢查）**：驗證數據新鮮度 → 回報主控

**班組4（信號關聯分析）**：對標五層信號，識別跨層相關性 → 回報主控

**班組5（趨勢預警）**：識別 30-60 天風險信號 → 回報主控

**主控職責**：收齊班組回報 → 統一交叉驗證 → 仲裁分歧 → 生成月度報告

**產出**：
- `月度監測報告_YYYYMM.md`（深度分析）
- `五層信號儀表盤_YYYYMM.md`（可視化）
- `證偽條件檢查_YYYYMM.md`（關鍵判斷）

**成本**：~235,000 tokens/月（實測錨點，使用混合模型：Haiku 查詢層 + Sonnet 分析層 + Opus 仲裁層）

---

### Graphify 集成

每月月度報告完成後：
1. 導入數據至 Graphify：`graphify add 法幣退潮監測/`
2. 生成知識圖譜：`graphify update 法幣退潮監測/`
3. 語義查詢測試：`graphify query "第三層信號"`

**目標**：識別跨月信號的關聯性、發現隱蔽趨勢

## 💡 方法論亮點

1. **可證偽性優先**：每層信號有明確的「反證條件」，不是預言而是假說
2. **信號強度分層**：不混淆「避險情緒」（一二層）與「貨幣體系轉變」（四五層）
3. **自動化 + 深度分析結合**：L3 日常監測低成本，L2 月度報告高質量
4. **主控統一交叉驗證**：不是獨立層層分析，而是主控收齊後對齐結論
5. **長期紀律**：24個月時間窗口，到期時誠實做結論（成立或證偽）
