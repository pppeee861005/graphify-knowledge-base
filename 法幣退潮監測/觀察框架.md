# 五層信號監測框架 — 詳細觀察指南

**框架設計理念**：將「法幣退潮」從模糊的世界觀轉化為具體、可觀測、可證偽的分層信號系統。

> 越往下的層級，信號越硬、越難被替代解釋取代。
> 因此，信號分佈本身就是對假說可信度的實時評估。

---

## 📊 四層適配矩陣

| 層級 | 信號類型 | 觀測難度 | 信號強度 | 當前狀態 | 預期浮現時間 |
|------|---------|---------|---------|---------|-------------|
| **一層** | 價格脫鉤 | ⭐ 簡單 | 🟡 弱（易被替代解釋） | ⏳ 建立中 | 已有部分跡象 |
| **二層** | 金銀比收斂 | ⭐⭐ 中等 | 🟠 中（較硬） | ⏳ 建立中 | 6-12個月內 |
| **三層** | 實物撕裂 | ⭐⭐⭐ 較難 | 🔴 強（難被替代） | ⏳ 重點追蹤 | 12-24個月內 |
| **四層** | 官方計價 | ⭐⭐⭐⭐ 很難 | 🔴🔴 最硬 | ❌ 為零 | 24-36個月內 |
| **五層** | 制度法律 | ⭐⭐⭐⭐ 很難 | 🔴🔴 最硬 | ❌ 為零 | 36+ 個月 |

## 第一層：價格層面的脫鉤

**核心觀察**：黃金/白銀價格與美元指數(DXY)的歷史相關性斷裂。

### 基礎理論

在正常的法幣框架下：
- **美元強 → 金銀弱**（負相關）
  - 理由：強美元代表美元信用穩健，對避險資產的需求下降
- **美元弱 → 金銀強**（負相關）
  - 理由：弱美元代表美元信用衰退，投資者轉向避險資產

### 脫鉤信號

若「法幣退潮」為真，你應該觀察到：
- **金銀和美元同時走強**
  - 含義：市場不再把美元當作金銀的對立面，而是把兩者都當避險標的、共同對抗「法幣體系本身」
  - 這意味著：從「相對風險厭惡」（美元 vs 金銀 的選擇）轉變為「絕對風險厭惡」（法幣 vs 實物 的轉換）

### 具體觀測指標

#### 指標 A：美元指數(DXY) vs 黃金價格相關係數

**計算方法**：
```
相關係數 = cov(DXY, Gold) / (σ_DXY × σ_Gold)
```

**觀測窗口**：30天滾動相關係數

**數據來源**：
- 美元指數(DXY)：Alpha Vantage / FRED API
- 黃金價格(Gold)：Metals-API / Quandl

**基線建立**：
```
歷史正常相關係數範圍：-0.6 ~ -0.8（負相關）
脫鉤信號：相關係數上升至 -0.2 以上（相關性明顯減弱）
反轉信號：相關係數轉正（金銀和美元同時上升）
```

---

#### 指標 B：美元指數與黃金同向日數比例

**計算方法**：
```
同向比例 = (DXY 上升且 Gold 上升 的日數) / 總交易日數
```

**觀測窗口**：90天滾動

**數據來源**：日線數據（Alpha Vantage）

**基線建立**：
```
歷史正常同向比例：5-15%（極少數同時上升）
脫鉤信號：比例持續上升至 30-40%
強脫鉤信號：比例穩定在 40% 以上
```

**當前記錄**：[ ] 待建立基線

---

### 證偽條件

**何時判定此層信號「破裂」**：
- 相關係數回到 -0.6 以下（恢復歷史負相關）
- 同向比例跌回 15% 以下（恢復獨立性）
- **持續時間**：若脫鉤信號出現後，又倒回 6 個月無改善 → 判定為「短期波動」，非系統性脫鉤

---

### 為什麼這層最弱

- **易被替代解釋**：脫鉤可能由「避險情緒升級」導致，而非貨幣地位轉變
- **可逆性強**：一旦美元恢復信心或地緣政治緩和，脫鉤就會消失
- **必要條件非充分條件**：是「法幣退潮」的前兆，但不是確鑿證據

---

## 第二層：金銀比的結構性收斂

**核心觀察**：Gold-Silver Ratio（金銀比）從歷史的 70-90 區間持續向下突破並穩定在低位。

### 基礎理論

**金銀比的歷史**：
```
中世紀金銀比例（官方貨幣制）：1:12 ~ 1:15
19世紀金本位時期：1:15 ~ 1:16
20世紀金銀脫鉤後：1:50 ~ 1:100（白銀貶為工業金屬）
```

### 為什麼金銀比意義重大

若白銀只是「工業金屬」：
- 它的價格由**工業需求**驅動（太陽能、電子產品）
- **應該獨立於黃金波動**，甚至與黃金反向（黃金避險時 vs 白銀工業衰退）

若白銀被**重新賦予貨幣溢價**：
- 它的價格由**貨幣屬性**驅動（與黃金共振）
- **金銀比會系統性下降**（向古典貨幣比例靠拢）

### 具體觀測指標

#### 指標 A：Gold-Silver Ratio 絕對值

**計算方法**：
```
GSR = 黃金價格($/oz) / 白銀價格($/oz)
```

**觀測窗口**：月度平均值、年度趨勢

**數據來源**：
- Metals-API（實時報價）
- FRED API（歷史數據）

**目標驗證**：
```
初期目標（12個月內）：GSR 跌破 60
中期目標（24個月內）：GSR 跌破並穩定在 40 以下
長期目標（36個月內）：GSR 趨向 15-20（古典貨幣比例）
```

**當前基線**：[ ] 待記錄（建立項目時的 GSR 數值）

---

#### 指標 B：Gold-Silver Ratio 長期趨勢

**計算方法**：
```
30個月移動平均線
長期趨勢斜率 = (最近1個月平均值 - 30個月前平均值) / 30
```

**解釋**：
```
斜率 < -1.0：強下降趨勢 → 白銀相對升值 ✅ 強信號
斜率 -0.5 ~ -1.0：中等下降趨勢
斜率 -0.2 ~ -0.5：弱下降趨勢 → 信號模糊
斜率 > 0：反向或平穩 → 信號破裂 ❌
```

**當前記錄**：[ ] 待建立

---

### 證偽條件

**何時判定此層信號「破裂」**：

1. **24個月內 GSR 反彈回 80 以上**
   - 含義：白銀重新被市場定價為純工業品
   - 判定：論證被削弱

2. **長期趨勢斜率轉正（> 0）且持續 3 個月**
   - 含義：不再有系統性的下降趨勢
   - 判定：收斂已結束，無長期支撐

3. **脫鉤指標同時消失**（第一層信號也破裂）
   - 含義：三層信號同時反向，基本確認為「短期市場情緒波動」
   - 判定：整個假說進入「驗證失敗」狀態

---

### 為什麼這層比第一層強

- **難以被替代解釋**：金銀比反映的是相對定價邏輯，不只是絕對價格
- **可追蹤周期長**：24個月足以區分「短期波動」與「結構性轉變」
- **有明確的數值錨點**：古典貨幣比例 1:15 提供了理論支撐

---

## 第三層：實物與紙面的撕裂

**核心觀察**：實物白銀溢價持續擴大、紙銀(期貨/ETF)與實物價格脫節、交割違約或提貨困難。

> 這是真正有力的一層，因為它直接暴露「信用凭証 vs 實物本體」的矛盾。

### 基礎理論

**正常情況下**：
```
紙銀(COMEX 期貨)價格 ≈ 實物白銀價格 + 儲存成本
（兩者高度相關，差異控制在 2-5%）
```

**撕裂信號**：
```
實物溢價 > 10% 且持續擴大
→ 市場不再信任「紙面承諾可以按需交割實物」
→ 參與者用「溢價」來補償交割風險
```

### 具體觀測指標

#### 指標 A：實物白銀溢價(Spread)

**計算方法**：
```
溢價(%) = (實物銷售價格 - COMEX 現貨價格) / COMEX 現貨價格 × 100
```

**數據來源**：
- 實物銷售價格：本地珠寶/金幣經銷商報價（每月調查 3-5 家）
- COMEX 現貨價格：Metals-API / COMEX 官方數據

**觀測窗口**：月度平均、季度趨勢

**基線建立**：
```
歷史正常溢價：0-3%
微弱信號：溢價上升至 5-7%
明顯信號：溢價穩定在 10-15%
強信號：溢價突破 20% 以上
```

**當前記錄**：[ ] 待建立基線

---

#### 指標 B：COMEX/LBMA 庫存趨勢

**計算方法**：
```
月度庫存變化率 = (本月庫存 - 上月庫存) / 上月庫存 × 100
累計趨勢 = 最近 12 個月平均下降率
```

**數據來源**：
- COMEX 官方庫存報告（每日更新）
- LBMA 官方庫存報告（每日更新）

**解釋**：
```
月度變化率 < -5%：快速下降 → 撕裂信號 ✅
月度變化率 -2% ~ -5%：穩步下降 → 中等信號
月度變化率 > 0：庫存上升 → 信號破裂 ❌
```

**當前記錄**：[ ] 待監測（已設定自動收集）

---

#### 指標 C：交割違約或困難事件

**監測方式**：新聞監測 + 官方公告掃描

**具體信號**：
- COMEX 宣布「現金結算替代實物交割」
- 經銷商報告「提貨延遲超過 7 天」
- 交易所降低「交割質量標準」（接受更低純度）
- 出現「強制現金結算」的訴訟或糾紛

**當前記錄**：[ ] 待監測

---

### 證偽條件

**何時判定此層信號「破裂」**：

1. **實物溢價回到 < 5% 並穩定 6 個月**
   - 含義：市場恢復對紙面交割的信心

2. **COMEX 庫存回升超過 6 個月平均值的 20%**
   - 含義：供應端不再吃緊

3. **無新增交割困難事件，且既有事件全部解決**
   - 含義：系統回到正常運作

---

### 為什麼這層是「強信號」

- **直接驗證「信任轉變」**：溢價 = 市場用真金白銀投票，放棄紙面承諾
- **難以造假**：經銷商報價、庫存數據都是公開的，難以操縱
- **不可逆性強**：一旦溢價出現並持續擴大，通常反映了深層的信用問題

## 第四層：官方計價單位的轉變

**核心觀察**：國家或國際組織開始用白銀作為計價或結算單位。

> 這是真正能區分「儲備化」和「貨幣化」的決定性信號。

### 為什麼這層最硬

前三層都還能被「避險資產價格上漲」解釋 → 金價漲不代表金本位回歸。

只有當白銀重新成為**計價尺度**時，才能證明貨幣地位的回歸：
- **現在**：用法幣標價白銀（「1盎司白銀 = 30 美元」）
- **轉變**：用白銀標價商品（「1盎司等於多少商品」）

### 具體觀測指標

#### 指標 A：國家發行「白銀計價的主權債券」

**觀測**：
- 某國政府發行「白銀計價的長期債券」，而不是美元/歐元計價
- 例：「俄羅斯發行 10 年期國債，面值 100 盎司白銀，年息 4%」

**數據來源**：官方財政部公告、國際債券市場新聞

**當前狀態**：❌ 基本不存在

---

#### 指標 B：BRICS 結算單位納入白銀錨定

**觀測**：
- BRICS 新結算貨幣（如「Unit」或「BRICS Coin」）正式納入白銀作為底層資產
- 比例：例如 30% 黃金 + 20% 白銀 + 50% 國家外匯

**數據來源**：BRICS 官方聯合公報、央行協議公告

**當前狀態**：❌ 尚無正式納入（僅有提議）

---

#### 指標 C：貿易合同開始以白銀重量計價

**觀測**：
- 國際貿易合同（尤其是能源、礦產、農產品）開始出現「以白銀克數計價」的條款
- 例：「中俄大豆貿易按 1 噸大豆 = 15 公斤白銀 結算」

**數據來源**：
- 海關公告 / 貿易統計
- 新聞監測（Reuters、Bloomberg 商業報導）

**當前狀態**：❌ 尚無正式案例

---

### 證偽條件

**何時判定此層信號「破裂」**：

若某個時間窗口內（例如 24-36 個月），此層三個指標都始終為零：
- 無國家發行白銀計價債券
- BRICS 結算單位無白銀納入
- 無國際貿易白銀計價合同

→ **判定結論**：「只是又一輪貴金屬牛市，不是貨幣體系的轉變」

---

### 為什麼這層如此關鍵

- **是「假說轉變為現實」的臨界點**
- 前三層都還是「市場表現」，第四層是「政策信號」
- 若第四層始終為零，則：「市場可能認可新貨幣地位，但各國政府仍拒絕承認」

---

## 第五層：制度與法律層面

**核心觀察**：法律地位變化 — 某國取消金銀交易的資本利得稅、恢復金銀的法定貨幣地位、允許以金銀繳稅。

### 具體觀測指標

#### 指標 A：取消貴金屬交易的資本利得稅

**觀測**：
- 某國政府宣布：金銀交易所得**不再徵收資本利得稅**
- 在稅法上，等同承認「金銀是貨幣而非資產」

**數據來源**：各國稅務機構公告、立法院記錄

**當前狀態**：
- ✅ 美國部分州已取消貴金屬銷售稅（但非資本利得稅）
- ❌ 聯邦層面及主要經濟體未取消

---

#### 指標 B：恢復金銀的法定貨幣地位

**觀測**：
- 某國政府正式宣布：金銀重新成為「法定貨幣」或「法定支付手段」
- 中央銀行修改貨幣政策文件，明確承認金銀的貨幣職能

**數據來源**：官方立法、央行聲明

**當前狀態**：❌ 任何主要經濟體都未宣布

---

#### 指標 C：允許以金銀繳稅

**觀測**：
- 某國稅務機構宣布：接受用實物金銀支付稅款
- 例：「聯邦所得稅可用黃金支付，按當日倫敦金價折算」

**數據來源**：稅務機構公告、國家銀行政策文件

**當前狀態**：❌ 任何主要經濟體都未允許

---

### 證偽條件

**何時判定此層信號「破裂」**：

若在 36 個月內，此層三個指標都始終為零，且不存在任何官方層面的相關草案或立法提議：

→ **判定結論**：「貨幣地位轉變已被制度層面否決」
