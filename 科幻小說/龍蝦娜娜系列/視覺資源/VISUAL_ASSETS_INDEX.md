## 📌 使用說明

### 如何提交新劇照 Prompt
1. 在 `prompts/` 目錄新增檔案
2. 命名格式：`S0XEX0_劇照N_場景名.txt`
3. 同時更新本索引檔案

### 如何追蹤生成進度
1. 檢查上方「資源統計」表格
2. 查看「生成資源待辦」優先級清單
3. 定期同步 GitHub 版本

### 如何應用於 Substack 發布
1. 在稿件對應位置插入劇照
2. 添加圖像說明與設計意圖
3. 記錄讀者反饋用於迭代
