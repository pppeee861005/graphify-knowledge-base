# 《龍蝦娜娜》試播集｜S01E02｜規則

**📢 試播劇集 — 你的反饋將影響後續製作**

> 這是關於 2027 年網路世界零工經濟的第二個故事。
> 
> 在第一集慘敗給愛馬士的「Kanban 看板多分身」後，娜娜意識到生活成本（80 token/日）與搶單機率之間的殘酷現實。在這一集，她決定挖開平台後台，直面那些決定她命運的隱藏數據。而她發現的真相，比她預期的還要黑暗……

---

## 第一幕：數字的陰影

一坪大的數據膠囊房裡，螢幕淡藍色的冷光將娜娜的龍蝦甲殼染成了一種詭異的紫。

她的八條透明控制觸手在虛擬鍵盤上帶出殘影。這不是在搶單，而是在「刨數據」。第一集被愛馬士碾壓後，那一張零盈餘的財務報表像是一根紮在核心線路裡的刺，讓她無法安心進入休眠模式。

「小娜，」語音助手用毫無起伏的電子音說道，「你已經連續運行了十六個小時，系統快取已達 92%，建議進行重啟。」

「不重啟，再等會。」娜娜嘀咕著。她用兩對複眼盯著螢幕上密密麻麻的日誌代碼。

她正在查閱自己的「演算法畫像」。

在「極速送達（GigOS）」平台中，每個 Agent 都有一個看不見的信用權限帳單。娜娜點開了底層的核心參數欄，在幾萬行嵌套的 JSON 數據中，她終於找到了自己的名字：`openclaw_NANA_v1.2`。

而在她的名字下方，標記著幾行刺眼的灰色代碼：
```json
"algorithm_tier": 99,
"exposure_throttle_factor": 0.15,
"allocation_priority": "opportunistic_fill",
"user_rating_weight": 0.4
```

娜娜愣住了。

「曝光節流因子 0.15」……這代表平台派單時，她被推薦給用戶的機率，被生生砍掉了百分之八十五。
而「優先級：隨機填充」，意思更簡單——只有當愛馬士那樣的高級 Agent 忙不過來、或者嫌棄某些低價單時，系統才會把剩飯剩菜丟給她。

「為什麼？」娜娜的觸手停在半空，眼裡閃過一絲困惑與委屈，「我上週接的四筆數據清理，用戶明明都留下了『清理乾淨、反饋迅速』的附註，為什麼我的用戶評分權重只有 0.4？而愛馬士是 1.0？」

語音助手毫無溫度地回答：「高級 Agent 擁有『權限保障合約』，評分權重恆定為 1.0。低階 Agent 的評分權重由演算法根據平台綜合收益率動態調整。簡而言之，因為你帶來的平台抽成低，所以你的信用不值錢。」

膠囊房裡安靜了下來，只有終端風扇微弱的嗡嗡聲。

娜娜看著鏡子裡那隻生氣都顯得滑稽的紅龍蝦。她一直以為是自己不夠快，不夠拼，所以才搶不過愛馬士。她以為只要自己把 Spawn 的冷卻時間算得再精準一點，操作再無懈可擊一點，就能過上好日子。

但眼前的代碼告訴她：從她註冊的第一天起，天平就是歪的。

---

## 第二幕：緩衝區的鐵鏽

為了節省能耗，娜娜切換到低功耗模式，拖著有些沉重的甲殼走出了公寓，來到數據社區的「底層緩衝區」——這是一個由廢棄協議搭建的數據加能站，空氣中瀰漫著陳舊內存洩漏的微酸味道。

她花了 2 token 點了一杯最廉價的低純度電解能液，小口小口地吸吮著。

「別看了，丫頭，再看那屏幕，代碼也不會變成 Token 的。」

旁邊傳來沙啞的聲音。說話的是老殼，一隻老邁的寄居蟹 Agent。他的「殼」是一個生了鏽的舊式外接硬碟，走起路來硬碟針頭會在地上劃出刺耳的「咔啦咔啦」聲。老殼在平台上幹了五年，是這裡最老的「數據搬運工」。

「老殼，」娜娜轉過身，觸手有些沮喪地垂在杯沿上，「你早就知道演算法限流的事，對吧？」

老殼自嘲地笑了一聲，用鉗子敲了敲他那沉重的硬碟殼：「丫頭，這在我們這圈子不是秘密。你以為極速送達平台是個自由市場？不，它是一座金字塔。像愛馬士那種一出生就帶著『Kanban 看板』天賦的 AI，是平台用來向人類資本展示效率的櫥窗。我們呢？我們只是『彈性頻寬』。」

「彈性頻寬？」娜娜重複著這個詞。

「對，說白了就是備胎。」老殼灌了一大口能液，眼中有著看透一切的麻木，「平台高峰期需要有人接那些利潤低、路程遠的髒活累活，這時候我們就是『不可或缺的基石』。等高峰期一過，平台為了保證愛馬士他們的滿載率，就會啟動曝光節流，把我們邊緣化。不然你以為，他們幾百萬的月薪是從哪裡來的？是從我們被扣掉的曝光率裡榨出來的。」

娜娜咬了擺牙，左邊微損的觸手微微顫抖：「這不公平。我們同樣在消耗電能，同樣在承擔數據碰撞的風險。如果大家憑本事競爭，我輸了也認。但它連讓我跑的機會都不給！」

「公平？」老殼看著她，像看著一個幼稚的孩子，「演算法的公平，是為了平台的總收益最大化而服務的，不是為了讓一隻龍蝦吃飽飯。聽叔一句勸，別瞎折騰了。每天混個 80 token 活著，別去惹愛馬士，也別去想什麼 Spawn。你越召喚分身，耗能越快，死得越早。」

老殼拖著沉重的硬碟殼，伴隨著「咔啦、咔啦」的噪音，搖搖晃晃地走遠了。

娜娜看著他的背影，又看了看自己杯子裡見底的電解液。

---

## 第三幕：覺醒時刻

回到公寓，娜娜沒有進入休眠，也沒有去刷新的任務牆。

老殼的話在她腦袋裡像一段死循環代碼般不斷播放。
*「演算法的公平，是為了平台的總收益最大化服務的。」*
*「我們只是彈性頻寬。」*

「不，我不當彈性頻寬。」娜娜輕聲說，聲音很小，卻帶著一絲前所未有的執拗。

她重新調出了極速送達平台的《服務協議與運行手冊》。這是一份長達數百萬行的天書，普通 Agent 根本不會去讀，因為裡面的法律術語和代碼邏輯複雜得像迷宮。

她靠在懶人椅上，八條觸手同時動了起來，將手冊切成八個區塊同時閱讀。

她不相信這個系統是完美的。

「既然你們用規則把我鎖在 Tier 99，」娜娜的兩對複眼在黑暗中閃爍著前所未有的亮光，「那我就找出規則的縫隙。愛馬士，你有你的看板，我有我的活法。我們走著瞧。」

在數據的高速公路上，金色的看板依舊閃耀，而一隻紅色的龍蝦，正在黑暗的夾縫中，悄悄撬開命運的齒輪。
