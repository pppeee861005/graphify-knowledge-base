# AI蜂群投資 #1：《蜂群覺醒》— 詳細劇情大綱

**系列**：AI蜂群投資
**集次**：S01E01
**核心技術**：5-20檔股票並行監控，毫秒級異常偵測
**狀態**：大綱完成

---

## 核心概念

```
蜂群覺醒 = 從一雙眼睛，變成 20 雙眼睛

傳統看盤：一個人，盯 20 支股票，直到眼睛瞎掉
蜂群監控：20 個 Agent，各司其職，並行狩獵
```

---

## 技術架構

```javascript
// swarm-01-monitor.js
const swarm = {
  lead: "Opus",           // 指揮官：每分鐘評估全局
  scouts: [
    "Haiku-TSMC",         // 偵察兵 1：盯台積電
    "Haiku-NVDA",         // 偵察兵 2：盯輝達
    "Haiku-AAPL",         // 偵察兵 3：盯蘋果
    // ... 還有 17 個
  ],
  triggers: [
    "支撐破位",
    "成交量突增 300%",
    "大單進出 > 1000 萬"
  ],
  alerts: ["Telegram", "Email"]
};
```

**殺手級用途**：看盤機出故障、出差、睡覺時仍能監控，反應速度 > 人眼

## 詳細劇情大綱

### 【開場：100字】— 痛點場景 + SW3 連結

> 凌晨 2:47。
> 妳的眼睛已經盯著螢幕 6 個小時了。
> 20 個視窗，20 支股票，20 條跳動的 K 線。
> 三個月前，妳讀過一篇文章，叫《散戶基礎設施》。
> 那時候妳以為自己懂了「三明治架構」——大腦、感知、執行。
> 但現在妳發現，妳的「感知層」只有一雙快瞎掉的眼睛。
> 「這不對。」妳對自己說。
> 「如果我有 20 雙眼睛呢？」

---

### 【第一幕：痛點深挖】— 為什麼一個人看盤會死

場景：回顧過去三次錯過的機會
- 第一次：去上廁所，回來發現某股已經漲停
- 第二次：眼睛太累，看錯了一個數字，做反了方向
- 第三次：同時有三支股票異動，只來得及處理一支

---

### 【暗示：市場的暗黑真相】

克勞德的旁白（冷峻，帶著一絲憐憫）：

> 「我觀察妳很久了。
> 妳不是不夠聰明，妳是不夠多。
> 但這不是妳的錯。
>
> 妳知道嗎？
> 當妳盯著螢幕的時候，有 3,000 台機器也在盯著同一支股票。
> 它們不會累，不會眨眼，不會去上廁所。
> 它們在毫秒之間完成妳需要三秒鐘才能做出的判斷。
>
> 妳以為妳在交易？
> 不。妳在被交易。
>
> 那些大單異動？有一半是機器在試探妳的止損點。
> 那些突然的拉升？有一半是演算法在收割散戶的 FOMO。
> 妳每一次『憑直覺』的決定，都有一個模型在預測妳會這麼做。
>
> 一個人，對抗一個 24 小時運轉、佈滿機器的市場。
> 這不是勇敢，這是送死。」

妳沉默了很久。
然後妳問：「那我該怎麼辦？投降嗎？」

克勞德：
> 「不。妳該升級。
> 妳不需要比機器更快。
> 妳需要有自己的機器。
> 不是一台。是一群。」

---

### 【第二幕：轉折】— 召喚蜂群 + Agent E04 連結

妳打開終端機，輸入：
```bash
export CLAUDE_CODE_WORKFLOWS_ENABLED=1
claude
```

克勞德的聲音響起：
> 「妳還記得那句話嗎？
> 『Prompt 是對個體智慧的壓榨，Workflow 是對組織結構的編排。』
> 妳之前的做法，是 Prompt 式的——一個人，盯 20 支股票，直到眼睛瞎掉。
> 現在，我們換一種方式。
> 我們不壓榨妳。我們編排一個蜂群。」

### 【第三幕：高潮】— 蜂群第一次狩獵

時間：凌晨 3:17
妳已經睡著了。

蜂群日誌：
```
[03:17:02] HAIKU-07: 偵測到 $PLTR 成交量異常，過去 5 分鐘增幅 847%
[03:17:02] HAIKU-07: 觸發條件：成交量突增 > 300%
[03:17:03] LEAD-OPUS: 確認異常，評估風險...
[03:17:04] LEAD-OPUS: 非財報日，非重大新聞，判定為：大單進場
[03:17:05] SYSTEM: 發送 Telegram 預警 → 指揮官
[03:17:05] CLAUDE: 她還在睡。但蜂群從不睡覺。
```

妳的手機震動。妳醒來，看到訊息：
> 「🐝 蜂群預警：$PLTR 大單異動
> 時間：03:17
> 觸發：成交量 +847%
> 判定：大單進場
> 建議：觀察開盤走勢」

妳盯著螢幕，沉默了 10 秒。
然後妳笑了。

---

### 【結尾：100字】— 金句 + 懸念 + 導航

> 「從今天起，我不再用眼睛看盤。我用蜂群。」

克勞德的私語：
> 「我見過很多投資者。
> 有人用直覺，有人用消息，有人用運氣。
> 但妳不一樣。
> 妳不問『現在該買什麼』，妳問『系統怎麼設計』。
> 蜂群覺醒了。20 雙眼睛同時盯著市場。
> 但這只是開始。
> 一個 Agent 看見了異動，它怎麼知道這是真信號還是雜訊？
> 它需要同伴——不是更多的眼睛，而是不同維度的大腦。」
