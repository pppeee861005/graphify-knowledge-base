# AI蜂群投資 #2：《三維獵殺》— 詳細劇情大綱

**系列**：AI蜂群投資
**集次**：S01E02
**核心技術**：籌碼面+基本面+技術面三角印證系統
**狀態**：大綱完成

---

## 核心概念

```
三維獵殺 = 三個分析師同時出手，只有全票通過才能扣下扳機

維度 1：基本面分析師 — 這家公司值不值錢？
維度 2：技術面分析師 — 現在是不是好時機？
維度 3：籌碼面分析師 — 誰在買？誰在賣？

三維印證 → 統一評分 0-100 → 決策
```

---

## 技術架構

```javascript
// swarm-02-triangulate.js
const triangulationSwarm = {
  lead: "Opus",                    // 指揮官：綜合三份報告
  analysts: [
    "Sonnet-Fundamental",          // 基本面分析師
    "Sonnet-Technical",            // 技術面分析師
    "Sonnet-Chip"                  // 籌碼面分析師
  ],
  scoring: {
    pass: "≥80 → 推薦買入",
    hold: "60-79 → 觀望",
    avoid: "<60 → 回避"
  },
  output: "完整推理鏈 + 統一評分"
};
```

### 【開場：100字】— 痛點場景 + 群組陷阱

> 群組炸了。
> 「這支要噴了！技術面完美！」

>

---

### 【第一幕：痛點深挖】— 單維度的致命陷阱

場景：回顧三次被單一維度騙局收割的經歷

**第一次：技術面陷阱**
> 「技術面完美」的股票，財報造假被揭穿，股價歸零。
> 妳學到：K 線可以被畫出來。

**第二次：基本面陷阱**
> 「基本面優秀」的股票，但主力已經在出貨。
> 妳買在最高點，套了半年。
> 妳學到：好公司不等於好時機。

**第三次：籌碼面陷阱**
> 「法人狂買」的股票，但那是為了掩護另一支股票出貨。
> 妳學到：籌碼也可以是煙霧彈。

---

### 【暗示：市場的多維真相】

克勞德的旁白（冷峻，帶著警示）：

> 「妳知道嗎？
>
> 市場裡有一種獵人，專門狩獵『單維度投資者』。
>
> 他們知道妳只看技術面，所以他們畫出完美的 K 線。
> 他們知道妳只看基本面，所以他們包裝出漂亮的財報。
> 他們知道妳只看籌碼面，所以他們製造假的買盤。
>
> 一個維度，就是一個盲點。
> 兩個維度，還是有縫隙。
> 三個維度？
>
> 那才叫做『無處可逃』。
>
> 妳不是要比獵人更快。
> 妳是要讓獵人在三個維度上同時騙過妳——這幾乎不可能。」

妳沉默了很久。
然後妳問：「怎麼做到？」

克勞德：
> 「妳需要三個分析師。
> 不是三個人。是三個 Agent。
> 它們同時開槍，只有三發都命中，才算獵殺成功。」
