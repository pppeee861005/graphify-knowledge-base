### 第二篇：《三維獵殺》— 三角印證投資信號系統

**核心技術**：籌碼面+基本面+技術面同時跑，權重自動調整

**技術架構**：
- Sonnet×3 並行：基本面分析師、技術分析師、籌碼分析師
- Opus Lead 綜合三份報告 → 統一評分 0-100
- 評分≥80 才推薦買，60-79 觀望，<60 回避
- 每份報告都有完整推理（可追溯決策邏輯）

**殺手級用途**：防止單一維度騙局（技術形態好但基本面爛、或反之）

| 元素 | 內容 |
|------|------|
| **場景** | 群組裡瘋傳某支「技術面完美」的股票 |
| **痛點** | 妳買了，結果爆雷——基本面早就爛透了 |
| **轉折** | 「一個維度不夠。我要三個維度同時印證。」 |
| **高潮** | 三個分析師同時報告，評分只有 47 分：「回避」 |
| **結尾** | 「從今天起，沒有三維印證，我不出手。」 |

### 第三篇：《自動校準》— 個人投資組合動態再平衡引擎

**核心技術**：持倉 10 檔以上時自動建議是否調整配置

**技術架構**：
- 每個持股一個 Sub-agent 監控風險/報酬比變化
- 當偏離目標配置超過閾值時自動提案
- Lead Agent 全局優化：考慮稅率、手續費、流動性衝擊
- 輸出：「現在應該賣掉 NVIDIA 加倉 TSMC」的精確建議

**殺手級用途**：避免人工持倉漂移（贏的越來越多、輸的越來越少）

| 元素 | 內容 |
|------|------|
| **場景** | 妳的 NVIDIA 漲了 300%，佔組合 60% 了 |
| **痛點** | 捨不得賣，結果一次回調吃掉半年獲利 |
| **轉折** | 「我需要一個沒有情緒的再平衡系統。」 |
| **高潮** | 蜂群提案：「賣出 NVIDIA 15%，加倉 TSMC 10%」 |
| **結尾** | 「從今天起，我不跟自己的貪婪對賭。」 |

### 第四篇：《新聞獵手》— 新聞-基本面聯動套利偵測

**核心技術**：即時捕捉「新聞發生→股價應該反應但還沒反應」的機會

**技術架構**：
- Haiku 爬取財經新聞+公司公告
- Sonnet 做情感分析（正面/負面/中立）
- 另一個 Sonnet 查歷史類似事件的市場反應數據庫
- Lead Agent：預測「應該股價」vs「實際股價」
- 差異>2% 就發出套利信號

**殺手級用途**：新聞秒出→毫秒內就知道是否有套利空間（vs 人工讀新聞要 3-5 分鐘）

| 元素 | 內容 |
|------|------|
| **場景** | 重大利多新聞發布，妳還在讀第三段 |
| **痛點** | 讀完新聞，股價已經漲完了 |
| **轉折** | 「我需要比人類快 1000 倍的新聞解讀。」 |
| **高潮** | 新聞發布 0.3 秒後，蜂群：「套利空間 3.2%，建議買入」 |
| **結尾** | 「從今天起，新聞不是用來讀的，是用來狩獵的。」 |

### 第五篇：《跨境狙擊》— 跨市場套利掃描器

**核心技術**：並行監控多個市場同一標的的價差

**技術架構**：
- Sub-agent 1：台股 vs 香港 ADR 價差
- Sub-agent 2：台股 vs 美股 ADR 價差
- Sub-agent 3：現貨 vs 期貨價差
- Sub-agent 4：相關產業鏈個股價差（上游原料 vs 下游製品）
- Sub-agent 5：融資融券利率套利
- Lead Agent：實時計算現貨-期貨-稅率-手續費後是否還有利潤

**殺手級用途**：套利機會轉瞬即逝，人工跨市場比價根本來不及，WF 可並行 5 個市場無延遲

| 元素 | 內容 |
|------|------|
| **場景** | 台積電台股、ADR、期貨三個價格在跳動 |
| **痛點** | 妳算完價差，機會已經消失了 |
| **轉折** | 「我需要同時看見五個市場的蜂群。」 |
| **高潮** | 5 個 Sub-agent 同時報告：「台股-ADR 價差 1.8%，扣除成本後淨利 0.9%」 |
| **結尾** | 「從今天起，我不在一個市場裡打獵，我在五個市場裡圍獵。」 |

---

### 第六篇：《末日推演》— 風險情境模擬與壓力測試

**核心技術**：並行跑 N 個「如果...會怎樣」場景

**技術架構**：
- 場景 1：Fed 升息 +0.5%，市場反應評估
- 場景 2：台海衝突升級，台股科技股影響
- 場景 3：產業需求驟降，個股風險評估
- 場景 4：匯率波動 ±5%，出口商影響
- 場景 5：融資餘額爆量，市場反轉預警
- 場景 6：重點持股上市公司爆雷，組合風險
- 場景 7-10：進一步細化組合
- Lead Agent：生成實時風險熱力圖（哪個情景對我傷害最大）

**殺手級用途**：傳統 VaR 只算歷史波動，WF 可主動假設極端情境提前預警

| 元素 | 內容 |
|------|------|
| **場景** | 市場一片歌舞昇平，但妳睡不著 |
| **痛點** | 「如果明天黑天鵝來了，我會死多慘？」 |
| **轉折** | 「我需要一個能模擬末日的蜂群。」 |
| **高潮** | 10 個場景並行推演，風險熱力圖生成：「台海衝突對你傷害最大」 |
| **結尾** | 「從今天起，我不只看見現在，我看見所有可能的未來。」 |

### 第七篇：《終極顧問》— AI 助手式個人投資顧問

**核心技術**：Opus + context memory，你的專屬 AI 投資長期顧問

**技術架構**：
- 記住你的投資風格、風險承受度、長期目標
- 你問「現在該買什麼」→ Lead Agent 不只回答「買 TSMC」，而是：
  - 為什麼現在是好時機（3 個維度的理由）
  - 建議倉位大小（基於你的組合、風險承度）
  - 進場點、目標價、停損點
  - 進場後的每週監控規則
  - 若市場反轉如何應對
- 對話有記憶：「上次建議 TSMC 現在該加倉/減倉」，不需重複解釋背景

**殺手級用途**：Bloomberg 顧問 $50K/年 + 人工顧問 $10-20K/年，現在 $20/月自動替代

| 元素 | 內容 |
|------|------|
| **場景** | 妳問：「現在該買什麼？」 |
| **痛點** | 網路上的建議都是垃圾，顧問費又貴得離譜 |
| **轉折** | 「我需要一個記得我是誰、知道我要什麼的顧問。」 |
| **高潮** | 蜂群回答：「基於妳的風格、組合、目標，建議...」完整的 5 層建議 |
| **結尾** | 「從今天起，我不再孤獨。我有了一個永遠在線的軍師。」 |
