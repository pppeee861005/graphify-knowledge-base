## 入口

找 **{核心速查}** → 輸入：

```
ultraWork [任務]
```

例：
```
ultraWork 多股票實時監控蜂群
限制 100萬 token
```

Claude 會生成 .js 戰術書。

---

## 流程（記牢）

```
1. ultraWork 下達任務
2. 設 token 上限（彈藥管控）
3. Claude 生成戰術書
4. 精進腳本（這步很重要，別跳過）
5. 「請以 xxx.js 執行」
```
