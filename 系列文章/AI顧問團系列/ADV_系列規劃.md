# AI 顧問團系列規劃

**系列代碼**：`ADV` (AI Advisor)
**啟動日期**：2026-06-11
**狀態**：🚀 規劃中 → 📝 進行中（實施中）

## 🎯 系列定位

### 一句話定義

> 當你需要做決策時，AI 不是替你決策，而是幫你看清全貌、權衡利弊、找到最優路徑的智囊團。

### 核心哲學

- **Human in the Loop 的應用**：人類決策，AI 輔助
- **多層次顧問架構**：財務顧問、技術顧問、戰略顧問、倫理顧問...
- **決策可視化**：把複雜問題轉化為可讀的選擇集
- **長期價值**：不是快速答案，而是深層理解
- **L1 Subagents 的實踐**：Coordinator 持有願景，多個 Subagent 並行開發不同席位
- **九席治理架構**：八位領域專家提供專業分析，第九位反方與風險顧問挑戰所有假設
- **人類保有決定權**：人類主席不是第十位 AI 顧問，而是最終價值判斷者與責任承擔者

### 與其他系列的區隔

| 系列 | 核心問題 | 受眾 |
|------|----------|------|
| Agent 系列 | 蜂群 Agent 技術架構是什麼？ | 技術人員 |
| Software 3.0 | 散戶如何建立自己的 AI 工具鏈？ | 個人創作者 |
| Human in the Loop | 企業如何用 AI 改造流程？ | 企業管理層 |
| **AI 顧問團** | **個人/組織如何用 AI 進行高質量決策？** | **決策者、創業者、管理者** |

## 👥 目標受眾

### 主要受眾

1. **創業者**：融資、擴張、人才決策
2. **高管**：戰略抉擇、資源配置
3. **個人**：職業轉換、重大生活決策
4. **組織決策層**：需要智囊團支持的決策者

### 讀者痛點

- 「大決策面前，我一個人想太累，也想不全面」
- 「有 ChatGPT，但不知道怎麼系統地用它輔助決策」
- 「需要多角度思考，但沒有真實的顧問團」
- 「決策過程不透明，事後問題重重」

### 讀者收穫

- 理解多層顧問模型（財務、技術、戰略、倫理四層）
- 學會搭建自己的 AI 顧問團框架
- 掌握決策可視化工具和模板
- 從「AI 給我答案」升級到「AI 幫我看清選擇」

```

  ├─ 持有：AI顧問團產品線計劃（8位領域專家＋1位反方與風險顧問）
  ├─ 持有：信任生產線SOP（戰報→機房→教科書→劇場）
  └─ 分配與協調：
      ├─ Subagent-Season1：願景架構篇（2-3篇核心定義）
      ├─ Subagent-Season2：實戰應用篇（3-4篇場景解析）
      ├─ Subagent-Season3：工具系列篇（2-3篇工具和Prompt）
      └─ Subagent-Resource：資源與模版庫（持續更新）
```

### 文體映射（信任生產線四件套）

每篇文章都遵循：**戰報 → 機房 → 教科書 → 劇場** 的進階發展

| 層級 | 文體 | 內容形式 | 發布週期 |
|------|------|---------|---------|
| ⚡ 戰報 | 實時洞察 | 決策現場的原始觀察、困境、第一時間發現 | 即時 |
| 🏭 機房 | 完整收據 | 決策流程的完整記錄、數據、決策矩陣、結果驗證 | 決策後 3 日內 |
| 📚 教科書 | 可複用模式 | 決策框架的系統總結、最佳實踐、模板庫 | 同類決策 ≥2 次驗證後 |
| 🎭 劇場 | 傳播敘事 | 決策故事的精彩呈現、場景感、角色化 | 教科書完成後 |

## ✍️ 寫作風格

### 敘事結構：框架 + 故事 + 工具

1. **框架層**：清晰呈現決策模型的邏輯
   - 用圖表、流程圖、對比表
   - 解釋「為什麼這樣框架化」

2. **故事層**：通過真實/假設案例展示應用
   - 角色化：創業者、高管、個人的視角
   - 情境化：具體的決策時刻

3. **工具層**：提供可直接使用的 Prompt 和模板
   - Prompt 範例（複製即用）
   - 檢查清單（決策前過一遍）
   - 模板庫（下載即填）

### 語調

- **不煽情，講清楚**：不用「顛覆」「革命」，直接說機制
- **承認複雜性**：「決策永遠不完美，但可以系統化」
- **強調『輔助』而非『替代』**：「AI 是助手，你才是決策者」
- **鼓勵自主構建**：不是推銷我的框架，而是教你建自己的

✅ **協調**：
- 各篇之間的邏輯連貫性
- 與其他系列（Agent、Software 3.0、Human in Loop）的橋樑關係
- 與產品線計劃的實現進度同步

### Subagent 責任（具體執行）

各 Subagent 在 Coordinator 的指導下：
1. **研究層**：深入研究分配主題，收集案例、數據、最佳實踐
2. **撰寫層**：根據信任生產線 SOP 撰寫初稿（戰報 → 機房 → 教科書 → 劇場）
3. **反饋層**：提交初稿，接收 Coordinator 反饋，迭代完善
4. **發布層**：完成信任生產線自查清單，準備發布
