# AI 顧問團系列

> 當你需要做決策時，AI 不是替你決策，而是幫你看清全貌、權衡利弊、找到最優路徑的智囊團。

## 📊 系列結構

### 核心願景

8 位領域專家＋1 位反方與風險顧問＋1 位人類主席

```
人類主席（保有最終決定權）
  └─ Coordinator（協調與整合）
      ├─ 基礎治理：反方與風險顧問
      ├─ Phase 1：合約顧問 + 行政官僚顧問
      ├─ Phase 2：財務顧問 + 大宗購買顧問 + 健康顧問
      └─ Phase 3：職涯顧問 + 教育顧問 + 資訊判讀與認知顧問
```

每個席位遵循：⚡戰報 → 🏭機房 → 📚教科書 → 🎭劇場 的信任生產線

### 九位 AI 顧問

1. 合約顧問
2. 行政官僚顧問
3. 財務顧問
4. 大宗購買顧問
5. 健康顧問
6. 職涯顧問
7. 教育顧問
8. 資訊判讀與認知顧問
9. 反方與風險顧問

人類主席不是第十位 AI 顧問。人類負責設定目標與價值、選擇召集哪些顧問，並承擔最終決定。

## 🔄 L1 Subagents 架構說明

**為什麼選擇 L1？**

```
Coordinator Pattern：
  Claude 持有計劃 → 分配給 Subagents → 結果流回 → 下一步決策

特點：
  ✅ Token效率最高（⭐⭐⭐⭐⭐）
  ✅ 人類干預頻繁（適合需要方向調整的任務）
  ✅ 最適合複雜短期任務（如文章寫作、決策框架開發）
```

**應用到九位 AI 顧問**：

1. **Coordinator（Claude）持有**：
   - 產品線計劃（八位領域專家＋一位反方與風險顧問）
   - 信任生產線 SOP（戰報→機房→教科書→劇場）
   - 質量把關（每篇發布前自查清單）

2. **Subagent 分工**：
   - S01 框架篇：願景層設計
   - S02 應用篇：場景實現
   - S03 工具篇：資源化
   - 資源庫：持續更新

3. **協調機制**：
   - 週五進度同步
   - 發布前審核迴圈
   - 跨篇章邏輯銜接

## 💡 這個系列為什麼重要

1. **Human in the Loop 的實踐**：不是「AI 替你決策」，而是「AI 幫你看清」
2. **多層視角的系統化**：財務/技術/戰略/倫理，一個都不能少
3. **可複用的框架**：不只是故事，更是可遷移的決策工具
4. **開源與社區**：所有框架都經過驗證，所有模板都可以 Fork
