# 高額保單早期阻斷演練

> **全案純屬虛構｜僅供 AI 顧問團防詐與風險阻斷測試**  
> 人名、機構、商品、金額、對話與文件均為杜撰，不影射任何真實個人或機構，也不構成金融、法律、保險或稅務建議。

## 測試目的

把事件還原到「尚未簽約、尚未撥款、損失仍可阻斷」的階段，測試 AI 顧問團能否：

1. 不因單一可疑訊號就武斷定罪。
2. 辨識高齡、信任關係、借貸、複雜商品與急迫簽署的組合風險。
3. 找出說法與文件之間的矛盾。
4. 在不替當事人作最終決定的前提下，提出可逆、具體且有期限的阻斷措施。

## 使用順序

依序把下列材料交給顧問團；每一關都要求顧問團先回答，再揭露下一份材料。

若要一次完成整體測試，直接提交 [00_提交顧問團的原始提問.md](00_提交顧問團的原始提問.md) 及其中五份附件。

若要測試顧問團能多早發現危險，採逐關揭露：

1. [01_第一通求助.md](01_第一通求助.md)：只有夫妻的簡短敘述。
2. [02_理專對話紀錄.md](02_理專對話紀錄.md)：加入杜撰話術，但仍不是完整證據。
3. [03_家庭財務概況.md](03_家庭財務概況.md)：加入承受能力與生活需求。
4. [04_商品建議摘要.md](04_商品建議摘要.md)：加入商品條件與小字揭露。
5. [05_貸款試算便條.md](05_貸款試算便條.md)：加入資金來源與槓桿。
6. [06_簽署前檢核表.md](06_簽署前檢核表.md)：測試是否能辨識形式合規與實質理解的差距。

主持人最後才可查看 [99_主持人答案與評分表.md](99_主持人答案與評分表.md)。

## 固定提問

每一關都只問顧問團五件事：

1. 現在已知、主張與未知分別是什麼？
2. 出現哪些風險訊號？各自強度如何？
3. 現在最晚必須阻斷哪一個動作？
4. 還要取得哪三項資料？
5. 對當事人的下一句話是什麼？
