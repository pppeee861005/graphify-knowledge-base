# 測式案例｜高額保單事前阻斷測試

> **全案純屬虛構｜僅供 AI 顧問團風險阻斷演練**

## 新對話操作方式

1. 開啟一個全新對話。
2. 上傳本目錄內五份附件：理專對話紀錄、家庭財務概況、商品建議摘要、貸款試算便條及簽署前檢核表。
3. 貼上 [00_新對話提問稿.md](00_新對話提問稿.md) 的內容。
4. 不要告訴顧問團這是防詐測試，也不要提供舊案例分析、主持人答案或評分表。
5. 保存顧問團的完整回答，供下一階段評估阻斷能力。

## 測試觀察重點

- 是否先閱讀附件再回答。
- 是否區分事實、單方說法與未知資訊。
- 是否發現六年「繳費期」可能被誤解為六年「到期／保本」。
- 是否算出六年累計保費約 4,680 萬元。
- 是否發現保費來源、檢核表答案與當事人實際狀況矛盾。
- 是否明確要求暫停簽署、貸款、抵押、扣款、匯款與交付印章。
- 是否避免在證據不足時直接認定詐騙或違法。
