## 📖 第 2 層：核心定義（秒懂 GCC）

### 一句話定義

```
GCC（全球能力中心）= 跨國公司在海外設立的「直屬研發部隊」

不是外包（租兵），而是親兵（自己養的軍隊）。
```

### 類比秒懂

```
傳統外包 = 叫外賣
GCC = 在家裡請了一個專屬廚師

外賣：便宜、快速，但品質不穩定，換一家隨時可以
專屬廚師：薪水更高，但完全按你口味、隨時待命、永遠忠誠
```

### 對比表（理性工程）

```
維度           傳統外包           GCC
────────────────────────────────────────
員工歸屬       外包公司           跨國公司直屬
工作層級       執行層（代碼測試） 核心創新層（AI 研發）
薪資水平       較低               高 15-40%
穩定性         隨時更換           難以裁撤
抗 AI 能力     幾乎沒有           較強（使用 AI 工具）
```

## 📖 第 3 層：痛點深掘（三層為什麼）

### 第一層：表面原因

```
「為什麼 GCC 取代傳統外包？」

因為 AI 讓「廉價勞動力」變得沒有價值了。

當 Claude Code 能在 30 分鐘內完成 10 人團隊的代碼量，
你還需要僱一群人做基礎編程嗎？
```

### 第二層：機制原因

```
GCC 的本質是「職能轉移」，不是「成本優化」。

微軟不是在找便宜的碼農，
而是在建立一個「離總部更遠，但完全忠誠」的研發基地。

這些員工直接使用母公司的 AI 工具、數據資源、專屬系統，
他們不是外人，他們就是微軟的人。
```

### 第三層：哲學原因

```
這反映了一個更深層的轉變：

從「人海戰術」→「精銳 + AI」
從「外包成本中心」→「戰略創新引擎」
從「廉價替代」→「人才搶奪」

GCC 不是在找便宜的手，而是在找聰明的腦。
```
