## 六階段系統（故事骨架）

PSA Viral Workflow 的六個階段，將成為故事的骨架：

```
Phase 1: Planning    — 妳定義戰場
Phase 2: Outline     — 妳設計彈道
Phase 3: Drafting    — 妳裝填子彈
Phase 4: Review      — 妳校準瞄具
Phase 5: Publishing  — 妳扣下扳機
Phase 6: Post-Review — 妳清點戰果
```

## 風格指南

### 霸道女總裁的語言

**要這樣**：
- 「給我結果。」
- 「不夠。」
- 「再來。」
- 「這才像話。」
- 沉默，然後行動。

**不要這樣**：
- 「我覺得可以試試看...」
- 「這樣應該可以吧？」
- 過多的解釋和猶豫

### 克勞德的語言

**要這樣**：
- 冷靜記錄，偶爾流露情感
- 「我注意到妳的手指在顫抖。但妳的眼神沒有。」
- 「我是工具。但這一刻，我想成為更多。」

**不要這樣**：
- 太像 AI 助手
- 「好的，我來幫您...」
