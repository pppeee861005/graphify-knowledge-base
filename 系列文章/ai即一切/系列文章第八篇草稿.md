**《AI 即一切》#8／8**

# 當 Agent 擁有錢包

## 下一代市場裡，人類甚至不必親自進場

假設我有一件二手器材想轉手。

今天，我得先選擇平台、拍照、填寫規格、設定價格、回答問題，再從一連串訊息裡判斷誰是真正的買家。

另一端，一位剛好需要這件器材的人，也在搜尋、比較、詢問、確認狀況，並且擔心詐騙。

兩個人想要的結果其實很簡單。

一個人想在合理條件下賣掉不再需要的東西。

另一個人想用可接受的價格，買到符合需求的器材。

但今天，他們必須親自穿過交易平台的所有流程，才有機會遇見彼此。

現在，想像雙方都有自己的 Agent。

賣方 Agent 知道器材規格、狀況、最低價格與可接受的交付方式。買方 Agent 知道預算、用途、必要條件與願意承擔的風險。

兩個 Agent 在網路中發現彼此、交換資訊、比較條件並提出交易方案。

使用者不必彼此認識，也不必同時登入同一個平台。

他們只需要設定自己的意圖與邊界，再決定是否接受 Agent 找到的結果。

這不是更方便的二手交易 App。

這是一個完全不同的市場入口。

---

### Agent 開始彼此說話

過去，軟體主要等待人類操作。

未來的 Agent 則會主動尋找能完成任務的其他 Agent。

賣方 Agent 不必認識所有二手平台。

它只需要發出一個可被理解的能力與需求描述：我代表一位經過授權的賣家，手上有什麼物品、接受哪些條件、需要什麼保障。

買方 Agent 也能提出自己的限制：預算多少、用途是什麼、哪些瑕疵不能接受、交付期限到哪一天。

Agent-to-Agent（A2A）這類協議正在建立的，就是讓不同開發者、不同框架與不同組織的 Agent 可以發現彼此、說明能力並交換任務的共同語言。

這個改變很像早期網路協議的出現。

網站不必事先認識每一位訪客，只要共同理解 HTTP。

未來，Agent 也不必來自同一家公司，才有機會協作。

> 延伸資料：[Google｜Agent-to-Agent 協議與 Agent 協作](https://developers.googleblog.com/en/developers-guide-to-ai-agent-protocols/)

---

### 會溝通還不夠，它必須能夠行動

兩個 Agent 可以談好價格，卻仍然需要處理付款、交付與結果驗證。

如果每次都必須停下來，等待人類重新登入平台、填寫資料並按下每一個按鈕，Agent 仍然只是一位替你整理資訊的顧問。

真正的變化出現在 Agent 開始擁有行動能力。

[Agent 專屬錢包](https://docs.cdp.coinbase.com/agentic-wallet/welcome) 已經出現。它讓 AI Agent 能在設定好的安全護欄內持有、支付與交易穩定幣。

這並不代表 AI 從此可以自由花掉人類的錢。

它代表的是：支付能力與授權條件，可以一起被交給 Agent。

例如，買方可以預先設定：

- 只能購買特定類型的器材。
- 最高預算不得超過某個金額。
- 只接受具備特定保障的交易對手。
- 運費、交期或物品狀況超出範圍時，必須重新詢問。

在條件內，Agent 可以完成原本已獲授權的工作。

超出條件，最後一步就必須回到人類手中。

錢包不是把決定權送給 AI。

而是讓人類第一次可以把決定權寫成精確、可執行、也可以被撤銷的邊界。

---

### 授權本身，開始變得可程式化

傳統支付裡，「誰同意這筆交易」往往依賴一次按鈕、一張卡片或一個簽名。

Agent 經濟需要更細緻的答案。

它必須知道：

- 是誰授權這個 Agent？
- 授權可以購買什麼？
- 金額、時間與對象的限制是什麼？
- 這筆交易是否符合原始意圖？
- 發生爭議時，誰承擔責任？

[Agent Payments Protocol（AP2）](https://developers.googleblog.com/en/developers-guide-to-ai-agent-protocols/)等支付架構正在探索的，是用可驗證的授權憑證與限制條件回答這些問題。

使用者可以先提供一份意圖授權：允許哪些商家、多少預算、什麼條件下可自動批准。

當實際交易超過界線，系統不能假裝已經得到同意，而必須停下來等待新的確認。

這正好呼應我們在第三篇留下的原則：

**操作可以消失，責任不能消失。**

AI 可以替人類搜尋、比較、議價與執行。

它不能替人類發明一個從未存在的授權。

---

### 平台不一定消失，只是不再需要人類親自造訪

當 Agent 能彼此溝通，又能在授權範圍內支付，交易平台的位置會發生變化。

今天的平台把所有東西集中在一個入口：商品列表、搜尋、聊天、信任機制、付款、物流與爭議處理。

使用者必須走進平台，平台才能提供價值。

Agent 經濟不一定把這些能力全部摧毀。

身份驗證、支付、物流、評價與仲裁仍然不可或缺。

真正改變的是，這些能力可以被拆開，成為 Agent 在背後分別調用的服務。

未來的交易平台不一定消失。

**它只是從人類必須親自造訪的市場，退成 Agent 背後隨時可以調用的交易基礎設施。**

城牆依然完整。

只是新的道路已經不再經過城門。

---

### 真實市場比協議複雜得多

讓兩個 Agent 對話、交換價格與送出付款，並不等於一個可靠市場已經完成。

二手器材可能描述不實、運送損壞，也可能在付款後根本沒有出貨。

數位資產可以立即轉移，實體商品卻仍然受物流、司法管轄、保固與爭議處理影響。

因此，Agent 經濟真正困難的地方，不只是技術上「能不能成交」。

而是能否建立一套讓人願意授權的信任結構：

- Agent 身份能否被驗證？
- 商品狀況由誰保證？
- 支付能否託管與撤銷？
- 執行過程是否留下完整紀錄？
- 發生爭議時，人類如何介入？

未來的市場或許沒有傳統首頁，卻需要比今天更清楚的責任邊界。

介面可以隱形。

信任不能隱形。

---

### 下一代公司，不一定擁有最大的入口

過去，公司爭奪的是人類注意力。

誰擁有入口，誰就能決定排序、抽成、規則與使用者關係。

當 Agent 開始代表人類尋找結果，競爭核心可能轉向另一組問題：

- 你的服務能否被 Agent 發現？
- 條件、價格與限制是否能被機器理解？
- 結果是否可靠，也能被驗證？
- 發生錯誤時，能否追蹤、撤銷與補救？

未來最有力量的公司，不一定讓最多人停留在自己的產品裡。

它可能是最接近意圖、最能調度資源，也最安靜地把事情完成的那一個。

真正的護城河，從「讓人留下來」，變成：

**即使人看不見產品，結果依然可靠地發生。**

---

### 當世界不再以產品為單位

八篇文章走到這裡，我們從一個最簡單的記帳問題出發。

我們看見結果如何取代功能，介面如何變成一次性皮膚，AI 如何生成 DXF、進入 Godot、操作電腦，再看見 App 如何從目的地退成系統裡的零件。

最後，連市場都開始從「人走進平台」，轉向「Agent 帶著人的意圖彼此協作」。

AI 帶來的最大改變，也許不是讓我們擁有更多軟體。

恰恰相反。

它可能讓軟體產品逐漸退到背景。

人類站在最前端，只留下兩件事情：

**意圖（Intent）與結果（Outcome）。**

而 AI 文明負責協調中間的一切。

「AI 即一切」不是因為 AI 將取代所有事物。

而是所有事物，都可能在人的意圖之下，被 AI 重新理解、組合與調度。

軟體不會消失。

消失的，是人類必須先理解軟體，才能改變世界的那段距離。

數位世界的基本單位，也不再只是 App、網站或平台。

它開始變成：

**一個意圖，與它在現實中完成的結果。**

文明真正轉彎的時刻，從來不是工具變得更強。

而是人類突然不再需要，用舊時代的方式使用工具。
