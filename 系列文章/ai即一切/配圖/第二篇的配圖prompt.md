# 《AI 即一切》第二篇配圖 Prompt

**文章**：#2〈結果，才是下一代真正的商品〉  
**副題**：從功能競爭走向 Outcome 經濟

本篇配置三張圖：封面主視覺、文中概念圖、結尾餘韻圖。三張圖延續第一篇的世界觀，但從「軟體退到幕後」推進到「意圖在現實中獲得結果」。

## 共用生成規格

- **畫幅**：橫向 16:9，適合 Substack；主體集中在中央 60% 安全區。
- **風格**：超現實電影感編輯插畫、建築式象徵、高級思想雜誌主視覺、霧面材質、細緻顆粒。
- **色彩**：深黑、炭灰、冷白，少量暗金；暗金只代表人類意圖與已完成的結果，加入極少量低飽和泥土綠與暖木色。
- **人物**：同一位不露臉、比例渺小但姿態穩定的人類；不呈現被控制、逃亡或崇拜。
- **AI 的存在方式**：以路徑、空間整理、光線與工具殘影暗示，不出現機器人或 AI 臉孔。
- **文字規則**：不可出現標題、可讀文字、Logo、品牌名稱、浮水印或亂碼。
- **構圖限制**：每張圖只保留一個主要衝突，不使用拼貼、分鏡或資訊圖表。

## 共用負面 Prompt

> 不要機器人、仿生人、金屬人臉、發光 AI 頭像、藍色數位大腦、人機握手、晶片、電路板、二進位數字、程式碼雨、霓虹賽博龐克、手機操作畫面、聊天視窗、App Logo 牆、資訊圖表、簡報圖示、浮誇全息介面、過度飽和藍紫光、企業科技廣告感、末日災難、爆炸、恐怖機器統治、可辨識文字、簽名、Logo、浮水印、邊框、拼貼、分割畫面。不要讓工具或 AI 比人類意圖與已完成結果更明亮。

---

## 圖一｜封面主視覺

### 名稱

**〈結果從工具的另一端走出來〉**

### 建議位置

文章封面／標題下方第一張圖。

### 核心 Prompt

> 一張橫向 16:9 的超現實電影感編輯插畫。畫面中央是一張巨大、深黑色、略帶霧面質感的工作台，工作台左側堆疊著冷灰色的傳統軟體工具：視窗框架、按鈕、表格、設定面板、工具列與複雜的操作介面，它們像一座精密卻無人使用的機械城市，全部沒有文字。工作台右側則是一個已經完成、具有真實重量的物件：一座為書桌量身打造的簡潔收納架，材質是溫暖木質與暗金邊緣，清楚放入鍵盤、耳機與充電器，卻不遮住插座；它是全圖最明確的結果，不是概念圖或光球。
>
> 畫面下方中央站著一個極其渺小、性別模糊的人類背影，人物沒有操作任何按鈕，只伸出一隻手，掌心捧著一小團暗金色、尚未定形的人類意圖之光。從這團光延伸出一條簡潔的弧形路徑，越過左側所有工具，直接在右側凝聚成完成的收納架。路徑經過工具但沒有停留，暗示 AI 調度工具、直接交付結果。工具仍然完整存在，沒有被摧毀，只是退到背景。
>
> 使用極端尺度差、大量黑色負空間與安靜的中央構圖。視線順序必須是「人類意圖 → 被越過的工具 → 具有重量的完成結果」。主色為深黑、炭灰、冷白、低飽和木色與少量暗金；柔和體積光、深陰影、細緻電影顆粒、高級雜誌封面質感。整體感覺是精準、克制、具體而不魔法化。

### 封面專用負面 Prompt

> 套用共用負面 Prompt；另外不要把收納架畫成抽象金色獎盃、寶箱、魔法物品或家具廣告，不要讓工具堆成垃圾或廢墟，不要讓人物跪下、按鍵、操作滑鼠或被光線牽引，不要加入農田、旅行箱、會計數字等多重主題。

### 驗收標準

- 縮成手機縮圖後仍能看見「小人物、工具群、具體完成物件」三層關係。
- 收納架必須像可使用、可驗收的實物，而不是願望或抽象答案。
- 工具被越過但沒有消失，符合「軟體退到幕後」的系列命題。
- 暗金意圖是路徑起點，完成結果是第二焦點；工具不得搶光。

## 圖二｜文中概念圖

### 名稱

**〈功能的重量，結果的輕盈〉**

### 建議位置

放在「下一代的競爭公式」段落、公式前後皆可。

### 核心 Prompt

> 一張橫向 16:9 的超現實電影感編輯插畫，延續《AI 即一切》的深黑、冷灰、冷白與暗金視覺。畫面中央是一座極精密的雙臂天平，但它不是商業圖示，而是一件巨大、沉重、具有建築尺度的黑色金屬裝置。左側托盤堆滿代表取得結果總成本的物件：厚重的操作手冊、密集的無字表格、重疊的視窗框架、等待中的沙漏、斷裂的路徑、沉重的石塊與一盞即將熄滅的冷白燈。這些物件象徵學習時間、操作摩擦、等待、錯誤風險與注意力，但不能出現文字或數字。
>
> 右側托盤只有一個小而完整的暗金色結果：一個已經澆灌、健康生長的幼苗，根系穩定地嵌在一小塊真實土壤中；幼苗不是奇幻植物，而是清楚可被照料、觀察與驗收的生命。右側結果雖然小，卻讓天平穩定地向右側傾斜。畫面下方，一個極小的人類背影站在天平中央，沒有推動任何一側，只用手中的暗金意圖之光照亮右側結果。冷灰工具被光線壓低，暗金幼苗與人物之間形成安靜的視覺連線。
>
> 構圖只表達一個衝突：「功能很多不代表取得結果的成本很低」。大量負空間、低調方向光、霧面材質、細緻顆粒與哲學雜誌插畫質感。不可做成商業資訊圖、公式海報或直白的效率宣傳。

### 概念圖專用負面 Prompt

> 套用共用負面 Prompt；另外不要出現可辨識公式、數字、貨幣符號、百分比、文字標籤、商業簡報天平、金幣、獎盃、股票圖表、巨大農田或枯死植物，不要把結果畫成抽象光球，不要讓天平看起來像公平比較產品功能。

### 驗收標準

- 左側能感受到時間、注意力與操作摩擦的重量，但不依賴文字說明。
- 右側結果必須具體、可觀察、可驗收，而不是「成功」的符號。
- 人類站在中央保持判斷權，不是被 AI 代替或被天平操控。
- 畫面能承接「消費價值 ≈ 結果品質 ÷ 取得結果的總成本」的思想。

## 圖三｜結尾餘韻圖

### 名稱

**〈意圖在現實世界裡獲得形狀〉**

### 建議位置

放在「當意圖開始在現實世界裡獲得形狀」段落之後，或結尾導航之前。

### 核心 Prompt

> 一張橫向 16:9 的極簡超現實電影感編輯插畫。畫面左側是一個極小、側背向的人類站在深黑色書桌旁，姿態平穩，不露臉。書桌上有鍵盤、耳機與充電器，但它們只作為尺度參照，不成為主體。人物胸口與手掌之間有一點克制的暗金色意圖之光，這束光沿著一條極細而清楚的線，穿過黑暗空間，向右側延伸。
>
> 右側是一座剛剛完成的桌面收納架，直接放在真實書桌上；它的尺寸與鍵盤、耳機、充電器相互匹配，留出插座位置，結構簡潔、穩定、可使用。收納架由溫暖木色、炭灰與極少量暗金邊緣構成，像一件已通過驗收的實物。它不是發光的未來產品，也不是豪華家具，而是恰好解決需求的普通而精準的物件。金線終點落在收納架上，表示人的意圖越過螢幕，在現實中獲得形狀。
>
> 金線兩側遠處只有極淡的冷灰工具殘影：建模網格、材料樣本、測量線與 3D 列印路徑，它們像被完成結果留在身後的工作痕跡，不可搶過實物。整體極度安靜，大量黑色負空間，視線從人物沿金線抵達收納架。霧面黑、冷灰、低飽和木色、少量暗金，柔和體積光，細緻電影顆粒，高級哲學雜誌插畫；沒有科技奇觀，只有意圖、驗證與落地。

### 餘韻圖專用負面 Prompt

> 套用共用負面 Prompt；另外不要把收納架畫成金色獎盃、魔法門、漂浮物、豪宅家具或 3D 印表機廣告，不要讓金線變成電纜、雷射或鎖鏈，不要出現尺寸標註、工程文字、CAD 軟體畫面、產品 Logo、多人或多條路徑。

### 驗收標準

- 縮圖後仍能看見「人類意圖 → 金線 → 可使用實物」的單一路徑。
- 收納架具有真實重量與功能細節，能被想像成真的完成品。
- 工具與 AI 只留下淡淡痕跡；結果比工具更接近觀眾。
- 情緒是安靜、具體、可信，而不是魔法或未來科技炫技。

## 三張圖的一致性鎖定句

分批生成時，請在每張 Prompt 最後追加：

> 延續同一套《AI 即一切》視覺世界：同一位不露臉、比例渺小、姿態穩定的人類；相同的霧面深黑背景、冷灰工具結構、冷白細節與低飽和暗金意圖之光；暗金只屬於人類意圖與已驗收的結果。工具永遠存在但退到幕後，AI 不以機器人、人臉或數位大腦出現；使用超現實建築式象徵、克制電影光線、細緻顆粒與高級編輯插畫質感。

## 建議生成順序

1. 先生成封面，鎖定人物比例、收納架造型、木色與暗金色。
2. 以封面人物與色彩作為圖二、圖三的視覺參考。
3. 生成後並排縮成手機列表尺寸檢查：封面負責提出「工具與結果」的反差，概念圖負責呈現成本重量，餘韻圖負責讓意圖落地。
4. 若出現可讀文字、機器人、科技廣告感或抽象光球，直接重生，不以局部修補保留錯誤構圖。
