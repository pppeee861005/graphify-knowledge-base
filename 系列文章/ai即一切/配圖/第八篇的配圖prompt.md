# 《AI 即一切》第八篇配圖 Prompt

**副題**：下一代市場裡，人類甚至不必親自進場

## 共用規格

橫向 16:9、宏大而克制的超現實市場編輯插畫，宇宙黑、深紫、價值金與治理紅。用無身體光點、授權鑰匙、交易星座與地下基礎設施表現 Agent 市場；不畫人類被排除、不畫投機廣告、不讓 Agent 未經授權花錢。無可讀文字、Logo、浮水印或加密貨幣符號。

## 圖一｜封面主視覺

### 〈沒有人的夜市，仍在交易〉

> 一座無限延伸的夜間市場像城市與宇宙的混合體，攤位自行開門、交換與結算，市場中沒有任何人類。無數沒有身體的深紫與暗金光點攜帶微小錢包，在空中形成有秩序的交易星座；每個光點只沿著受限的金色路徑移動。市場外圍站著一位極小的人類，手握一枚能讓整座市場暫停的紅色印章。地面下方露出平台、支付、物流、身份與合約基礎設施的根系，顯示平台沒有消失，只退到幕後。宏大、著迷、制度性警覺。

**避免**：加密貨幣投機、金幣海、無授權花錢、機器人商人、空蕩末日城市、Logo、文字。

## 圖二｜文中概念圖

### 〈授權被鑄造成河道〉

> 黑暗高處，一位渺小人類放下一把暗金色鑰匙。鑰匙落下後不是武器，而是鑄造成一組具有寬度、方向與閘門的河道；數個小型 Agent 光點與錢包沿河道流動，彼此發現、比較、交換，但不能越過紅色閘門。小額低風險流動已經通過，遠方一筆巨大交易被紅色閘門凍結，等待人類確認。畫面具體呈現預先授權、限額、審計與撤銷，而不是自由失控。

**避免**：河流中的金幣、金融廣告、無限自由資金、文字流程圖、加密貨幣標誌、AI 臉孔。

## 圖三｜系列最終餘韻圖

### 〈世界背後的世界〉

> 畫面表面只有一位平靜而渺小的人類站在深黑空間中，手中持有一點暗金意圖之光。畫面像剖開地面般向下展開：地下依序可見由介面花、一次性控制室、DXF 向量藍圖、可運行遊戲世界、跨工具電腦道路、繞城新路與無人交易市場組成的深層文明；每一層都在安靜運作，彼此由一條細金線連回人的手。所有平台與工具仍存在，只是離開人類視線。不要做成資訊圖或八格拼貼，而是一個連續、深邃、具有地下城市根系的世界。最亮處只屬於人的意圖與授權。

**避免**：拼貼、分鏡、八個獨立圖示、末日地底、機器統治、文字、Logo、過度明亮科技城市、宗教救世主構圖。

## 一致性鎖定句

> 延續整季的渺小穩定人類、霧面深黑與暗金意圖線；本篇讓暗金最豐富，但紅色永遠只代表治理、凍結、確認與撤銷。平台、工具與市場仍在運作，只是退到人類視線之外。
