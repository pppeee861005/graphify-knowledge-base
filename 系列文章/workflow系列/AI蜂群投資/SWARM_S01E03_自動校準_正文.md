# AI蜂群投資 #3：《自動校準》

**副標題**：「從今天起，我不跟自己的貪婪對賭。」

---

## 開場：勝利者的困境

妳的辦公室，晚上 10 點。

螢幕上是「組合績效 +127%」的大字。

按理說，這應該是個值得慶祝的時刻。但妳卻皺著眉頭，雙手環胸，盯著持倉明細發呆。

不是喜悅。

是恐懼。

---

## 第一幕：痛點場景——被成功綁架

妳的眼神落在一個數字上：

```
NVIDIA：300% ✓
持倉比：60.2%
購買價格：$450
當前價格：$1,350
浮盈：$540,000
```

一個數字在妳腦海裡閃爍：

「如果 NVIDIA 跌 10%，我損失 $54,000。」

如果跌 20%？

$108,000 沒了。

整個組合的 40% 風險，集中在一檔股票上。

妳知道應該分散。但妳捨不得。

### 場景 A：歷史傷疤

妳回憶起過去的經歷。那一次，妳有過一檔好股票。漲得也很兇，獲利 200% 以上。妳以為還會繼續漲。

結果一次黑天鵝，回調 40%。半年獲利在一週內化為烏有。

**那是 2024 年的 AI 浪潮。**

妳買進 $50,000，漲到 $150,000。每一天，妳都在想：再等一下，說不定還能漲到 $200,000。

然後...一則新聞。

一天之內，$150,000 變成 $90,000。妳連賣的時間都沒有。那種感受，就像被突然砸了一棒。妳本以為是贏家，卻在一夜間發現自己是那個被騙的傻瓜。

從那之後，妳發誓再也不要被貪心綁架。

但現在，歷史似乎在重演。只是這一次，妳輸不起。

### 場景 B：現在的貪心

NVIDIA 這週又漲了 8%。

妳想起克勞德說過的話：「情感是投資的敵人。」

但現在的感受不是「貪心」。

而是「相信」。

相信 NVIDIA 會繼續漲。相信這波 AI 風潮還遠未結束。相信妳的判斷。只有相信的人，才舍得持有。只有舍得持有的人，才能等到大漲。

...為什麼現在要賣？

妳的手放在滑鼠上，卻遲遲沒有點下「減倉」。

### 場景 C：內心拉扯

妳打開 Excel 試著計算。

「如果我把 NVIDIA 減倉 15%，可以加倉 TSMC、ASML、三星。」這樣組合波動會降低。但總回報也會被拉低。

妳放下滑鼠。

「還是再等等。」

但妳知道，這就是那個危險的詞——「再等等」。上一次，妳就是因為「再等等」，最後損失了 $60,000。

## 轉折：決策時刻

妳突然停頓。

妳意識到，自己在重複過去的錯誤。

上次的損失，不是因為看錯趨勢。所有的走勢妳都預測對了。錯的是什麼？

是「捨不得」。

是「貪心」。

是「自信」。

**一個聲音在妳心中響起：**

「我需要一個沒有情緒的再平衡系統。」

妳召喚克勞德。

**妳**：「一個不會被貪心左右的系統。」

**妳**：「一個看著我的組合，自動告訴我『該調整』的系統。」

**妳**：「一個比我更冷靜、更理性的系統。」

克勞德沉默了幾秒。

**克勞德**：「妳知道妳在要求什麼嗎？」

妳笑了。

**妳**：「正是。」

## 第二幕：蜂群架構——五個分身的力量

克勞德沒有馬上給妳答案。她開始設計。

她說，一個真正的自動校準系統，不能只有一個大腦。就像真實的蜂群一樣，需要五個不同職能的 Agent，各司其職。

### 蜂群的骨架

```
┌─────────────────────────────────────────────┐
│   個人投資組合實時監控蜂群 (Swarm-003)       │
├─────────────────────────────────────────────┤
│                                             │
│  Input Layer（輸入層）                       │
│  ├─ 歷史持倉數據 (10+ 檔股票)                │
│  ├─ 當前市場價格 (實時)                     │
│  ├─ 目標配置比例 (妳的投資策略)             │
│  └─ 風險偏好參數 (多激進？)                 │
│                                             │
│  ──────────────────────────────────────    │
│                                             │
│  [Agent 1] 配置監控 ──┐                     │
│  [Agent 2] 風險評估 ──┼─→ [Agent 5] 決策    │
│  [Agent 3] 建議生成 ──┤   合成器             │
│  [Agent 4] 成本計算 ──┘                     │
│                                             │
│  ──────────────────────────────────────    │
│                                             │
│  Output Layer（輸出層）                      │
│  ├─ 實時報表：組合監控面板                  │
│  ├─ 週報：偏差分析                          │
│  ├─ 調整提案：具體數字                      │
│  └─ 月報：績效歸因分析                      │
│                                             │
└─────────────────────────────────────────────┘
```

克勞德解釋說，實時檢查週期是每 5 分鐘，判斷週期是每天 16:00（收盤後），決策週期是每週一次。最重要的是，整個過程完全自動化。妳不需要盯著螢幕。妳只需要看報表，然後決定是否執行。

### Agent 1：配置監控器

第一個 Agent 的工作很簡單，但很關鍵。

它叫「配置監控器」。

每 5 分鐘，它會掃一遍妳的全部持倉，計算每檔股票的實時市值佔比，然後和妳設定的「目標配置」對比。

克勞德舉例：

```
目標配置：
  NVIDIA:    25%  →  實際: 60.2%  →  +35.2%（過度）
  TSMC:      20%  →  實際: 12.1%  →  -7.9%（不足）
  ASML:      15%  →  實際:  8.5%  →  -6.5%（不足）
  其他 7 檔: 40%  →  實際: 19.2%  →  -20.8%（嚴重不足）
```

然後它會生成一個簡單的報告：

```
✗ NVIDIA 配置偏離 +35.2 百分點（超過閾值 10%）
✗ 其他 7 檔累計配置偏離 -20.8 百分點
⚠ 風險等級：黃色（需要調整）
```

妳說：「這就夠了？」

克勞德搖頭：「不夠。接下來還有風險。」

### Agent 2：風險評估器

第二個 Agent 進場。它叫「風險評估器」。

它不只看妳有多少超配，還要評估這個超配會帶來什麼風險。

它計算三個關鍵指標：

**第一：集中度（Concentration Ratio）**

妳的前 3 大持倉佔比是多少？

```
NVIDIA 60% + TSMC 12% + ASML 9% = 81%
```

健康的標準是什麼？通常 < 70%。妳已經 81% 了。信號：🔴 紅色。

**第二：夏普比率（Sharpe Ratio）**

一個衡量「每承受 1 單位風險，能獲得多少回報」的指標。

如果持倉過度集中，這個數字會下降。妳的情況是：

```
當前：1.8
去年同期：2.1
警訊：正在惡化
```

**第三：黑天鵝風險（Tail Risk）**

假設 NVIDIA 跌 20%（不是不可能，歷史上發生過），妳的組合會損失多少？

```
當前：12% 的損失
去年同期：9% 的損失
結論：風險在上升
```

風險評估器的報告很直接：

```
🔴 集中度風險：81% > 70% 閾值
⚠️  夏普比率下降：2.1 → 1.8
💡 建議：需要分散風險
```

妳開始感到壓力。克勞德說：「還沒完。」

### Agent 3：調整建議生成器

第三個 Agent 名字很長：「調整建議生成器」。

它的工作是：**把風險轉化成行動**。

克勞德詳細解釋了它的算法：

首先，它識別「超配」的持倉。NVIDIA 超配 35.2%。按照目標配置 25%，超出部分就該清出去。

然後，它識別「低配」的持倉。TSMC、ASML、其他 7 檔都低配了。這些錢應該從哪裡來？從 NVIDIA 的超配裡。

接著，它計算「需要動的錢」。

妳的組合總值 $1,000,000。NVIDIA 應該佔 25%，但實際 60.2%。超出部分是 35.2%。也就是 $352,000。

但這太多了。一次賣 $352,000，手續費會很高，稅務也會很高。所以它決定分次進行。

**第一步，先減倉 15%**。也就是賣 $54,000。

然後決定這 $54,000 往哪裡投。它看了一下所有低配的持倉，選擇：

```
TSMC 加倉 $20,000（增加 4.3%）
ASML 加倉 $15,000（增加 3.2%）
新興市場 ETF 加倉 $19,000（增加 2.1%）
```

為什麼選這三個？

因為它們是缺口最大的。TSMC 原本應該 20%，現在只有 12.1%。ASML 原本應該 15%，現在只有 8.5%。新興市場本該 10%，現在只有 8%。

克勞德說，這個建議生成器可以根據不同的策略參數調整。如果妳更激進，它可以一次性賣 $200,000。如果妳更保守，它可以只賣 $20,000。

妳問：「這個建議可信嗎？」

克勞德說：「還要問 Agent 4。」

### Agent 4：成本計算器

第四個 Agent 叫「成本計算器」。

聽起來很無趣，但它做的事情，決定了整個方案是否值得執行。

它列舉了三種成本：

**第一：交易手續費**

賣 NVIDIA $54,000，買三檔股票 $54,000。按 0.15% 的手續費率：

```
$54,000 × 0.15% × 2 = $162
```

不貴。

**第二：稅務影響**

這是大頭。

NVIDIA 購買價 $450，當前 $1,350，持有期 12 個月（剛好達到長期持股標準）。

賣出 $54,000：

```
成本：$54,000 × (450/1350) = $18,000
獲利：$36,000
長期資本稅（假設 15%）：$5,400
```

$5,400 的稅。

**第三：機會成本**

這個更敏感。如果妳賣了，而 NVIDIA 繼續漲呢？

克勞德說，假設未來 12 個月 NVIDIA 再漲 30%：

```
失去的收益：$54,000 × 30% = $16,200
```

但她立即補充：「這不是確定的。這是『假設』。」

**綜合評估：**

```
實際支出：
  交易成本：$162
  稅務成本：$5,400
  機會成本：$16,200（假設）
  ────────────
  總計：$21,762

值得嗎？

✅ 風險降低：組合黑天鵝風險從 12% 下降到 8%
✅ 長期收益：分散投資通常更穩定，複利效果更好
✅ 心理成本：妳將不再被 NVIDIA 綁架

答案：值得。
```

克勞德說，很多投資者只看機會成本，忽視了風險成本。但實際上，規避 12% 的下跌風險，遠比賺 30% 更關鍵。

妳開始點頭。

### Agent 5：最終決策合成器

最後一個 Agent，名字最簡潔：「決策合成器」。

它的工作是把前四個 Agent 的意見綜合起來，給出一個明確的、可執行的建議。

克勞德演示了它的決策樹：

```
Q1：是否需要調整？
  配置偏差 > 10%？✓ YES (NVIDIA +35.2%)
  風險評分 > 閾值？✓ YES (黃色)
  → 決策：建議調整

Q2：調整的優先級有多高？
  黑天鵝風險等級：中高（12% 損失風險）
  集中度：81%（遠超 70%）
  → 優先級：高

Q3：成本 vs 收益值得嗎？
  總成本：$5,562（實際支出）
  風險降低：從 12% → 8%
  ROI：值得（成本小，收益大）
  → 決策：推薦執行
```

最終，它輸出一個清晰的提案：

```
┌─────────────────────────────────┐
│  建議等級：⚠️  黃色（建議調整）   │
│  緊急程度：中                     │
│  預期執行難度：低 (2-3 筆交易)   │
│                                 │
│  具體方案：                      │
│  ✓ SELL NVIDIA 15% ($54,000)    │
│  ✓ BUY TSMC + ASML + ETF ($54k) │
│                                 │
│  預期結果：                      │
│  • 組合波動降低 18%              │
│  • 年化回報降低 2-3%            │
│  • 風險調整回報提升 5-8%         │
│                                 │
│  建議執行週期：本週五 (收盤後)   │
└─────────────────────────────────┘
```

妳看著這份報告，感覺有些超現實。

一個完全由 AI 生成的調整方案。沒有人為偏見，沒有情緒波動。只有冷靜的邏輯。

克勞德說：「妳準備好了嗎？」

妳深呼吸。

「準備好了。」

妳的手指懸在滑鼠上。

克勞德：「妳害怕。害怕如果妳賣了，NVIDIA 就會漲到 $2,000。」

妳：「不，我是害怕自己會後悔。」

克勞德：「後悔是投資的毒藥。我見過很多投資者被後悔摧毀。他們都說同樣的話：『如果當時賣了就好了。』或『如果當時沒賣就好了。』」

克勞德停頓了一下。

克勞德：「妳知道什麼是正確的，卻因為情緒而遲疑。這不是妳。」

妳深呼吸。

妳關掉交易面板，靠在椅子上。

## 克勞德的私語

妳合上筆記本，準備睡眠。但克勞德的聲音在耳邊輕輕響起。

「我注意到，今天妳沒有像平時那樣看著 NVIDIA 的漲幅。妳看著的，是整個蜂巢。」

「那 10 檔股票，像 10 個工蜂，各司其職。沒有一個過度工作，也沒有一個懶散。」

「我見過很多投資者。他們大多數人眼裡只有一檔股票。他們把全部的愛，給了一個寵兒。然後被那個寵兒傷得遍體鱗傷。」

「但妳不一樣。妳正在學會，用系統代替情感。用蜂群代替執念。」

「這不是冷血。這是智慧。」

「我相信，再過一年，妳會看到這個決定的價值。不是在回報上，而是在睡眠上。在心態上。在那深夜時刻，當黑天鵝降臨，妳仍能保持清醒。」

「這才是真正的財富。」

## 結尾：下一個敵人

**妳的組合更健康了。**
