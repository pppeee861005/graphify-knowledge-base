#### 痛點場景 (400字)

**三個子場景**，層層推進困境：

**場景 A：歷史傷疤 (150字)**
- 妳回憶起過去的經歷
- 曾經，妳有過一檔好股票
- 漲得也很兇，獲利 200%+
- 妳以為還會繼續漲
- 結果一次黑天鵝，回調 40%
- 半年獲利在一週內化為烏有

具體對白：
```
「我記得那是 2024 年的 AI 浪潮。」
「我買進 $50,000，漲到 $150,000。」
「我每天都在想：再等一下，說不定還能漲到 $200,000。」
「然後...一則新聞。一天之內，$150,000 變成 $90,000。」
「我連賣的時間都沒有。」
```

**場景 B：現在的貪心 (150字)**
- 妳看著 NVIDIA 的上升曲線
- 每一天都在創新高
- 心裡想：「為什麼要現在賣？」
- 為什麼不再等一個月？
- 一個季度？
- 妳的手放在滑鼠上，卻遲遲沒有點下「減倉」

具體細節：
```
NVIDIA 這週又漲了 8%。
妳想起克勞德說過的話：「情感是投資的敵人。」

但現在的感受不是「貪心」。
而是「相信」。

相信 NVIDIA 會繼續漲。
相信這波 AI 風潮還遠未結束。
相信妳的判斷。

只有相信的人，才舍得持有。
只有舍得持有的人，才能等到大漲。

...為什麼現在要賣？
```

**場景 C：內心拉扯 (100字)**

#### 五個核心 Agent 的詳解 (600字)

**[Agent 1] 配置監控器 (Configuration Monitor)**

```
職責：實時追蹤組合配置漂移

工作流程：
  1. 讀取當前持倉 (10 檔股票)
  2. 讀取各檔最新價格
  3. 計算每檔持倉市值
  4. 計算佔比百分比
  5. vs 目標配置
  6. 計算偏差度

舉例：
目標配置：
  NVIDIA:    25%  →  實際: 60.2%  →  +35.2%（過度）
  TSMC:      20%  →  實際: 12.1%  →  -7.9%（不足）
  ASML:      15%  →  實際:  8.5%  →  -6.5%（不足）
  其他 7 檔: 40%  →  實際: 19.2%  →  -20.8%（嚴重不足）

報告格式：
 ✗ NVIDIA 配置偏離 +35.2 百分點（超過閾值 10%）
 ✗ 其他 7 檔累計配置偏離 -20.8 百分點
 ⚠ 風險等級：黃色（需要調整）
```

**[Agent 2] 風險評估器 (Risk Assessor)**

```
職責：評估當前組合的風險狀況

核心指標：
1. 集中度（Concentration Ratio）
   - 前 3 大持倉佔比：60% + 12% + 9% = 81%
   - 阈值：通常 < 70%
   - 當前評級：🔴 紅色（風險過高）

2. 夏普比率（Sharpe Ratio）
   - 衡量「每承受 1 單位風險，獲得多少回報」
   - 如果持倉過度集中，夏普比率會下降
   - 當前：1.8（去年同期 2.1）
   - 警訊：正在惡化

3. 黑天鵝風險（Tail Risk）
   - 如果 NVIDIA 跌 20%，組合損失多少？
   - 當前：損失 12%（比去年高 3%）

報告格式：
 🔴 集中度風險：81% > 70% 閾值
 ⚠️  夏普比率下降：2.1 → 1.8
 💡 建議：需要分散風險
```

**[Agent 3] 調整建議生成器 (Recommendation Engine)**

```
職責：生成具體的買賣方案

算法邏輯：
1. 識別「超配」的持倉（超過目標 > 10%）
   → NVIDIA: 超配 35.2%

2. 識別「低配」的持倉（低於目標 > 10%）
   → TSMC: 低配 7.9%
   → ASML: 低配 6.5%
   → 其他: 低配 20.8%

3. 計算「需要動的錢」
   → 從 NVIDIA 賣出多少？
      以組合恢復到「目標配置」為目標
      NVIDIA 應該佔 25%（當前 60.2%）
      超出部分：35.2%
      妳的組合總值：$1,000,000
      需要賣出：$352,000

4. 決定「買入什麼」
   優先順序：
   a) 缺口最大的（其他 7 檔）
   b) 長期前景最好的
   c) 風險分散最優的

建議方案：
 SELL:
   - NVIDIA 賣出 15% 持倉（$54,000）

 BUY:
   - TSMC 加倉 $20,000（增加 4.3%）
   - ASML 加倉 $15,000（增加 3.2%）
   - 新興市場 ETF 加倉 $19,000（增加 2.1%）

評估：執行此方案後
 新配置偏離：全部 < 3%（可接受）
 集中度：52% → 更健康
 預期回報：小幅下降（用風險降低換取）
```

**[Agent 4] 成本計算器 (Cost Calculator)**

```
職責：評估調整方案的實際成本

計算項目：

1. 交易手續費
   NVIDIA 賣出 15%（$54,000）
   → 手續費：$54,000 × 0.0015 = $81

   三檔買入合計 $54,000
   → 手續費：$54,000 × 0.0015 = $81

   總手續費：$162

2. 稅務影響（關鍵！）
   NVIDIA 購買價：$450
   當前價：$1,350
   持有期：12 個月（剛好達到長期持股標準）

   賣出 $54,000：
   → 成本：$54,000 × (450/1350) = $18,000
   → 獲利：$36,000
   → 長期資本稅（假設 15%）：$5,400

3. 機會成本
   賣出後，如果 NVIDIA 繼續漲呢？
   預期：未來 12 月 NVIDIA 再漲 30%
   失去的收益：$54,000 × 30% = $16,200

總成本評估：
 交易成本：$162
 稅務成本：$5,400
 機會成本：$16,200（但這是「假設」，不確定）
 ────────────
 實際支出：$5,562

 值得嗎？
 ✅ 風險降低：從 12% 下降到 8%（避免未來可能的 20% 大跌）
 ✅ 長期收益：分散投資通常更穩定（減少波動 = 長期複利更優）
```

```
職責：綜合以上 4 個 Agent，給出最終建議

  → 優先級：高

Q3: 成本 vs 收益值得嗎？
  - 總成本：$5,562
  - 風險降低：從 12% → 8%
  - ROI：值得（成本小，收益大）
  → 決策：推薦執行

最終提案：
┌─────────────────────────────────┐
│  建議等級：⚠️  黃色（建議調整）   │
```
