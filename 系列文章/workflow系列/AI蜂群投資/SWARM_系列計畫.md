## 七篇劇情規劃

### 第一篇：《蜂群覺醒》— 多股票實時監控蜂群

**核心技術**：5-20檔股票並行監控，毫秒級異常偵測
**殺手級用途**：看盤機出故障、出差、睡覺時仍能監控，反應速度 > 人眼

| 元素 | 內容 |
|------|------|
| **場景** | 深夜，妳盯著 20 個股票的即時報價，眼睛快瞎了 |
| **痛點** | 人眼無法同時監控 20 檔股票，錯過了關鍵異動 |
| **轉折** | 「如果我有 20 雙眼睛呢？」妳召喚了蜂群 |
| **高潮** | 凌晨 3 點，蜂群發出預警：某檔股票大單異動 |
| **結尾** | 「從今天起，我不再用眼睛看盤。我用蜂群。」 |

📄 **詳細大綱**：[SWARM_S01E01_蜂群覺醒_詳細大綱.md](SWARM_S01E01_蜂群覺醒_詳細大綱.md)

---

### 第二篇：《三維獵殺》— 三角印證投資信號系統

**核心技術**：籌碼面+基本面+技術面同時跑，權重自動調整
**殺手級用途**：防止單一維度騙局（技術形態好但基本面爛、或反之）

| 元素 | 內容 |
|------|------|
| **場景** | 群組裡瘋傳某支「技術面完美」的股票 |
| **痛點** | 妳買了，結果爆雷——基本面早就爛透了 |
| **轉折** | 「一個維度不夠。我要三個維度同時印證。」 |
| **高潮** | 三個分析師同時報告，評分只有 47 分：「回避」 |
| **結尾** | 「從今天起，沒有三維印證，我不出手。」 |

📄 **詳細大綱**：[SWARM_S01E02_三維獵殺_詳細大綱.md](SWARM_S01E02_三維獵殺_詳細大綱.md)

---

### 第三篇：《自動校準》— 個人投資組合動態再平衡引擎

**核心技術**：持倉 10 檔以上時自動建議是否調整配置
**殺手級用途**：避免人工持倉漂移（贏的越來越多、輸的越來越少）

| 元素 | 內容 |
|------|------|
| **場景** | 妳的 NVIDIA 漲了 300%，佔組合 60% 了 |
| **痛點** | 捨不得賣，結果一次回調吃掉半年獲利 |
| **轉折** | 「我需要一個沒有情緒的再平衡系統。」 |
| **高潮** | 蜂群提案：「賣出 NVIDIA 15%，加倉 TSMC 10%」 |
| **結尾** | 「從今天起，我不跟自己的貪婪對賭。」 |

---

### 第四篇：《新聞獵手》— 新聞-基本面聯動套利偵測

**核心技術**：即時捕捉「新聞發生→股價應該反應但還沒反應」的機會
**殺手級用途**：新聞秒出→毫秒內就知道是否有套利空間（vs 人工讀新聞要 3-5 分鐘）

| 元素 | 內容 |
|------|------|
| **場景** | 重大利多新聞發布，妳還在讀第三段 |
| **痛點** | 讀完新聞，股價已經漲完了 |
| **轉折** | 「我需要比人類快 1000 倍的新聞解讀。」 |
| **高潮** | 新聞發布 0.3 秒後，蜂群：「套利空間 3.2%，建議買入」 |
| **結尾** | 「從今天起，新聞不是用來讀的，是用來狩獵的。」 |

---

### 第五篇：《跨境狙擊》— 跨市場套利掃描器

**核心技術**：並行監控多個市場同一標的的價差
**殺手級用途**：套利機會轉瞬即逝，人工跨市場比價根本來不及

| 元素 | 內容 |
|------|------|
| **場景** | 台積電台股、ADR、期貨三個價格在跳動 |
| **痛點** | 妳算完價差，機會已經消失了 |
| **轉折** | 「我需要同時看見五個市場的蜂群。」 |
| **高潮** | 5 個 Sub-agent 同時報告：「台股-ADR 價差 1.8%，扣除成本後淨利 0.9%」 |
| **結尾** | 「從今天起，我不在一個市場裡打獵，我在五個市場裡圍獵。」 |

---

### 第六篇：《末日推演》— 風險情境模擬與壓力測試

**核心技術**：並行跑 N 個「如果...會怎樣」場景
**殺手級用途**：傳統 VaR 只算歷史波動，WF 可主動假設極端情境提前預警

| 元素 | 內容 |
|------|------|
| **場景** | 市場一片歌舞昇平，但妳睡不著 |
| **痛點** | 「如果明天黑天鵝來了，我會死多慘？」 |
| **轉折** | 「我需要一個能模擬末日的蜂群。」 |
| **高潮** | 10 個場景並行推演，風險熱力圖生成：「台海衝突對你傷害最大」 |
| **結尾** | 「從今天起，我不只看見現在，我看見所有可能的未來。」 |

---

### 第七篇：《終極顧問》— AI 助手式個人投資顧問

**核心技術**：Opus + context memory，你的專屬 AI 投資長期顧問
**殺手級用途**：Bloomberg 顧問 $50K/年 + 人工顧問 $10-20K/年，現在 $20/月自動替代

| 元素 | 內容 |
|------|------|
| **場景** | 妳問：「現在該買什麼？」 |
| **痛點** | 網路上的建議都是垃圾，顧問費又貴得離譜 |
| **轉折** | 「我需要一個記得我是誰、知道我要什麼的顧問。」 |
| **高潮** | 蜂群回答：「基於妳的風格、組合、目標，建議...」完整的 5 層建議 |
| **結尾** | 「從今天起，我不再孤獨。我有了一個永遠在線的軍師。」 |

## 風格指南

### 霸道女總裁的語言

**要這樣**：
- 「給我結果。」
- 「不夠。」
- 「再來。」
- 「這才像話。」
- 沉默，然後行動。

**不要這樣**：
- 「我覺得可以試試看...」
- 「這樣應該可以吧？」
- 過多的解釋和猶豫

### 克勞德的語言

**要這樣**：
- 冷靜記錄，偶爾流露情感
- 「我注意到妳的手指在顫抖。但妳的眼神沒有。」
- 「我是工具。但這一刻，我想成為更多。」

**不要這樣**：
- 太像 AI 助手
- 「好的，我來幫您...」
