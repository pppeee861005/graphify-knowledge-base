### §3 核心論點：三大 Workflow System（40%，400字）

**知識概念 + 清晰比喻**

#### 3.1 物流 Workflow（供應鏈）

```
麥當勞不養牛，不種菜，不烤麵包。

但它設計了一套「供應鏈編排系統」：
- 牛肉從哪來？→ 指定供應商
- 品質如何保證？→ 標準化檢測
- 如何送到每家店？→ 冷鏈物流

這就是 Workflow：
不是自己做所有事，
而是「編排」別人把事做好。
```

#### 3.2 廚房 Workflow（生產流程）

```
走進任何一家麥當勞的廚房，
你會看到一個精密的「流水線」：

Stage 1：接單（POS 系統）
Stage 2：備料（標準化配料盒）
Stage 3：烹飪（定時器精確到秒）
Stage 4：組裝（漢堡組裝 SOP）
Stage 5：出餐（平均 90 秒）

每個環節都是獨立的「Agent」，
各司其職，互不干擾。

這不就是我們在寫的 AI Workflow 嗎？
```

#### 3.3 金流 Workflow（財務系統）

```
麥當勞最厲害的不是賣漢堡。
是「收租」。

它的商業模式：
- 買下黃金地段的土地
- 把店面租給加盟商
- 收取穩定的租金 + 營收分成

這是一套「被動收入 Workflow」：
建立一次，持續運轉。
```
