## 核心觀念

### 1. 古埃及加工假說的基本模型

目前形成的候選工程模型是：

```text
人的推拉力量
→ 木製弓鑽、木桿或轉軸提供反覆旋轉
→ 銅管集中壓力並限制孔洞形狀
→ 水或其他液體攜帶磨料與碎屑
→ 高硬度磨料實際切削石材
→ 微小磨耗經長時間累積形成切口或鑽孔
```

此模型在物理原理上合理，也有管鑽岩芯與實驗研究作為部分支持，但不能直接當成古埃及施工紀錄的完整還原。

### 2. 為什麼這個故事同時屬於物理飛輪與思想飛輪

使用者的核心理解：古埃及工匠採用的方式，非常接近物理上的飛輪，也接近思想上的飛輪。

精確表述：

- 古代管鑽未必是嚴格機械定義下，用來儲存旋轉動能的飛輪盤。
- 但反覆旋轉、微小作用累積，以及前一圈替下一圈留下路徑的方式，符合飛輪的核心精神。
- 思想飛輪同樣由小量知識、意外連接、假說、查證、修正與回寫逐圈累積。

共同公式：

> 把微小、可重複的力量送進循環，最後完成單次力量不可能完成的工作。

### 3. Graphify 找到的是橋，不是終局答案

Graphify 可以連接：

```text
高硬度磨料
→ 研磨與鑽孔
→ 軟金屬可作為磨料載體
→ 銅管鑽
→ 古埃及銅加工
→ 吉薩花崗岩岩芯
→ 巨石加工假說
```

但關係只能產生「值得查證的橋」。橋的另一端是否為歷史事實，仍要檢查館藏、原始研究、實驗結果與反證。

完整知識飛輪是：

```text
連接 → 推理 → 查證 → 反證 → 修正 → 回寫 → 再次連接
```

### 4. 必須維持四層證據

| 層級 | 定義 | 本系列例子 |
|---|---|---|
| A｜直接證據 | 有可定位的遺物、館藏或同期紀錄 | 吉薩出土的管鑽花崗岩岩芯 Core 7 |
| B｜實驗支持 | 能重現某些效果或痕跡，但不是歷史唯一答案 | 銅管搭配不同磨料鑽削花崗岩的實驗 |
| C｜合理推論 | 符合材料與工程條件，但缺直接證據 | 木製旋轉裝置、銅管、液體與磨料的系統模型 |
| D｜開放猜想 | 有啟發性，但證據鏈仍不足 | 古埃及是否使用金剛石磨料 |

關鍵原則：

- 「可以做到」不等於「當時一定這樣做」。
- 「痕跡相似」不等於「工具身分已確認」。
- 「不能排除金剛石」不等於「已證實使用金剛石」。
- 單一鑽孔實驗不能解釋整座金字塔的所有工程。

### 5. 現代磨料水刀的埃及回聲

原始疑問是：「現代工業最前沿的水刀切割技術廠商是埃及人嗎？」

查證後的精確版本：

> 現代磨料水刀並非由一家埃及廠商發明；其關鍵發明者 Mohamed Hashish 博士出生於埃及亞歷山卓，並在美國 Flow 團隊完成技術突破。

Hashish 將磨料加入高速水流，使水刀能有效切割鋼、石材、玻璃與複合材料。這與古埃及「水、磨料、工具載體、硬材料」的組合形成有趣的思想回聲。

目前只能視為歷史巧合或工程思想的相似，不能當成古今技術傳承證據。完整故事安排在 S01E06，古今關係的辨析安排在 S01E07。

### 6. Graphify 如何降低 AI 上下文窗口盲點

AI 的上下文窗口像一張有限的工作桌面，無法一次攤開整座圖書館或巨型專案。

Graphify 不會讓 AI 取得無限上下文，而是先建立可導航的知識地圖，再讓 AI 沿著核心節點、社群與關係找到當前問題最相關的原始資料。

已建立三個延伸案例：

1. **巨型程式系統**：理解模組、函數、API、資料表與上下游相依關係。
2. **《紅樓夢》**：理解人物別名、家族、婚姻、主僕、事件、權力與象徵關係。
3. **《咒術迴戰》**：理解人物、術式、領域、束縛、血統、咒具、陣營與相剋關係。

核心比喻：

> 當一個世界大到無法一次放進 AI 的工作桌面，就先替它建立地圖，再讓 AI 沿著地圖找到需要理解的區域。
