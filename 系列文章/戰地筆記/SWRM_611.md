## 心得速記
1. **定義書是新武器**
   - 一份好定義書 > 一周手工代碼
   - 舉例：20 行定義書 → 400 行自動生成代碼

2. **Agent Harness 是自動工廠**
   - 投進定義書，吐出完整系統
   - 不需要理解內部如何運作（黑盒信任）

3. **Token 上限是彈藥管控**
   - 0.3 → 0.5 → 1.0 逐級提升
   - 防止蜂群暴走燒光金礦

4. **版本控制救命**
   - 每個 Harness 都要 Git 存檔
   - V1 → V2 快速回滾只需秒級

5. **蜂群是複用資產，不是一次性**
   - 股票監控蜂群用過 3 次
   - 每次加新監控對象，Harness 自動調整

6. **有些事永遠不該讓 Agent 做**
   - 戰術定義必須人類下達
   - 憲法、價值觀、決策權不能外包
   - Agent 只負責執行，不負責決策
