**但知道真相只是開始。**

這篇，我不再告訴你「應該買黃金」或「應該拋售股票」。

我教你**怎麼思考**。

我邀請你**成為獨立的探究者**。

## 第一步：建立你的「真實購買力追蹤系統」

**你需要什麼**：
- 一份簡單的表格
- Claude AI
- 15分鐘/月的時間

**怎麼做**：

打開Claude，說：

```
我要建立一個「真實購買力追蹤系統」。

我的基本信息：
- 今年名目收入：$[你的年薪]
- 主要支出：房租$[X]/月、食物$[Y]/月、交通$[Z]/月、其他$[W]/月

請幫我：
1. 用官方CPI計算我的實際購買力變化（每月）
2. 用現實指數計算我的實際購買力變化（每月）
3. 告訴我這兩個數字的差距意味著什麼
4. 每月提醒我檢查這個表格
```

**效果**：

你會看到每個月，你的真實購買力在增長還是下降。

這比任何投資顧問的報告都更真實。

## 第二步：分析你的投資組合

**問Claude**：

```
我的投資組合：
- 60% 股票（S&P 500 ETF）
- 30% 國債（10年期）
- 10% 現金

根據真實指數分析：
- 黃金被低估（真實利率-1.6%）
- 股市被高估（購買力停滯）
- 國債負收益（-1.6%）

我應該怎麼調整？
請給我調整框架，而不是直接答案。
```

**Claude會幫你**：

1. 計算你當前組合的「真實風險回報率」
2. 用真實利率重新評估各資產的合理配置
3. 給你一個「調整框架」，讓你自己決定

**重點**：不是告訴你買什麼，而是教你怎麼算。

## 第三步：追蹤央行的行動

**問Claude**：

```
請整理最近6個月全球主要央行的：
1. 黃金購買量（vs上年同期）
2. 美債持有量變化
3. 對官方聲明中提到「利率」「通膨」的關鍵詞

這些數據告訴我什麼信號？
```

**為什麼**：

央行是「聰明人」。

他們的行動是對市場的最真實的評估。

**如果央行都在減持國債、增持黃金，這本身就是最強的信號。**

你只需要跟著信號走，而不需要完全理解背後的經濟學。

---

## 第四步：驗證「官方vs現實」

**數據來源**：

| 數據 | 哪裡查 |
|------|--------|
| **官方CPI** | Bureau of Labor Statistics (BLS.gov) |
| **現實指數** | RealityIndex.co |
| **央行黃金數據** | World Gold Council |
| **各國央行年報** | 各國央行官網 |

**怎麼用Claude驗證**：

```
請對比：
- BLS官方CPI數據（過去5年）
- 現實指數數據（過去5年）
- 這兩個數據的差距趨勢是什麼？
- 差距在擴大還是縮小？為什麼？
```

**這樣你就不是被動接收信息，而是主動驗證。**

---

## 第五步：持續提問，不要停止思考

**你應該定期問自己**：

1. **「真實利率現在是多少？」**

   = 當前10Y利率 - 真實通膨

   每月問一次，看趨勢。

2. **「央行在做什麼，為什麼？」**

   每季度查一次央行數據。

3. **「我的投資組合與央行的選擇有多大差距？」**

   如果差距很大，為什麼？

4. **「如果我的假設是錯的會怎樣？」**

   永遠考慮相反的可能性。
