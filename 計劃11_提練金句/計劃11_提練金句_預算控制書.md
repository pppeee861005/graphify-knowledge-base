### 1.2 成本預期詳解

#### 自動提取（0.15單位）- 最大開銷項

**為什麼這個環節成本最高？**

```
需要做什麼：
1. 逐篇掃描70+文章
2. 識別候選金句（可能有500-1000候選）
3. 評估每個候選是否符合「金句」標準

成本驅動因素：
- 文字量大（80-100萬字）
- 邏輯判斷複雜（5維度評分）
- 上下文理解需求高（理解句子深度）
```

**優化方向**：
- 可根據文章類型分層處理（重點文章深度分析，輔助文章掃描）
- 可使用規則過濾降低成本

#### 人工審核（0.10單位）- 質量保證環節

**為什麼需要人工審核？**

```
必須審核的金句：
- 3.5-4.0分的邊界金句（大約30-50條）
- 模糊判定的金句
- 跨系列重複的金句

人工審核的目的：
- 確保品質一致
- 避免误判
- 發現自動化規則的盲點
```

**人工審核流程**：
1. Claude 先提出初步名單
2. 人工檢查 3.5-4.0 分的邊界金句
3. 確認是否入選、是否需要調整評分
4. 提出修改建議
5. 生成最終版本

| 指標 | 目標 | 監控方式 |

## 五、預算控制機制

### 5.1 成本超支應急方案

**Scenario A：在自動提取階段（20-50%）發現超支**

```
觸發條件：超支 > 10%

應對方案：
1. 立即分析超支原因
2. 調整評分規則，簡化判定邏輯
3. 按優先級分層處理（重點文章優先）
4. 可選：減少評分維度（從5維簡化為3維）

預期效果：降低成本 20-30%
```

**Scenario B：在評分階段（50-70%）發現超支**

```
觸發條件：超支 > 15%

應對方案：
1. 停止複雜評分，改用簡單分級（好/中/可)
2. 取消邊界金句的深度分析
3. 自動入選規則改為：簡潔度≥4 AND 深度≥4 即入選
4. 保留 200 條最高分金句

預期效果：立即降低成本 30-40%
```

**Scenario C：在人工審核階段（70-85%）發現超支**

```
觸發條件：超支 > 20%

應對方案：
1. 停止人工審核
2. 自動入選 4.0 分以上的金句
3. 3.5-4.0 分的金句標記為「待審」，後續補充
4. 先輸出初稿，後續迭代

預期效果：快速完成，定義為 PARTIAL_COMPLETION
```

### 5.2 預算充足時的優化

**若執行到 70% 時仍有餘額**：

```
可選優化方案：
1. 加深人工審核（3.0-3.5分的邊界金句也審核）
2. 生成額外的「關鍵概念索引」
3. 為每條金句生成「應用案例」
4. 生成「系列對比分析」（跨系列主題聯繫）

成本預期：額外消耗 0.10-0.20 單位
```
