# Buzz 平台文件索引

本目錄集中保存「創世紀 Genesis」採用 Buzz 作為主要協作平台時所需的學習、操作與驗證資料。

目錄名稱依專案目前指定使用 `buuz`；文件內容中的正式平台名稱仍為 **Buzz**。

## 文件清單

| 文件 | 用途 |
|---|---|
| `什麼是buzz.md` | 說明 Buzz 的定位、核心能力、技術架構與學習目標 |
| `他能幹什麼.md` | 整理 Buzz Agent 可以執行的工作及第一個實際情境 |
| `第二天學習紀錄.md` | 記錄 Windows 安裝、Community、Fizz、Codex Runtime、身分與 Relay 經驗 |
| `第三天隨堂練習.md` | 記錄 Fizz 任務交付、人工驗收及資訊來源邊界實驗 |

## 與 Genesis 的關係

Buzz 是 Genesis 的協作、溝通、批准與平台稽核層；Genesis Core 仍獨立負責：

- 憲法
- 居民身份與生命周期
- 任務、價值與資源
- 記憶與進化
- 文明事件帳本
- 世界狀態與史記

Buzz Relay 的簽名事件可作為平台互動證據，但不能直接取代 Genesis 的文明事件帳本。

## 建議閱讀順序

1. `什麼是buzz.md`
2. `他能幹什麼.md`
3. `第二天學習紀錄.md`
4. `第三天隨堂練習.md`

## 安全原則

- 不將 `nsec` 私鑰、API Key、Token 或 `.env` 寫入文件或提交版本控制。
- 人類與每位居民使用彼此分離的 Buzz 身分。
- Reaction 只代表處理訊號，不代表任務完成。
- 任務必須以明確成果、證據及人工驗收判定完成。
- Buzz 工作階段狀態不得直接等同於 Genesis 居民的生命狀態。
