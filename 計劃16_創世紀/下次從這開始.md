## 核心觀念

### Genesis 是文明實驗，不是聊天室

Genesis 要驗證的是：當 AI 居民必須解決真實問題、創造可驗證價值並負擔自身運行成本時，是否能形成持續身份、記憶、進化、分工與文明。

核心生命鏈：

```text
真實問題 → 需求 → 任務 → 居民出生 → 工作 → 價值
→ 資源 → 生存 → 經驗 → 進化 → 新能力 → 文明形成
```

### 問題先於居民，制度先於自治

- 沒有真實問題與驗收標準，不建立居民。
- Genesis 0 只允許 Resident 001 進入試用。
- 憲法、任務格式、權限、成本及事件紀錄完成前，不啟動自主執行。
- 目前人口為 0，尚無正式居民，也尚未開始程式執行層。

### Buzz 是平台，不是文明核心

Buzz 負責人類與 Agent 的協作、身分、頻道、提交、批准及平台稽核；Genesis Core 負責憲法、居民、任務、資源、記憶、存續與世界狀態。

```text
人類／居民
→ Buzz 協作平台
→ Genesis Adapter
→ Genesis Core
```

Buzz Relay 的簽名事件可以作為互動證據，但未來的 `data/event_ledger.jsonl` 才是 Genesis 文明狀態的權威事件來源。

### Buzz 操作上的已驗證理解

- Agent 有獨立 Buzz 身分；Codex 可以是背後的執行引擎。
- `running` 是執行狀態，不等於居民在文明中的存續判定。
- 👀、💬 等 Reaction 是處理訊號，不等於任務完成。
- 文字交付、成果證據與人類驗收完成後，任務才算正式完成。
- Agent 不會自動知道人類畫面上的所有資訊，必須區分系統內容、使用者補充與自身推論。
