## 🤖 核心哲學：Human in the Loop（人在回路中）

### 設計原則：AI 輔助，人類決策

> **AI 不是取代人做決定，而是協助把資料收齊、流程開好、期限提醒、文件整理與草稿先準備好。正式決策，始終由人類做出。**

#### 哲學定位

| 維度 | 計劃 1 新世界 HR |
|------|-----------------|
| **核心理念** | Human in the Loop |
| **自動化程度** | 半自動化 |
| **人類角色** | 最終決策者 |
| **AI 定位** | 輔助整理資料 |
| **設計原則** | AI 不取代人做決定 |

#### 核心原則

✅ **AI 負責**：
- 資料收集與整理
- 流程自動建檔
- 期限提醒與追蹤
- 草稿與摘要生成
- 政策查詢與建議

✅ **人類負責**：
- 最終審批決策
- 正式公告發布
- 經費核銷確認
- 特殊情況判斷
- 責任承擔

### 三層工作結構

```
第一層：AI 自動整理
  ├─ 自動建立員工檔案資料夾
  ├─ 自動整理申請資料
  ├─ 自動生成審批建議草稿
  └─ 自動設定期限提醒

第二層：人類審核決策
  ├─ 主管收到整理好的資料包
  ├─ 主管審閱 AI 建議（30 秒）
  ├─ 主管做出最終決策（批准/駁回）
  └─ 記錄決策日誌

第三層：例外處理
  ├─ 系統標記的特殊情況
  ├─ HR 主任人工審核
  └─ 記錄異常和決策理由
```

### 經典應用場景：員工請假半自動化

  ↓

主管的動作：

## 🎯 三層工作結構詳解

### 第一層：AI 自動整理層

**AI 負責**：
- 📁 自動建立檔案資料夾結構
- 📋 自動收集和整理申請資料
- 📊 自動檢查政策並生成建議
- ⏰ 自動設定期限提醒（Calendar + 通知）
- 📝 自動生成審批建議草稿

**應用場景**：
```
✓ 員工請年假/病假/事假
  → AI 整理資料 → 生成審批建議 → 送主管決策

✓ 員工申請報銷
  → AI 檢查金額和類別 → 整理憑證 → 送主管決策

✓ 員工查詢福利政策
  → AI 直接返回答案 → 完成（無需人工）

✓ 員工申請培訓課程
  → AI 檢查預算 → 整理申請資料 → 送主管決策
```

### 第二層：人類審核決策層

**人類負責**：
- ✅ 審閱 AI 整理好的資料包
- ✅ 做出最終決策（批准/駁回/要求補充）
- ✅ 承擔決策責任
- ✅ 處理需要判斷的情況

**審核流程**：
```
1. 主管收到 AI 整理的「審批資料包」
2. 瀏覽摘要和 AI 建議（30 秒）
3. 做出最終決策（批准/駁回）
4. 系統記錄：2026-06-10 14:23:45 李主管 批准
5. 系統自動通知員工結果
```

**為什麼人類做最終決策**：
- ✅ 符合 HR 合規要求（決策必須由授權人員做出）
- ✅ 保留人類判斷力（處理 AI 無法判斷的細微情況）
- ✅ 責任明確（決策者承擔責任）
- ✅ 建立信任（員工知道有人在關注）

### 第三層：例外處理層

**特點**：
- 🚨 AI 標記的特殊情況
- 👤 由 HR 主任或更高層級審核
- 📋 記錄異常理由和決策根據
- ⏱️ 優先處理

## 🛠️ 技術選型：不造輪子，用現成的車輪

### 核心基礎設施：Google Workspace

參考學校行政工作流的成功經驗，我們採用 **Google Workspace** 作為現成基礎設施：

| 組件 | 用途 | 說明 |
|------|------|------|
| **Google Forms** | 員工申請入口 | 請假、報銷、培訓申請表單 |
| **Google Drive** | 檔案自動建檔 | 員工檔案夾、申請附件、審批記錄 |
| **Google Sheets** | 總控台 + 追蹤表 | HR 管理面板、審批狀態追蹤 |
| **Google Docs** | 審批資料包 | AI 生成的摘要和建議文件 |
| **Google Calendar** | 期限提醒 | 審批截止日、假期日曆 |
| **Gmail** | 通知系統 | 審批通知、結果通知 |
| **Apps Script** | 自動化引擎 | 串接所有組件的膠水代碼 |

### AI 增強層

在 Google Workspace 基礎上，加入 AI 能力：

| 組件 | 用途 |
|------|------|
| **NotebookLM** | 員工手冊知識庫（政策查詢） |
| **Gemini** | 生成審批建議草稿、摘要、通知內容 |

### 為什麼用現成的車輪？

```
❌ 自己造輪子：
   建立自定義系統 → 開發 6 個月 → 維護成本高 → 員工需要學習新系統

✅ 用現成車輪：
   Google Workspace → 員工已經熟悉 → 零學習成本 → 專注在 AI 增強
```

**優勢**：
- 🚀 **快速啟動**：不需要從零開發基礎設施
- 💰 **低成本**：利用企業已有的 Google Workspace 授權
- 📚 **零學習曲線**：員工已經熟悉 Gmail、Drive、Forms
- 🔧 **易維護**：Google 負責基礎設施，我們專注業務邏輯
- 🔗 **生態整合**：與企業現有工具無縫整合
