# Google Workspace 行政專案工作流

## 專案資訊

- **來源**：[GitHub - mihozip/google-workspace-admin-project-workflow](https://github.com/mihozip/google-workspace-admin-project-workflow)
- **適用對象**：學校教師、行政人員（主任、組長、承辦人）
- **技術棧**：Google Workspace + NotebookLM + Gemini + Apps Script

---

## 解決的問題

學校行政的痛點：
- 資料分散（公文在信箱、附件在下載資料夾、照片在手機、會議紀錄在 LINE）
- 期限太多容易遺漏
- 成果報告總是最後才開始整理

---

## 核心功能

| 功能 | 說明 |
|------|------|
| 自動建檔 | 公文提交 → 自動建立 Drive 資料夾、Docs 紀錄、Sheets 追蹤表 |
| 階段管理 | 多階段日期自動同步到 Google Calendar |
| 集中控制 | 總控表統一管理所有專案 |
| 提醒通知 | Calendar 提醒 + Gmail 通知 |
| 成果導向 | 完整附件與檢核紀錄，方便產出成果報告 |

---

## 自動產生的資料夾結構

```
📁 專案資料夾
├── 📁 原始公文與附件
├── 📁 計畫書與核定資料
├── 📁 工作分工與會議紀錄
├── 📁 表單與回覆資料
├── 📁 經費與採購核銷
├── 📁 活動照片與照片說明
├── 📁 成果資料與成果報告
├── 📄 專案紀錄文件
├── 📄 待辦追蹤表
└── 📄 成果檢核表
```

---

## 工作流程

```
收到公文 → 填寫專案啟動表 → 系統自動建檔
    ↓
NotebookLM 整理專案脈絡（建立專案知識庫）
    ↓
Gemini 協助產出草稿（摘要、公告、待辦、成果報告）
    ↓
人工確認 → 正式送出
```

---

## AI 輔助產出

- 公文重點摘要
- 校內公告
- 待辦清單
- 表單題目
- 會議追蹤表
- 成果報告初稿
- 成果簡報大綱
- 下次辦理建議

---

## 設計原則

> AI 不是取代人做決定，而是協助把資料收齊、流程開好、期限提醒、文件整理與成果草稿先準備好。

- 正式公告、經費核銷、公文回覆、成果送出 → **仍由人確認**
- 符合學校現場的責任、權限與資料安全需求

---

## 安裝步驟

1. 建立 Google Drive 資料夾，記錄資料夾 ID
2. 使用 PHP 設定工具填入參數
3. 將生成的程式碼貼入 Google Apps Script
4. 執行初始化函數
5. 取得兩張自動生成的表單連結
