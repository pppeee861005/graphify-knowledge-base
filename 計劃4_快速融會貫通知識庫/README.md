## 🤝 核心哲學：Human in the Loop

### 人為操作的刻意設計

計劃 4 雖然強調 **Agent First 自動駕駛**，但有一個關鍵原則：

> **最終是人類要增加知識，不是機器。**

因此，計劃 4 刻意把**人為操作**安排在整個流程之中：

### 人類干預的三個關鍵時刻

#### 1️⃣ **輸入階段**：人類決定「要學什麼」
```
人類選擇 → 上傳書籍/文檔 → Agent 自動提取
  ↑
  └─ 人類決策：選擇哪本書、哪個領域、什麼優先級
```

**關鍵**：不是 AI 決定你應該學什麼，而是你決定

#### 2️⃣ **驗證階段**：人類評估「AI 是否理解正確」
```
Agent 提取結構 → 人類檢視和驗證 → 反饋調整
                  ↑
                  └─ 人類判斷：這個關係圖對嗎？
                              這個人物卡片準確嗎？
                              這個脈絡合理嗎？
```

**關鍵**：不相信 AI 的盲目輸出，人類主動驗證

#### 3️⃣ **應用階段**：人類思考「知識的含義」
```
結構化知識 → 人類思考和消化 → 生成個人見解
              ↑
              └─ 人類反思：為什麼這很重要？
                          如何應用到我的工作？
                          我的獨特觀點是什麼？
```

**關鍵**：AI 提供結構，人類提供意義

### 「不用人類介入的知識」的處理方式

**定義**：工具操作手冊、API 文檔、軟體使用指南等**無需人類解釋**的知識

**處理方案**：採用 **計劃 1 的方式**（企業 RAG 系統）
```
工具手冊 → RAG 知識庫 → Agent 查詢檢索
           （無需人類驗證的純技術文檔）

特點：
  ✓ 自動化完全處理
  ✓ 人類只需查詢（不需驗證）
  ✓ 知識來自官方文檔（已驗證）
  ✓ 純信息檢索，無需深度思考
```

**例子**：
- ✅ Python 函數文檔 → 用計劃 1 方式
- ✅ SQL 語法手冊 → 用計劃 1 方式
- ✅ AWS API 文檔 → 用計劃 1 方式
- ❌ 《人類簡史》 → 用計劃 4 方式（需人類思考）
- ❌ 《國際銀行家》 → 用計劃 4 方式（需人類理解）

### Human in the Loop 的三大原則

| 原則 | 說明 | 應用 |
|------|------|------|
| **選擇自主** | 人類決定學什麼 | 選擇書籍、設定優先級 |
| **驗證責任** | 人類檢視 AI 輸出 | 確認關係圖、人物卡片準確性 |
| **意義創造** | 人類產生見解 | 反思、應用、創新 |

### 為什麼需要 Human in the Loop？

**反思**：
- ❌ **完全自動化的危險**：AI 生成的結構可能看起來完美，但人類沒有真正理解
- ❌ **無人驗證的風險**：200 人物的關係圖，機器錯誤也很難看出
- ❌ **知識的虛假感**：快速獲得結構，卻沒有深度思考

**正確做法**：
- ✅ **AI 加速結構化**：快速提取框架（而非一無所有）
- ✅ **人類驗證修正**：確保準確性（而非盲目信任）
- ✅ **人類思考創造**：生成個人洞察（而非被動接收）

### 計劃 4 中的 Human in the Loop 設計

#### Phase 1：人類定義研究方向
```
人類 → 選擇《國際銀行家》 → 設定研究焦點
         ↓
Agent 開始理論研究（參考人類的方向）
```

#### Phase 2：人類驗證結果
```
Agent 自動提取 200 人物卡片
         ↓
人類檢視前 10 個人物卡片
         ↓
「這個人物的影響力評分正確嗎？」
「這個家族關係應該是 A 不是 B」
         ↓
反饋 → Agent 自動調整剩餘 190 個人物
```

#### Phase 3：人類思考應用
```
Agent 生成完整的關係圖和脈絡
         ↓
人類深入思考：
  「為什麼羅斯柴爾德能控制歐洲金融？」
  「現代金融系統如何繼承這個邏輯？」
  「如何應用到我的投資策略？」
         ↓
生成個人洞察和創意應用
```

## 🌟 《國際銀行家》——計劃 4 的實驗案例

### 為什麼選擇《國際銀行家》？

**系統終極挑戰**：
- 📚 **龐大的知識量**：800+ 頁，200+ 人物，複雜的金融歷史
- 👥 **複雜的人物網絡**：家族關係、利益集團、思想派系、衝突對立
- 🔗 **隱含的因果關係**：金融系統如何演化？為什麼會有經濟危機？
- 📊 **多維度的信息結構**：時間維、人物維、家族維、權力維

**傳統方式**：
- ❌ 手動整理 200 人物卡片：100+ 小時
- ❌ 手動繪製複雜關係圖：20+ 小時
- ❌ 手動梳理時間線和脈絡：15+ 小時
- **合計**：135+ 小時（超過 1 個月全職工作）

**計劃 4 的目標**：
- ✅ 自動提取 200+ 人物卡片：< 5 分鐘
- ✅ 自動生成 5 種關係圖：< 5 分鐘
- ✅ 自動梳理 4 個時代的演化：< 3 分鐘
- **合計**：< 30 分鐘自動完成，質量由 AI 保證

### 實驗目標

| 階段 | 時間 | 目標 | 預期成果 |
|------|------|------|---------|
| **Phase 1** | 7/15-7/22 | 建立理論框架 | 5 大理論 + research_plan.md |
| **Phase 2** | 7/23-7/31 | 實現融會貫通系統 MVP | 完整系統 + 《國際銀行家》案例 |
| **Phase 3** | 8/1-8/7 | 完成白皮書 | 《國際銀行家》200 人物全分析 |

### 《國際銀行家》的預期成果

**目錄層級**：
```
《國際銀行家：從洛斯柴爾德到現代金融帝國》
├── 第一章：金本位的起源與演變
├── 第二章：歐洲金融家族興起
├── 第三章：羅斯柴爾德家族的崛起
├── 第四章：洛克菲勒與美國金融帝國
├── 第五章：日本與亞洲金融勢力
├── 第六章：金權戰爭的現代延伸
└── 第七章：附錄與人物關係圖
```

**人物分類**（200+ 人物自動分層）：
```
主要人物（50 人）：影響全球金融的領袖人物
  ├─ 羅斯柴爾德家族核心成員（15 人）
  ├─ 洛克菲勒家族核心成員（12 人）
  ├─ 摩根家族核心成員（10 人）
  ├─ 政治領袖與央行行長（13 人）

次要人物（100 人）：支撐金融帝國運作的關鍵人物
  ├─ 其他金融家族（40 人）
  ├─ 企業家與投資者（35 人）
  ├─ 經濟學家與理論家（20 人）
  └─ 合作者與盟友（5 人）

邊界人物（50 人）：歷史事件的參與者或旁觀者
  ├─ 對手與競爭者（20 人）
  ├─ 政治家與官員（20 人）
  └─ 其他利益相關者（10 人）
```

**關係圖譜**（5 種維度自動推導）：
```
1. 家族關係圖 — 誰跟誰有親戚關係？
2. 利益集團圖 — 誰控制哪些企業和銀行？
3. 權力階層圖 — 誰對全球金融決策有影響力？
4. 思想傳承圖 — 經濟理論如何傳播和演化？
5. 衝突陣營圖 — 不同派系之間的對立與聯盟？
```

**時間線分析**（4 個歷史時期）：
```
1825-1945：金融帝國的建立期
  └─ 羅斯柴爾德如何控制歐洲金融？
  └─ 洛克菲勒如何建立美國金融帝國？

1945-1971：布雷頓森林體系時代
  └─ 二戰後全球金融體系如何重組？
  └─ 美元如何成為世界貨幣？

1971-2008：自由浮動匯率時代
  └─ 金本位制為何瓦解？
  └─ 現代金融創新如何推動？

2008至今：金融危機後重組期
  └─ 2008 年金融危機的根本原因是什麼？
  └─ 全球金融權力如何重新分配？
```

**故事脈絡**（5 個核心敘事線）：
```
1. 家族財富的積累與傳承
   → 從無到有，如何建立金融帝國？

4. 政治與金融的互相影響

5. 全球金融權力的集中與分散
   → 金融權力如何從歐洲轉移到美國？
```
