# 威廉一世 (Kaiser Wilhelm I)

- **身份**：德意志帝國首位皇帝（1871‑1888）。
- **時代**：19 世紀中期至後期（1797‑1888），於 1871 年德意志帝國成立後加冕。
- **主要貢獻**：
  - 授予奧托·馮·俾斯麥（Otto von Bismarck）全權統領外交與內政，推動德意志統一。
  - 作為皇帝象徵，鞏固新成立帝國的國家認同與國際地位。
- **關係**：
  - 與 **俾斯麥** 建立密切合作夥伴關係，皇帝授權俾斯麥執行「鐵血政策」。
  - 與 **羅斯柴爾德家族** 有財政往來，利用其資金支撐帝國軍事擴張。

*此筆記簡述威廉一世的生平及其在德意志帝國建國中的核心角色，未來可加入更詳細的政治與軍事事件描述。*
